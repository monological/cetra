# 11.6 — B5 Bokeh depth of field: near/far gather with an N-gon kernel

## Context

The current DoF (dof_coc → dof_blur → dof_composite) is a 16-tap Vogel
scatter-as-gather at half res with a full-res cross-fade composite. Two
structural limits: the composite `mix(sharp, blurred, |coc|/maxCoC)` keeps
sharp content mixed in until maximum defocus, so bokeh shapes never read
cleanly; and there is no near field, so a defocused foreground never spills
over an in-focus background — the most recognizable property of real DoF.
The 16-tap kernel renders discrete Vogel dots on small bright points.

The roadmap (docs/aaa-rendering-roadmap.md:286-296, Tier 2 row 10) pre-settles
the shape: keep dof_coc; add a 1/8-res tile+dilate pass (motion-blur
tilemax/neighbormax precedent); replace dof_blur with a half-res 64-tap
gather warped to an N-gon (CPU `vec2 kernel[64]` uniform, dof_blades /
dof_rotation, 0 = circle), MRT to near+far RGBA16F fields; extended
composite (far under sharp by CoC, near alpha-over with dilated coverage).
Autofocus untouched.

**Fixture: required.** No DoF golden, gate, or fixture exists anywhere — B5
creates the first. The roadmap itself lists the "bokeh chart" in its new-
test-content ledger. The fixture also becomes the repo's first consumer of
`KHR_materials_emissive_strength` (import works end-to-end at import.c:279-284
but no asset exercises it — the ao_fixture pattern of pinning an unexercised
import path).

DoF is opt-in (`--dof`), so the 15-golden battery… the existing 14 goldens
stay at 0 px through every phase; the new golden bakes last.

## Settled design

**D1 — CoC model unchanged.** `cocAtNdcZ` (include/depth.glsl, DOF_COC block)
ships byte-identical: `clamp((dist-focus)/range, -1, 1) * maxCoC`, sky →
+maxCoC, units = half-res texels. The SIGN is the near/far classification and,
because the ramp is monotonic in distance, signed-CoC ordering IS depth
ordering — the tile needs no min-depth channel and the gather no depth
texture. Physical aperture coupling (Exposure.aperture exists but is
exposure-only; needs focal length + sensor width nothing authors) is a
recorded follow-up with the formula in the spec.

**D2 — Tile + dilate.** `#define DOF_TILE 4` (half-res texels per tile texel
= 8 full-res px). Tile dims `(bloom_w+3)/4 × (bloom_h+3)/4`, GL_RG16F.
`dof_tile_frag.glsl`: 4×4 reduce of dof_coc's .a — R = max(coc, 0) (far),
G = max(−coc, 0) (near). `dof_dilate_frag.glsl`: channelwise max over
(2K+1)², `dilateRadius` K = clamp(ceil(maxCoC / DOF_TILE), 1, 8) CPU-side.
Two shaders per the tilemax/neighbormax idiom (noted deviation from the
roadmap's singular "dof_tile_frag"). Gather consumes via `texelFetch` (never
bilinear — interpolated maxima dip below either plateau at seams); gather
radius R = max(tile.r, tile.g); per-tile early-out when R < 0.5 writes
far = (center.rgb, 0), near = 0 → the composite passthrough reproduces the
sharp scene. The gather must NOT early-out on its own pixel's CoC — sharp
pixels next to defocused foreground need the tile radius to collect spill.

**D3 — Gather: one 64-tap loop, MRT near+far.** `dof_gather_frag.glsl`
(replaces dof_blur_frag.glsl), half-res, two RGBA16F attachments on one FBO
(glDrawBuffers(2) set once; always writes both). `CLASS_EPS = 0.25` (|coc|
below = in-focus, excluded from both fields — under the composite's 0.5
farBlend start, so every blended pixel is classified by its own center tap).

    float spread = (R * R) / float(TAPS);       // per-tap area / pi
    // per tap (plus one explicit center tap at d = 0):
    vec2  off   = kernel[i] * R * texelSize;
    vec4  tap   = texture(cocColorTex, TexCoords + off);
    float d     = length(kernel[i]) * R;
    float ac    = abs(tap.a);
    float reach = clamp(ac - d + 1.0, 0.0, 1.0);          // tap's disc covers us
    float aw    = min(1.0, spread / max(ac * ac, 0.25));  // 1/area energy norm
    float w     = reach * aw;
    // tap.a >  CLASS_EPS → far accumulate; tap.a < -CLASS_EPS → near + cov

The area weight conserves energy (a big disc is dim), implements CoC-ordered
occlusion (nearer/smaller-CoC dominates where both reach), makes `cov` the
GEOMETRIC coverage (disc-overlap fraction, soft ramp past silhouettes — the
"dilated coverage" without a separate pass), and is R-invariant (tap count ∝
1/R², aw ∝ R²) so tile-radius jumps are second-order — the structural answer
to tile pops. Outputs: FAR = (farW>0 ? farAcc/farW : center.rgb, farW) —
fallback to center color kills dark halos at the sharp↔far ring; NEAR =
PREMULTIPLIED ((nearAcc/nearW)·cov, cov) — empty texels are exact zeros, so
bilinear can only fade coverage, never smear color. Far-field continuity:
sharp taps are class-excluded, so the far texture is bg-colored ON foreground
pixels near silhouettes — bilinear across the edge reads blur, not fg color.
Depth source: none — tile+gather read only dof_coc's signed CoC (the existing
depth_fbo blit stays; aux.z would add a wants-aux term for --no-ssao --dof).

**D4 — Composite rewrite** (`dof_composite_frag.glsl`, full-res, same
dof_fbo/scene_tex handoff). Recomputes CoC at full res via the same helper
(full-res-crisp classification edge — the half-res shimmer mitigation):

    float farBlend = smoothstep(0.5, 1.5, coc);   // half-res texels
    vec4 nearF = texture(nearTex, TexCoords);     // premultiplied + coverage
    if (farBlend <= 0.0 && nearF.a <= 0.0) return sharp;   // bit-exact
    vec3 base = mix(sharp, texture(farTex, ...).rgb, farBlend);
    FragColor = vec4(nearF.rgb + base * (1.0 - nearF.a), 1.0);

The narrow smoothstep replaces |coc|/maxCoC — past ~1 half-res texel the far
field fully replaces sharp, which is what lets aperture shapes read. Near
composites over base (near bokeh occludes far bokeh). Units: sceneTex 0,
nearTex 1, farTex 2, depthTex 3 (re-seed the set-once block).

**D5 — Kernel: CPU Vogel spiral warped to an N-gon, deterministic by
construction.** In postfx.c, `DOF_TAPS 64`:

    r  = sqrt((i + 0.5) / TAPS); th = i * GOLDEN_ANGLE;
    if (blades >= 3) { seg = 2π/blades; a = fmod(th, seg) - seg/2;
                       r *= cos(seg/2) / cos(a); }     // disk → regular N-gon
    th += rotation;  k[i] = r * (cos th, sin th);

No RNG (determinism made Vogel-warp win over Poisson rejection; equivalent
blue-noise quality at 64 points). blades 0/1/2 = circle. Rotation is CPU-side
and per-frame static — no temporal jitter; deliberately NO per-pixel rotation
(it destroys the polygon). Upload via glUniform2fv(loc, 64, ...) each DoF
frame (uniform_set_vec2 is count-1; raw-location precedent exists).
PostFX gains `int dof_blades` (default 0) + `float dof_rotation` (default 0,
degrees). CLI `--dof-blades <n>`, `--dof-rotation <deg>`; GUI SliderInt
Blades 0-9 + SliderFloat Rotation 0-180 in the existing DoF panel
(engine.c:1863-1871). `.cscn post.dof` block: recorded follow-up, not in
scope (recipes pin focus/range via CLI anyway). Targets: replace
dof_blur_fbo/texture with dof_gather_fbo + dof_far/near_texture (half-res
RGBA16F ×2); add dof_tile/dilate FBOs (RG16F, tile dims); programs
create_dof_{tile,dilate,gather}_program; dof_blur program deleted.
postfx_run_dof becomes coc → tile → dilate → gather → composite.

**D6 — Fixture** (`assets/gen_dof_fixture.py` → dof_fixture.gltf + generated
checker PNG + hand-written dof_fixture.cscn; gen_ao_fixture.py template).
Camera at z=+6 → focus plane z=0. Focus panel: 1.2×0.9 checker+rings quad at
z=0 (the sharpness judge). Near row: 3 warm emissive spheres r=0.05 at 3 m,
strength 80 — one overlapping the panel edge (near-spill-over-sharp
assertion). Mid row: 5 white ×60 at 6.8 m (coc ≈ 0.53·max — transition
band). Far rows: 5 cool ×100 at 9 m + 4 magenta ×150 r=0.08 at 12 m (both
clamp to +maxCoC; distinct colors make a near/far swap instantly visible);
one far sphere half-occluded by the panel (far-under-sharp), one directly
behind a near sphere (ordering). Dark ground quad for the continuous ramp.
Depth-layout math goes in the generator docstring: scene radius ≈ 8.5 →
auto_near ≈ 0.42 m (nothing clips), and the scene-scaled default focus range
(≈12.7) would leave everything sharp — the recipe pins focus/range. Sphere
r=0.05 at 9 m ≈ 3.4 half-res texels — above the 64-tap spacing floor at
radius 8, so discs render filled. .cscn: ambient 0.03, one ~500 lm shadow-
casting point light for the panel, camera eye [0,1.2,6] target [0,1,0]
fov 40, post neutral/exposure 1.0. HDR-free.

**D7 — Golden: ONE, hexagon, no-bloom.**

    ./out/bin/render -m assets/dof_fixture.gltf -x -f 30 -W 800 -H 500 \
        --no-auto-exposure -E 1.0 --no-bloom \
        --dof --dof-focus 6 --dof-range 1.5 --dof-max-coc 8 \
        --dof-blades 6 --dof-rotation 15 -S out.ppm

--no-bloom isolates the kernel (bloom halos would mask the polygon edges —
the thing the golden pins); a second with-bloom golden rejected (bloom-over-
DoF is the existing bloom on a different scene_tex, already pinned). Hex +
rotation 15° exercises warp AND rotation in one image (a dead rotation
uniform is unmissable — 15° puts a flat top where 0° has a vertex). Circle
verified by A/B, not baked. Battery 14 → 15. Bakes ONLY in Phase 4 after
1:1 inspection; never bake with any dot/sparkle signature visible.

**D8 — Invariants.** OFF path untouched (the postfx hook is unchanged; new
shaders run only under --dof) — 14 goldens exact 0 every phase. NEW
everything-in-focus byte gate from Phase 3: `--dof --dof-focus <d>
--dof-range 1e6` on an interior scene (cornell_box) must be cmp-exact vs
no --dof (all coc≈0 → tile early-out → composite passthrough); interior
scene because sky pixels are +maxCoC by design. Determinism ×2 every phase
(kernel CPU-static, no noise anywhere); raiden byte-identical vs a
pre-branch baseline.

**D9 — Resolutions.** Half res = bloom_width/height, full = width/height, as
today. If B4 (TAAU) lands first, gather family moves to render res per the
roadmap's split — noted, not pre-built.

Branch `bokeh-dof` off master; spec `specs/11.6-bokeh-dof.md` committed
first. Every phase: build, 14-golden sweep 0 px, gates green, determinism ×2
(fixture --dof twice + raiden vs baseline), commit.

kernel + fields + CLI + GUI; dof_gather_frag.glsl lands under the OLD

**Phase 2 — tile + dilate** (D2). Verify: GUI maxCoC sweep 0→40 shows no
tile seams/pops on the fixture; discs grow symmetrically.

**Phase 3 — near/far MRT + composite rewrite** (D3+D4), the money phase.
Verify: near-row spill crosses the panel edge with a soft ramp; far sphere
stays cleanly UNDER the panel silhouette; near disc occludes the far disc
behind it; the everything-in-focus byte gate cmp-exact; panel-center crop
pixel-identical to --no-dof at pinned focus.

**Phase 4 — tune + golden bake + docs.** 1:1 inspection loop (CLASS_EPS,
smoothstep band, sphere sizes per D6 math); confirm no dot/sparkle at
maxCoC 8; bake dof_fixture_golden.png, add to the sweep, document recipe +

**Phase R — reviews + as-built + roadmap.** Five background audits, wait for

on explicit permission.

## The golden

`assets/dof_fixture_golden.png`, baked after 1:1 inspection at Phase 4:

    ./out/bin/render -m assets/dof_fixture.gltf -x -f 30 -W 800 -H 500 \
        --no-auto-exposure -E 1.0 --no-bloom \
        --dof --dof-focus 6 --dof-range 1.5 --dof-max-coc 8 \
        --dof-blades 6 --dof-rotation 15 -S out.ppm

Every flag is load-bearing: -W/-H because the golden is 1600x1000 (the 2x
supersampled framebuffer); --no-bloom because bloom halos would mask the
polygon edges the golden exists to pin; focus/range because the scene-scaled
defaults would leave the whole chart sharp; blades 6 + rotation 15 because
the hexagon pins the warp and 15 degrees puts a flat top where 0 has a
vertex, so a dead rotation uniform is unmissable.

What to look for, at 1:1 (never a thumbnail): filled hexagonal discs on the
cool/magenta far rows with the rotated flat top -- the pre-B5 signature was
discrete scalloped Vogel dots; the warm near sphere's disc crossing the
panel's left edge complete and soft (near spill OVER sharp); the cool disc
at the panel's right edge clipped by the silhouette (far UNDER sharp); the
checker/rings panel pin-sharp -- its interior is bit-exact against --no-dof
by the composite's passthrough.

## Risks

Near-field halos (mitigated: premultiplied storage + geometric coverage;
Phase-3 panel-edge A/B is the acceptance test); half-res edge shimmer
(full-res CoC classification + far-field center-color fallback + bg-colored
far field on fg pixels); tile pops (texelFetch + K sized from maxCoC +
R-invariant weights); big-CoC sparkle (fixture sizes above the spacing
floor, golden capped at maxCoC 8, GUI-40 quality note); slightly-near
underblur beside large far CoC (accepted classic gather artifact, recorded);
fp16 range fine (emissive ≤150 × coverage, ceiling 65504).

**Effort: M** (4 gated phases + reviews, ~1 week of sessions).
