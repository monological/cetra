# B2 — Volumetric clouds (with phase 0: the fog-golden bisect)

## Context

B2 is the last unstarted Tier-1 item on the AAA roadmap: Schneider/Nubis-style
volumetric clouds folded into SkyAtmosphere, sharing the sun, the
transmittance/multiscatter/sky-view LUTs, and the bake path. Before it starts,
one piece of recorded debt gets its owner (phase 0). Design grounded in three
code explorations (sky, noise/threading, postfx/temporal) plus an independent
design review; the roadmap's B2 sketch predates the 9.5-9.8 code and several
of its assumptions are corrected below (no separate reproject shader, no curl
field in v1, captures skip clouds rather than re-march).

## Phase 0 — fog-golden bisect (small, independent, first)

Recipe: `render -m assets/contact_fixture.gltf --fog --no-aerial -x -f 30
--no-auto-exposure -E 1.0 -W 640 -H 400 -S out.ppm` vs
`assets/froxel_fog_golden.png` — currently 1,036 px / PAE 6 LSB, a dotted
left-edge floor patch, proven to predate 10.9. Binary-search the 10.7-10.8.1
commits (~5 builds). Legitimate change → re-bake the golden with the reason
recorded; real leak → its own small fix. Done = golden compares 0 px and the
cause is written down. (Note: the fixture uses the procedural sky, NOT an HDR
env — so the 10.8.1 equirect work is NOT the obvious suspect; that is what
makes this worth the hour.)

## Settled design

**Where clouds render.** Half-internal-res march (RGBA16F: rgb = in-scattered
radiance, a = transmittance) into a sky-owned ping-pong target, run in the
pre-scene window (`engine.c:2300-2313`, before the main FBO binds).
Composite in the sky background slot (`render.c:748`): `sky*cloud.a +
cloud.rgb`, LEQUAL depth test, depth writes off — terrain occludes clouds for
free; the later froxel fog+aerial fold attenuates them as far scene untouched.
**No depth in the march** (only last-frame depth exists pre-scene; occlusion
is entirely the composite's depth test). Plain bilinear upsample — cloud
content is smooth and sky-only, geometry edges are the depth test's problem.
March rays from the UNJITTERED projection (the aerial/froxel discipline).

**Off-gate mechanism (byte-identity when off).** Two programs: clouds off →
the existing `sky_background` program binds, untouched; on → a new
`sky_background_clouds` program. Shared body via a new
`include/sky_radiance.glsl` extraction — landed as its OWN commit with an
immediate off-gate cmp so a nonzero diff is attributable to the extraction
alone; fallback is body duplication with a keep-in-step header and
`sky_background_frag.glsl` byte-untouched. Clouds off = no cloud GL objects
allocated, march never runs.

**Temporal.** Ray-direction reprojection with a cloud-owned previous camera
(rotation-only prev view + unjittered prev proj) + adjacency stamp, ping-pong
indexed by frame parity — the 9.5.1 froxel model, blended INLINE in the march
pass (no separate reproject shader). NOT TAA-gated: the dither is a pure
function of frame_index (`ign(gl_FragCoord.xy + vec2(frame*5.588238))`,
frame term only when the stamp says history is adjacent), so headless stays
byte-deterministic and goldens converge at fixed frame count. Blend 0.9
history on hit; current-only on miss/off-screen/stamp break.

**Clock (ruled).** Cloud drift never reads `render_time` (wall clock under
the render app — the wind hazard). `sky->clouds.scroll` advances once per
frame: `+= 1/60` when `engine->headless`, else `+= render_delta`.

**Captures & env cadence.** During probe/GI captures (`engine->capturing`)
the plain background program binds — capture cameras never sample the
screen-space cloud texture; the small ambient-vs-background inconsistency is
accepted and documented (a 12-step capture march is a named follow-up). Env
bake: `sky_bake_ex(..., with_clouds)` — live sun DRAG bakes the env without
clouds (keeps today's ~10ms drag cost), slider RELEASE does the full bake
with a 24-step env march (`sky_env_clouds_frag`), riding the existing
release path that already refreshes probe + GI. Cloud-param edits re-bake on
release only; the noise NEVER re-bakes (sun-independent).

**Working space.** The march include returns ABSOLUTE radiance (the env
cube's convention); each caller converts — the screen composite applies
`preExposure` once at the end and caps in-scatter at `WS_MEDIA_MAX`.

## The march (include/clouds.glsl — key numbers)

- Contract: `cloud_march(roKm, rd, sunDir, shapeTex, detailTex,
  transmittanceLut, skyViewLut, steps, lightSteps, detailOn, coverage,
  cloudType, densityScale, windOffsetKm, dither) -> vec4(radiance, T)`;
  samplers as parameters (the atmosphere.glsl convention); kilometers,
  camera-relative planet frame.
- Shell 1.5-4.0 km above ground on the atmosphere's Rg=6360; stable-quadratic
  ray-sphere (q-form; fp32 horizon precision is risk R5 with a day-1 probe);
  path capped 48 km with an exponential tail fade.
- Steps: screen 48-64 adaptive by path length; env 24; (capture 12,
  reserved). 6 exponential light steps toward the sun, density at mip 1, sun
  color via `transmittanceToSky` at altitude.
- Density: 128³ shape (Perlin-Worley R + 3 inverted-Worley octaves GBA, tile
  8 km) remapped by coverage + an altitude gradient by cloud type; 32³ Worley
  detail (tile 1 km) erodes edges only where density < 0.3. Extinction
  default 25/km × densityScale.
- Lighting: dual-lobe HG (0.85 / −0.3), powder term, one hoisted zenith
  sky-view tap as ambient; Hillaire energy-conserving per-step integration;
  early-out at T < 0.01; light march skipped at zero density.

## Noise bake (threaded, once, gated on clouds)

- noise.c gains a LOCAL-table API — `NoisePerm` + `noise_perm_init` (own
  LCG, never srand/rand — thread-safe, independent of the apps' global
  re-seeding) — plus stateless tiling `noise_worley3(x,y,z,period,seed)`
  lifted from the tree app's integer-hash 2D Worley. Fixed cloud seed.
- texture.c gains `create_texture_3d_rgba8_mipped` (REPEAT all axes,
  trilinear mips, glTexImage3D + glGenerateMipmap — the sibling the float
  helper's own comment reserves).
- Fields: 128³ RGBA8 shape + 32³ RGBA8 detail (~8.4 MB; curl DEFERRED, v1
  consumes nothing from it). `sky_bake_cloud_noise()` peer of
  `sky_bake_static_luts`: min(8, cores) threads via the thread.h shim over
  disjoint Z-slabs (bytes deterministic regardless of thread count — every
  voxel a pure function of (x,y,z,seed)), join, upload on the GL thread,
  timed + logged. Estimated ~250-450 ms across 8 threads, once.

## Cost estimate + knobs (1600×1200 → 800×600 march, M1 Max)

Typical partly-cloudy view ~2-5 ms; worst case (overcast horizon) 8-14 ms;
env-with-clouds bake 4-8 ms (why the drag path excludes it). Estimates, not
measurements — Phase 2 opens with the timing probe. Knob ladder if slow:
steps 64→48, light steps 6→4, detail only while T > 0.3, quarter-res march,
checkerboard temporal amortization, last-frame-depth mask.

## Phases

Each phase ends committed, building, gates green. Total ≈ 2-3 focused weeks.

1. **Noise foundations + debug view (~2d).** noise.c local-table API +
   worley3; the RGBA8 3D helper; `sky_clouds.c` + CloudLayer sub-struct on
   sky.h; threaded bake; a slice/channel debug view beside the sky LUT
   tiles; `--clouds` allocates + bakes only. Done: bake < 1 s wall, logged;
   tiles visually correct; byte-deterministic across runs AND thread counts;
   clouds-off renders 0 px vs master.
2. **Deterministic screen march (~4-6d, the hard part).** The
   sky_radiance.glsl extraction (own commit + immediate cmp), clouds.glsl,
   cloud_march_frag, sky_background_clouds_frag, the pre-scene march call,
   `--cloud-coverage`. R1 (GL-on-Metal 3D-tap perf, lighting stubbed) and R5
   (horizon precision sweep) probes run DAY 1, go/no-go before lighting.
   Static dither only. Done: clouds over the aerial-fixture ridgeline with
   correct occlusion, silver lining + powder at sun el 20; determinism ×2
   0 px; off-gate 0 px (raiden + fixture); march ms logged within envelope;
   `assets/cloud_fixture_golden.png` committed (+ a low-sun variant golden
   via --sun-elevation).
3. **Temporal reprojection (~2-3d).** Ping-pong + prev-camera + stamp; frame
   -strided dither when adjacent. Done: consecutive-frame churn strictly
   below Phase 2's static number under TAA; no visible smear on a fast orbit
   (translation parallax is R2 — blend/reject ladder recorded); determinism
   ×2 and off-gate still 0 px; golden re-baked with justification.
4. **Env/IBL + cadence split (~2-3d).** sky_env_clouds_frag (24 steps),
   sky_bake_ex, drag-vs-release wiring, startup bake with clouds. Done:
   IBL/probes/GI see clouds; sun-drag latency unchanged from master
   (measured, logged); no screen texture in captures; non-cloud goldens
   (aerial, froxel fog) still 0 px.
5. **Wind + GUI + CLI + gates (~2d).** The scroll accumulator + wind
   uniforms; `--cloud-wind`, `--cloud-density`; optional .cscn clouds block;
   GUI sky-group sliders (coverage/type re-bake env on release only); a
   cloud churn gate in gates.py (threshold from Phase 3's numbers ×1.5,
   report-only one cycle then blocking); roadmap B2 as-built; spec
   follow-ups named (cloud shadows on ground/froxels, weather texture,
   curl, capture march). Done: wind byte-deterministic headless (fixed
   step); full gates green; final off-gate sweep 0 px.

## Top risks (each with a cheap probe)

1. GL-on-Metal 3D-texture mip sampling perf in a dynamic fragment loop —
   day-1 timing probe, fixed-trip loop + explicit textureLod.
2. Half-res + TAA + ray-dir reprojection smear (translation unmodelled) —
   orbit/dolly A/B at 1:1; ladder: blend 0.8, angular-error reject, 3×3
   clamp.
3. The ~10ms drag re-bake budget — structurally mitigated by the cadence
   split; measure the with-clouds cost once and record it.
4. Banding at 48 steps — dither on/off A/B at 48 vs 64; accept fixed 64 if
   adaptive 48 bands.
5. fp32 shell intersection at the horizon (Rg 6360 km catastrophic
   cancellation) — elevation-sweep probe rendering entry/exit distances;
   camera-centred km frame + stable quadratic + path cap.

## As-built (11.0)

Shipped in six commits on `volumetric-clouds` (spec, phase 1 noise, the
sky_radiance extraction, phase 2 march, phase 2 goldens+probes, phase 3
temporal, phase 4 env/IBL, phase 5 wind+GUI+gates). Phase 0 (the fog-golden
bisect) landed separately on master: the 1,035-px drift bisected in three
builds to e86fce9 (the catcher/ground z-fight fix, 10.5 era) -- a
legitimate change whose golden re-bake was missed; re-baked with the cause
recorded.

### Deltas vs the plan

- The coverage remap needed its own calibration: the raw 1-coverage
  threshold flipped clear-to-overcast within a tenth (the Perlin-Worley
  band's mass sits in ~0.5-0.75), so coverage maps onto the band's extent
  (lo = mix(0.85, 0.45, coverage)).
- The lighting needed three first-light fixes beyond the planned terms:
  short cone taps (the planned 3 km far tap blackened everything through
  neighbouring towers), a dual-Beer multi-scatter cheat, a floored powder,
  and a CLOUD_MS_GAIN 8 calibration constant standing in for the multiple
  scattering a single-scatter march cannot produce (documented in
  clouds.glsl against the sky's own arbitrary radiance scale).
- The phase-2 goldens were deliberately baked AFTER the user approved the
  look, then re-baked at phases 3 (accumulation) and 4 (IBL carries the
  deck) with justification in each commit.
- The gate's churn factor was recalibrated on its own basis: _taa_churn
  compares frames THIRTY apart, where the non-repeating dither touches
  ~6x more pixels than the adjacent-frame churn the plan's number came
  from. Report-only this cycle at factor 9.7 (153,015 px vs 23,656 floor,
  measured); flips to blocking next cycle.

### Measured numbers

- Noise bake: ~540-555 ms across 8 threads + ~12-54 ms upload/mips, once,
  byte-deterministic across runs (and thread counts by construction).
- R1 march cost: 200 frames with clouds == 200 frames without, once the
  one-time bake is subtracted -- sub-ms at the fixture framing; no
  GL-on-Metal 3D-sampling pathology. R5: shell entry/span fields smooth
  through the horizon band, no banding or NaN at grazing incidence.
- Env bake with clouds: 73.6 ms vs ~10 ms plain -- the number that
  justifies the drag/release cadence split.
- Temporal: adjacent-frame churn 27,957 px vs 9,724 floor at RMSE 0.00032
  (imperceptible); the static-dither stipple fully resolved by frame 30.
- Off-gates, all 0 px: aerial fixture golden (every phase), froxel fog
  golden, raiden cross-build (master vs branch tip), zero-wind vs the
  committed cloud golden. Wind deterministic x2 headless (fixed 1/60
  step).
- Full gates.py green throughout; all pre-existing gates byte-identical.
