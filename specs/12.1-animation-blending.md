# Spec 12.1 — Animation blending

## Context

`docs/game-engine-roadmap.md` lists animation blending as the next item after audio (12.0):
"Absent (one clip at a time) — smooth locomotion (idle↔walk↔run), layered actions." Today a
clip is baked straight into skin matrices by one fused function, `compute_bone_matrices`
(`cetra/src/animation.c:746-955`): sampling, retargeting, hierarchy accumulation, spring bones
and skin-matrix build in a single pass over `mat4` locals. Matrices cannot be blended, so there
is no seam to blend at. Switching clips is a hard cut (`set_animation`, `animation.c:441-449`).
Two more ceilings sit under it: the renderer holds ONE process-global pose
(`cetra/src/render.c:69`, `g_current_animation_state`) so two rigs cannot carry two poses, and
the game framework's `COMPONENT_ANIMATOR` is a bare enum line (`cetra/src/game/component.h:12`).
No app but `apps/render` drives skeletal animation; gametest's player is a red box.

This spec adds the blend layer the roadmap booked, the per-node pose it needs, the `ANIMATOR`
component on the 12.0 audio template, a procedural puppet so gametest has a rig that is
asset-free and gate-able (the way 12.0 used procedural tones), timeline events with a callback
(the notify model every shipping engine has), and an `anim` gate group. The walk cycle
`assets/strut_walk.fbx` (animation-only, 52 channels @ 60 tps, 86 ticks, bone names on the
`cetra_rig:` prefix) is in `assets/` now and is the committed real-motion input.

**Non-goals** (stated, not built): root motion; IK; additive layers; an animation state machine
or graph (a game decides what plays; the animator does fading, blending and events); pose
interpolation by the fixed-step alpha; `.cscn` animation authoring; committed real character
content (raiden stays gitignored and is the by-hand path); changing `interpolate_position`'s
zero fallback for a channel with no position keys (byte identity is this spec's contract — the
puppet authors a translation track per animated joint instead, and the trap is recorded).

## Design

### 1. A pose is a value (`cetra/src/animation.h/.c`)

```c
typedef struct BoneTransform { vec3 position; versor rotation; vec3 scale; } BoneTransform;
typedef struct Pose {
    const Skeleton* skeleton; size_t bone_count;
    BoneTransform bones[MAX_BONES];
    uint8_t driven[MAX_BONES]; // 0 = no clip drove it: TRS holds the bind local DECOMPOSED so a
                               // blend has numbers, but apply copies the bind MATRIX verbatim
} Pose;
void pose_bind(const Skeleton*, Pose* out);
void animation_sample_pose(const Animation*, const Skeleton*, float time_ticks, Pose* out);
void pose_blend(const Pose* a, const Pose* b, float t, Pose* out);          // may alias
void pose_blend_masked(const Pose* base, const Pose* over, const float* w, Pose* out);
void animation_state_apply_pose(AnimationState*, const Pose*, float dt);    // dt drives springs
```

- `animation_sample_pose` is PASS 0 + PASS 1 of today's function for ONE clip, statement for
  statement, with per-call stack scratch (the three file-statics at `animation.c:766-768` go).
  The global-retarget branch reads the parent's animated global from a scratch `mat4 globals[]`
  the sampler accumulates from the clip's own locals (`animation.c:854` today reads
  `state->global_transforms[parent]`, which is that same value) — so each clip is sampled
  self-consistently before any blend. Rotation stays exactly what `interpolate_rotation`
  produced (un-normalised slerp output, `animation.c:661`); do not "clean up" here.
- `driven` is what keeps the single-clip path bit-identical: `Bone.local_transform` is assimp's
  matrix verbatim and decompose→recompose is not the same bits, so an undriven bone copies the
  matrix as `animation.c:919-922` does today.
- ONE static helper builds a local from TRS (`T*R*S`, the exact call order of
  `animation.c:876-883`), used by both the sampler's scratch and the apply.
- `pose_blend`: lerp position/scale; rotation by **nlerp** with hemisphere flip and normalise
  (commutative, the standard for pose blends). `t <= 0` copies a, `t >= 1` copies b, flags
  included. A bone undriven in both stays undriven. `pose_blend_masked`: per-bone `w`
  (`<= 0` copies base, `>= 1` copies over).
- `animation_state_apply_pose`: refuses (log, return) when `pose->skeleton != state->skeleton`;
  TRS → `local_transforms` → `global_transforms` (the parent accumulation of
  `animation.c:924-932`) → `spring_bone_update` (`:936-940`, unchanged) → PASS 2. The two
  scratch arrays stay: springs consume them.
- `compute_bone_matrices` / `update_animation` become thin wrappers (sample → apply) for the
  identity phases, and are deleted with the `AnimationState` clock fields
  (`current_animation, current_time, speed, looping, playing`, `set_/play_/pause_/stop_/reset_/
  update_animation`) in the last phase — the only callers are apps/render and `gui.c`, both of
  which move to the `Animator`. `create_animation_state` → `calloc` (`debug_pose_dumped` and
  `prev_bone_rows` are uninitialised today); refuse `bone_count > MAX_BONES` at creation
  (`:943-946` writes past `bone_matrices` today).
- **Events on a clip**: `Animation` gains `AnimationEvent { float time_ticks; char* name; }
  events[]`; `animation_add_event(Animation*, float time_ticks, const char* name)`.

### 2. The `Animator` (`cetra/src/animator.h/.c`, new; add to `CETRA_PUBLIC_HEADERS`)

Owns its `AnimationState` (one writer of the once-per-frame prev-pose latch; the app reads
`animator->state` for `node_set_pose`, springs, the X-ray, `--check-stretch`). Fields under the
11.108 banners; the probes read the ENGINE-OWNED ones.

```c
typedef struct AnimatorEntry { const Animation* clip; float position; } AnimatorEntry;
Animator* create_animator(Skeleton*);            void free_animator(Animator*);
// Base layer. fade <= 0 is a hard cut (springs reset); a fade never resets springs.
void animator_play(Animator*, const Animation*, float fade_s, bool looping);        // replaces the source
void animator_play_space(Animator*, const char* name, const AnimatorEntry*, int n,
                         float fade_s, bool looping);                                 // 1..ANIMATOR_SPACE_MAX (4)
void animator_play_once(Animator*, const Animation*, float fade_s);                 // one-shot; at its end
                                                                                     // crossfades BACK to the
                                                                                     // source it replaced
void animator_stop(Animator*);
bool animator_finished(const Animator*);         // per-frame EDGE: true only on the frame a
                                                 // non-looping base clip ended (input's pressed())
// Override layer: one bone-masked clip over the base, its own fade in/out, auto-release at a
// one-shot's end. mask = bone_count floats.
void animator_play_layer(Animator*, const Animation*, const float* mask, float fade_in, float fade_out, bool looping);
void animator_stop_layer(Animator*, float fade_out);
bool animator_layer_finished(const Animator*);
int  animator_mask_subtree(const Skeleton*, const char* root_bone, float* mask); // 1 on the bone + subtree
// Timeline events: dispatched AFTER the pose is applied, so a handler may call animator_play.
typedef void (*AnimatorEventFn)(Animator*, const char* name, void* user);
void animator_set_event_callback(Animator*, AnimatorEventFn, void* user);
void animator_update(Animator*, float dt_seconds);   // exactly once per rendered frame
// SETTINGS (plain fields): bool playing; float speed; float param;   // param = the blend-space knob
```

- **Blend space**: entries sorted by position; weights piecewise-linear between the two
  neighbours, clamped at the ends (support ≤ 2 entries; a zero-weight entry is not sampled).
  ONE phase for all entries: the clock is kept in the TICKS of the lowest-indexed entry with
  weight (`ref`), other entries sampled at `phase × duration_i`, and the clock advances at
  `dt × tps_ref × speed × Σ w_i·(D_ref/D_i)`. With one entry the rate factor is exactly
  `1.0f`, so a 1-entry space executes the literal statements of `update_animation`
  (`animation.c:491-509`, `fmodf` wrap / clamp) — byte-identical by construction. When `ref`
  changes the time is rescaled by the duration ratio (the one documented rounding, never on an
  identity path).
- **Crossfade**: `animator_play*` with a fade keeps the previous source as `outgoing` (its
  clock still advancing) and ramps `fade_weight` 0→1 linearly in seconds; when
  `fade_elapsed >= fade_seconds` the outgoing is DROPPED that frame (not blended at 1), so the
  post-fade pose equals what the incoming source alone would produce having started at the
  switch frame — the invariant the crossfade gates assert. A `play` arriving mid-fade freezes
  the previous frame's blended base pose and fades from that (no pop, never more than two
  things sampled on the base layer). `animator_play_once` remembers the replaced source
  (clock paused) and re-plays it with the same fade when the one-shot ends.
- **Override layer**: phases OFF→IN→ON→OUT; weight ramps by `dt/fade`; a non-looping clip at
  its end goes OUT (holding its last key while fading, the interpolators clamp); at weight 0 it
  is OFF and `finished` latches until the next play. Per-bone weight = layer weight × mask.
- **Events**: crossed markers this frame on the base's highest-weighted entry only (ties →
  lowest index; the outgoing/frozen source fires nothing) and on the layer clip; a looping
  clip that wrapped fires `[prev, duration) ∪ [0, now)` once. Collected during the update,
  dispatched in clip-time order after `animation_state_apply_pose`.
- **Per-frame sequence** (`animator_update`): `animation_snapshot_prev_pose(state)` first and
  unconditionally (a paused pose reads zero deformation velocity, `animation.h:184-188`) →
  return if `!playing` or no source → advance base (and outgoing) clocks, fade, layer envelope
  → sample the base entries with weight, blend → blend the outgoing at `fade_weight` → sample
  and mask the layer → `animation_state_apply_pose(state, final, dt)` → dispatch events →
  latch the `finished` edges. The once-a-frame rule the latch carries is now one function.
- **Invariants a gate can assert bit-exactly**: (I1) a 1-entry space, no fade, no layer ⇒
  every `bone_matrices` byte equals the pre-refactor frame; (I2) after the fade, frame T of a
  run switched at K equals frame T−K of a run playing only the incoming clip; (I3) `param` at
  an entry's position ⇒ identical to that clip alone; (I4) the nlerp midpoint is analytic:
  blending identity with a 90° rotation at `t` gives `2·atan2(t·sin45°, (1−t)+t·cos45°)`
  (21.6° / 45° / 68.4° at .25/.5/.75 — three params so slerp's 22.5° is told apart); (I5) once
  the layer weight is 1, masked bones equal the layer clip's sample and unmasked bones' locals
  AND globals equal the base alone; (I6) a one-shot layer ends OFF, weight 0, `finished`, pose
  equal to the base alone; (I7) events: two per cycle from a walk at any param, none at idle,
  never doubled when two entries have weight.

### 3. Per-node pose (retire the global)

- `SceneNode` gains `struct AnimationState* pose` under BY FUNCTION (`node_set_pose`, borrowed;
  store + `scene_graph_touched()`); `create_node` (`scene.c:746`) zeroes it.
- `DrawItem` gains `const AnimationState* pose` — the nearest ancestor's `node->pose`, recorded
  only on a skinned item so unskinned props under two characters still batch. `append_node`
  (`draw_list.c:245`) carries the inherited pose down the recursion. `_refusal`
  (`draw_list.c:225`) refuses a skinned mesh whose `mesh->skeleton` is not the inherited pose's
  skeleton, by node name, once (today it uploads a foreign rig's matrices and draws garbage;
  `draw_list.c:361` only stops the bound). `draw_item_bounds` reads `item->pose`;
  `draw_run_key_equal` (`draw_list.c:407-409`) adds pose equality (never order).
- `render_update_skinning_uniforms(program, mesh, pose)` takes the item's pose at its three
  call sites (`render.c:714`, `render.c:1075`, `shadow.c:898`). Delete `g_current_animation_state`,
  `set_/get_render_animation_state` (`render.c:68-77`, `render.h:131-134`) and `CullView.pose`
  (`draw_list.h:160`, `render.c:79-88`). `occlusion.c` needs nothing.
- `gui.c:296-318` (the engine panel's Animation section, which reads the global) is deleted;
  apps/render draws its own Animation window (the `apps/tree` precedent) — the app owns the
  animator, so the app owns the panel.
- `rigging.c:16`: `normalize_bone_name` also strips `cetra_rig:`.

### 5. The puppet (`assets/gen_puppet_fixture.py` → `assets/puppet.gltf` + `puppet.cscn`)

Template `assets/gen_skinned_cull_fixture.py` (stdlib only, byte-deterministic for
`fixture-gen`). Y up, faces +Z, T-pose rest with identity local rotations (pure translation
offsets), feet at y = 0, symmetric in x/z (the render app's recenter is a no-op — asserted).
Twenty bones on the names `strut_walk.fbx` carries — `cetra_rig:` Hips, Spine, Spine1, Spine2,
Neck, Head, Left/Right Shoulder/Arm/ForeArm/Hand, Left/Right UpLeg/Leg/Foot — each driving one
rigid box (all vertices weight that bone at 1.0), ~1.8 m tall; skin joints listed parent-first
(that order IS the skeleton's, `import.c:987-1007`). Embedded clips (LINEAR samplers, keys every
T/8, **every animated joint also carries a translation track holding its bind offset**):

| clip | length | loop | content |
|---|---|---|---|
| `idle` (index 0) | 2.0 s | yes | Spine2 ±3° X, Head ±2° X, Hips y ±0.01 |
| `walk` | 1.0 s | yes | UpLegs ±30° X opposite phase, Arms ∓20° Y counter-swing; **cos phase** so t = 0 / 0.5 s are the extremes |
| `run` | 0.5 s | yes | same shape, ±50° / ±35° |
| `jump` | 1.0 s | no | legs tuck by 0.2 s, hold to 0.7, back to bind at 1.0 |
| `wave` | 1.0 s | no | RightArm raised (−80° Z), RightForeArm ±25° Z alternating; ends on bind |
| `hold90` | 4.0 s | no | LeftForeArm 0 → +90° Z over 0.25 s then HELD (last key at 4.0 s) |
| `rest` | 4.0 s | no | the bind as a clip (one identity channel) — the other endpoint for the midpoint arm |

Generator asserts: every joint weights ≥ 1 vertex; bbox min y == 0, centre x == z == 0;
parent-first; every rotation channel has a translation sampler; the 20 prefixed names; the
loops read their amplitude at 0.5 s; hold90's last key ≥ 4.0 s; every box face's normal points
outward (the `shadow_lag` winding trap). Docstring records the HOLD-not-end trap
(`skinned_cull`'s lesson), the read frame (30 = 0.5 s), the cos phase, why translation tracks
are authored, and that `anim-clip-loads` is what notices if assimp stops keeping the colon.
`.cscn`: camera eye (0, 0.95, 4.2) → (0, 0.95, 0) fov 45, one directional light on the +Z face,
exposure pinned (`tonemap neutral, exposure 1, auto_exposure false, bloom off`).

### 6. The `ANIMATOR` component (`cetra/src/game/animator_component.c/.h`, new)

The 12.0 shape (`audio.c:291-318`): a private payload `{ Animator* animator; SceneNode* node; }`;
`entity_add_animator(entity, Animator*)` takes ownership, binds `node_set_pose(entity->node,
animator->state)` when a node is set; `entity_get_animator`; a static free that clears the
node's pose (the node outlives the component: `free_game` frees the entity manager first,
`game.c:54-58`, the scene last); `update_all_animators(em, dt)` over
`entity_manager_foreach_with(COMPONENT_BIT(COMPONENT_ANIMATOR))`.

`game_pre_render` (`game.c:268-291`) calls it after the app's `on_pre_render` and before audio,
with `(float)game->sim_clock.delta` — once per RENDERED frame, never per fixed step (two steps
in a frame would latch prev twice; a 0-step frame would never latch). A paused sim or a 0-step
frame passes 0: the pose holds and reads zero deformation velocity. `component.h:12` comment
names the header.

### 7. gametest

  gametest's scene (a material belongs to the scene that registered it, `draw_list.c:225-241`,

- **Attach**: the entity's node is a HOLDER `sync_entity_transforms` owns; the rig is its
  CHILD carrying the −1 m drop (capsule centre → feet) and the facing yaw, because
  `entity.c:276` overwrites the entity node's local every step and Jolt overwrites
  `entity->rotation` (`character.c:459`). Yaw = smoothed `atan2(vel.x, vel.z)` when moving,
  written to the child's `original_transform` in `on_update` (sim-time, deterministic).
- **Locomotion**: space `{idle@0, walk@0.5, run@1}`; each step `param = min(|vel.xz| /
  PLAYER_SPEED, 1)` from the controller's POST-SOLVE velocity (`gametest.c:517`, before the input
  overwrite) so walking into a wall stops the walk. Jump → `animator_play_once(jump, 0.25)`
  (airtime is 1.0 s with v = 10, g = 20; the clip returns to the space by itself). New action
  `wave` (E / left bumper, script name `lb`) → `animator_play_layer(wave, mask(RightArm), 0.1,
  0.1, false)`. Footsteps: `animation_add_event(walk, 0, "step_l")`, `(walk, half, "step_r")`,
  same on `run`; the callback plays a short tone through 12.0's audio (`--mute` silences it).
- **Flags**: `--no-puppet`, `--puppet <path>`, `--twin <clip>` (a second entity at (−6, 1, 0),
  no controller, its own Animator looping `<clip>`, a second node tree over the same meshes via
  `mesh_ref` — verify `mesh.h:366`), `--anim-probe <case>`.
- **Trace**: APPEND after `jump %d` (the gamepad regex is anchored on it): `anim <param>
  <w_idle> <w_walk> <w_run> <fade> <layer> <src>`; `src` = the base source's name
  (`locomotion` | `jump`).
- **`--anim-probe <case>`** (`run_audio_probe`'s shape, `gametest.c:653-754`; dispatched before
  the window; headless `create_game` + the puppet scene + an entity manager; every step through
  `update_all_animators(em, 1/60)`; lines `anim <case> <label> <key> <numbers…>` `%.6f`):

| case | prints | defeats |
|---|---|---|
| `locomotion` | weights for param 0, .25, .5, .75, 1, 1.5, −.5 | unnormalised, wrong neighbour pair, unclamped |
| `crossfade` | fade at t0 / F/2 / F / F+1 tick, `settled`, and `pose maxdiff` vs a fresh animator playing the clip from the switch frame with fade 0 | snap, never settles, outgoing still weighted, incoming clock started at fade END |

| `events` | the fired names and ticks over 2 s at param 0, .5, 1, and at idle | none, doubled at .5, fired at idle, missed on wrap |
| `import` | `load_animations_from_file(scene, skel, "assets/strut_walk.fbx", false, NULL)` → `matched`, `channels`, `seconds` | a name drifting in the generator, the exact-match path broken |
