# Tier 3 · 4.10.1 — KHR_materials_specular + KHR_materials_sheen (activating the reserved slots)

## Context

The engine reserved two material slots — `sheenTex` (unit 8) and `reflectanceTex` (unit 9) — and
wired their full CPU plumbing (Material `Texture*` + setter, reserved `TEXUNIT_*`, Assimp texture
import, render.c bind + upload, shader uniform declarations) but **never implemented the shading**:
the `sheenTex`/`reflectanceTex` samplers are declared-and-dead (never read → the GLSL compiler drops
them). A prior, non-physical implementation survives only in `pbr_frag.glsl.old` (not compiled). So
these are genuine gaps, not half-done work — and the just-shipped 4.10 clearcoat lobe + the
`sampler2DArray` mask foundation give us the exact pattern and the free headroom to finish them.

We implement **both** glTF material extensions, activating the reserved slots:

- **KHR_materials_specular** — re-parameterizes the *existing* dielectric BRDF: `specularColorFactor`
  (vec3) tints F0, `specularFactor` (float) weights the dielectric specular. **Not a new lobe** — it
  modulates F0 at the single point `pbr_frag.glsl:743-744`. Small, but it touches the byte-identity-
  sensitive F0 expression (feeds F / energyComp / kD / IBL), so it validates our F0-guard approach.
- **KHR_materials_sheen** — a **new retroreflective cloth lobe** (velvet/satin): a Charlie NDF +
  Ashikhmin visibility term added over the base, `sheenColorFactor` (vec3) + `sheenRoughnessFactor`
  (float). The bigger, visually distinctive payoff; mirrors the clearcoat lobe's structure exactly.

**Zero new samplers:** sheen-color and specular-color textures ride the reserved units 8/9; the two
scalars (sheen roughness, specular factor) become new `maskArray` layers on unit 2.

## Design decisions

- **Specular = F0 re-parameterization, guarded for byte-identity.** In `pbr_frag.glsl` at 743-744,
  wrap the F0 build so the *default* path is the pre-existing expression:
  ```glsl
  vec3 F0 = vec3(iorF0);
  if (specularEnabled > 0 && specularFactor >= 0.0) {      // sentinel gate (see below)
      F0 = min(F0 * specularColorFactor * specColorTex, vec3(1.0));
  }
  F0 = mix(F0, albedoMap, metallicMap);
  ```
  The dielectric specular term (base `:849` and IBL `:958`) is scaled by `specularFactor * specTex.a`.
  **Byte-identity mechanism:** `Material.specular_factor` defaults to a **-1 sentinel** ("extension
  absent"); the importer sets a real value (glTF default 1.0) only when KHR_materials_specular is
  present. Assets without the extension (c64, raiden) → `specularFactor < 0` → the original
  `vec3(iorF0)` expression compiles unchanged → `cmp`-exact. This is the clearcoat `clearcoat > 0`
  gate applied to a modulation.
- **Sheen = additive Charlie lobe, gated on `sheenColor > 0`.** `sheenColorFactor` defaults to
  **(0,0,0)** → the natural "no sheen" gate `if (sheenEnabled > 0 && max3(sheenColor) > 0.0)` → lobe
  skipped for non-sheen assets → byte-identical, exactly like clearcoat's factor-0 skip. New helpers
  `distributionCharlie(NdotH, ccR)` + `visibilityAshikhmin(NdotL, NdotV)` sit next to
  `distributionGGX` (`:258`). Lobe: `sheenSpec = sheenColor * Dcharlie * Vash` (no Fresnel, per
  glTF), folded into the same accumulate line as the coat (`:908`); base attenuated by
  `albedoSheenScaling = 1.0 - max3(sheenColor)` (an analytic directional-albedo approximation — a
  **baked Charlie E-LUT is the documented follow-up**, deferred to keep the zero-new-sampler
  property). IBL sheen reuses `prefilteredMap` at sheen roughness (no new sampler), same
  attenuation.
- **Two new mask-array layers.** `sheen_roughness` and `specular_factor` are single-channel scalars
  → new `maskArray` layers (unit 2). **`MASKS_PER_MATERIAL` MUST bump 7 → 9** in `mask_array.c:59`
  (it sizes the dedup scratch buffer; `mask_layer_for` writes without bounds-growth, so a stale 7
  heap-overflows once every material carries the 8th/9th mask). Add `sheen_roughness_layer` /
  `specular_factor_layer` to Material, the two `mask_layer_for` lines, the two `*Layer` uniforms +
  gated shader reads — the exact recipe the mask foundation already uses ×7.
- **Color textures ride the reserved units, as sRGB.** sheen-color → `sheenTex` (unit 8),
  specular-color → `reflectanceTex` (unit 9). Both are **sRGB** per glTF (the current import table
  loads them linear — fix the sRGB flag). Keep the existing field/uniform names to minimize churn;
  they simply become live.
- **Assimp import, verified then wired (fallback = bespoke).** Assimp 6.0.5 exposes
  `AI_MATKEY_SHEEN_COLOR_FACTOR`, `AI_MATKEY_SHEEN_ROUGHNESS_FACTOR`, `AI_MATKEY_SPECULAR_FACTOR`,
  and specular color via the legacy-shared `AI_MATKEY_COLOR_SPECULAR` (`$clr.specular`, must be
  glTF-guarded like the transmission/IOR block so FBX/OBJ don't pick up a Phong specular). The
  scalar factors go in the shared `extract_material_properties` (`import.c:119`, both sync + async
  get them free). The **sheen roughness texture is at `aiTextureType_SHEEN` index 1** — unreachable
  by the index-0 mapping table, so it needs a **bespoke read** in both paths, mirroring clearcoat's
  `aiTextureType_CLEARCOAT` index-2 template (`import.c:356-367` / `:467-472`). Because the 6.0.5
  glTF2 importer `.cpp` isn't on disk to inspect, S1/H1 begin by **runtime-verifying** the keys
  populate on a real asset (dump material keys); if a sub-property isn't surfaced, fall back to a
  direct glTF-extension read.
- **Kill-switch / plumbing mirrors clearcoat exactly** — the 7-point spine per feature:
  `specular_enabled` / `sheen_enabled` engine field (default true) + `--no-specular` / `--no-sheen`
  app triple + `specularEnabled` / `sheenEnabled` uniform + guarded shader block + GUI checkbox
  (next to "Clearcoat"). Per-material values are asset-driven (global toggles only, like clearcoat —
  no per-material GUI sliders).

## Milestones (branch `materials-sheen-specular`, `git commit -S -v`)

### Phase S — KHR_materials_specular (F0 + specular-color modulation; the byte-identity-sensitive one first)

**S1 — Data + import + plumbing (inert; byte-identical).** Material: `float specular_factor` (default
**-1** sentinel), `vec3 specular_color_factor` (default (1,1,1)), `int specular_factor_layer`
(default -1); `reflectance_tex` becomes the specular-color slot (flip its import sRGB flag).
Import (`extract_material_properties`): `AI_MATKEY_SPECULAR_FACTOR` + glTF-guarded
`AI_MATKEY_COLOR_SPECULAR`, setting `specular_factor` to 1.0 when only color is present; **first
verify** the keys populate on a known specular asset, wire the specular-color texture from the
correct Assimp source (empirical), add the optional `specularTexture.a` strength as
`specular_factor_layer` (mask). `MASKS_PER_MATERIAL` → 8. render.c upload; `specular_enabled` global
+ `--no-specular` app triple + GUI checkbox. Shader declares the uniforms, no math yet.
*Gates:* c64 + raiden `cmp`-exact; `--no-specular` parses.

**S2 — The shader modulation.** F0 guard (above) + scale base/IBL dielectric specular by
`specularFactor * specTex.a`. Keep the guarded block's float grouping so the off-path is unchanged
(clearcoat B3 reassociation lesson).
*Gates:* c64 + raiden `cmp`-exact (sentinel skip); `--no-specular` `cmp`-exact; determinism ×2;
visual A/B on a specular fixture — colored/weighted dielectric specular (e.g. a gold-tinted
specular on a white plastic), grazing behavior sane, no over-bright.

### Phase H — KHR_materials_sheen (the Charlie cloth lobe)

**H1 — Data + mask layer + import + plumbing (inert; byte-identical).** Material: `vec3
sheen_color_factor` (default (0,0,0)), `float sheen_roughness_factor` (default 0), `int
sheen_roughness_layer` (default -1); `sheen_tex` becomes the sheen-color slot (sRGB). Import:
`AI_MATKEY_SHEEN_COLOR_FACTOR` + `AI_MATKEY_SHEEN_ROUGHNESS_FACTOR` in `extract_material_properties`
(verify first) + **bespoke `aiTextureType_SHEEN` index-1** sheen-roughness read in both sync + async
paths (clearcoat index-2 template). `MASKS_PER_MATERIAL` → 9. render.c upload; `sheen_enabled`
global + `--no-sheen` app triple + GUI checkbox. Shader declares uniforms + reads sheenColor /
sheenRoughness, no lobe yet.
*Gates:* c64 + raiden `cmp`-exact (sheenColor 0); `--no-sheen` parses.

**H2 — The sheen BRDF (analytic + IBL).** New `distributionCharlie` + `visibilityAshikhmin` helpers
by `:258`. Guarded `if (sheenEnabled > 0 && max3(sheenColor) > 0.0)`: analytic `sheenSpec =
sheenColor * Dcharlie(NdotH, ccR) * Vash(NdotL, NdotV)` folded into the accumulate at `:908` with
base scaled by `albedoSheenScaling = 1 - max3(sheenColor)`; IBL sheen reuses `prefilteredMap` at
sheen roughness with the same scaling (no new sampler). Firefly-clamp with the existing `min(...,
10.0)`.
*Gates:* c64 + raiden `cmp`-exact (sheen off / color 0 / `--no-sheen`); determinism ×2; visual A/B
on the cloth fixture — retroreflective grazing rim (velvet), soft sheen sweep, energy sane (base
dims under strong sheen, no over-bright).

**H3 — Cloth test asset.** `gen_sheen_fixture.py` (clearcoat-fixture pattern): velvet + satin
spheres with varying sheenColor / sheenRoughness (and a no-sheen A/B sphere) under an HDR env.
*Gates:* byte-identical off; visual weave/rim; determinism.

## Budgets & risks

- **Zero new samplers** (units 8/9 already reserved+bound; scalars → mask layers). Uniform
  components ~+12 / 4096 — negligible.
- **`MASKS_PER_MATERIAL` bump is load-bearing** — forgetting it heap-overflows the dedup buffer once
  a material carries the 8th/9th mask. Bump to 9 in one place (`mask_array.c:59`).
- **Byte-identity, the sensitive part:** specular modifies F0 (feeds F / energyComp / kD / IBL). The
  **-1 sentinel guard** keeps the exact `vec3(iorF0)` expression for non-specular assets → `cmp`
  gate. Sheen is additive/guarded on `sheenColor>0` like clearcoat. Preserve float grouping in both
  guarded blocks (the clearcoat B3 compiler-reassociation lesson); if `cmp` fails with 0-visible-
  pixel RMSE, it's reassociation — match the original grouping.
- **Assimp import uncertainty** (6.0.5 importer `.cpp` not inspectable): S1/H1 runtime-verify the
  keys populate before wiring; fallback is a bespoke glTF-extension read. Sheen-roughness texture at
  `aiTextureType_SHEEN` index 1 needs a bespoke read regardless.
- **sRGB:** the two color textures are sRGB — flip the import flag (currently linear).
- **Sheen energy:** analytic `albedoSheenScaling` is approximate (no Charlie E-LUT) — a documented
  v1 limitation; the baked LUT (a free unit: 4/7/15) is the future-correct refinement.
- Refs: glTF KHR_materials_sheen / _specular; Estevez-Kulla "Production Friendly Microfacet Sheen"
  (Charlie); Ashikhmin-Premoze sheen visibility; Filament sheen/specular; glTF Sample Viewer.
