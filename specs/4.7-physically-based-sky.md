# Tier 2 · 4.7 — Physically-Based Sky & Atmosphere (Hillaire)

## Context

The engine lights exclusively from photographic HDRIs (`-e`): static sky, fixed lighting.
§4.7 adds a procedural physically-based sky (Hillaire EGSR 2020 — transmittance +
multiple-scattering + sky-view LUTs as fullscreen raster passes, GL 4.1, no compute) with a
movable sun that drives the skybox, IBL, key light, shadows, catcher, fog, and probe/SSR
coherently. Exploration verified the integration is almost free: only `load_hdr_environment`
(ibl.c:267) is file-bound — a procedural sky renders the env cubemap directly and the entire
downstream pipeline (irradiance/prefilter/skybox/ground/probe/SSR/fog publish) consumes it
unchanged. **Aerial perspective was DEFERRED** (user-approved): invisible at studio/prop scene
scales (<0.1% extinction over 100 m), and `--fog` already provides sun-driven depth haze;
the follow-up shape (units→km app knob + transmittance-LUT term in fog_frag) gets documented.
**Shipped in spec 9.6**, once a world-scale scene existed to make it visible — the predicted
units→km knob is `world_units_per_km`, and the LUT term became a 32³ volume folded into the fog
composite (the `fog_frag` this note names was retired by 9.5).

## Design (validated by exploration + design pass)

- **Sky→IBL: direct-to-cubemap, no equirect intermediate.** Six-face raster passes sample
  the sky-view LUT into a **256² env cubemap** (+`glGenerateMipmap`); then the EXISTING
  chain: irradiance 32² (mip level parameterized: `log2(env_size/64)`, currently hardcoded
  at ibl.c:407), `ibl_prefilter_cubemap` at **256²/7 mips** for sky mode,
  `ibl->max_reflection_lod = 6.0` (uniform-driven — zero pbr_frag changes), BRDF LUT reused.
- **Sun disc: analytic in the background shader only, NEVER in the env cube** — a 0.53° disc
  is ~3 texels at 256² (aliased), fireflies the prefilter, and would double-count energy the
  key light already carries. Trade-off documented: IBL mirror reflections show no disc (the
  key light's specular highlight covers it).
- **LUTs** (cloned from the `render_brdf_lut` local-FBO template, ibl.c:493-522, `post_vert`):
  - Transmittance 256×64 RGBA16F, Bruneton (μ,r) mapping, km units — baked ONCE.
  - Multi-scatter Ψms 32×32 RGBA16F (64 sphere dirs × 20 steps in-shader) — baked ONCE.
  - Sky-view 192×108 RGBA16F, sun-relative azimuth × sqrt-horizon-warped latitude — PER SUN
    MOVE. Fixed virtual eye altitude (~1 m); radiance pre-scaled for 16F safety.
- **Sun ↔ key light**: app populates `ibl->light_dirs[0]=dir_toward_sun`,
  `light_energies[0]=1`, `light_count=1` → the existing key-light block
  (apps/render/src/render.c:1203-1240) creates ONE shadow-casting directional light
  (intensity 10), catcher on, fog lightDir/lightColor auto-published (shadow.c:642).
  Key-light COLOR = CPU transmittance eval (~40-step integral in sky.c, no readback), fades
  out below −0.6° elevation. PCSS light_size: tan(0.53°)×8r ≈ 0.075r ≈ the existing 0.08r
  app default — no change, comment the coincidence.
- **Dynamic sun (GUI): split re-bake.** Live per-changed-frame: sky-view LUT + env cube +
  mipgen + irradiance (all cheap). On slider release (`igIsItemDeactivatedAfterEdit`):
  prefilter + probe env-only re-prefilter (probe.c:63-84, leak-free) + key-light retint.
  Specular briefly stale while dragging; diffuse/background track live.
- **Flags**: `--sky` kill switch (default off ⇒ byte-identity structural); `-e` + `--sky`
  = hard error; `--sun-elevation <deg>` (default 35), `--sun-azimuth <deg>` (default 135),
  `--sky-debug` (blit LUTs to screen corners). GUI: "Sky" sub-group in the Environment
  header (engine.c:1225): elevation/azimuth sliders + disc size.
- **Ground projection: forced OFF in sky mode** (app policy) — the dome remap would smear
  horizon haze radially across the floor; instead sky_env/background shade below-horizon
  rays as a Lambertian virtual ground (albedo ~0.3, sun-lit), so the catcher still grounds.
- **Module: new `cetra/src/sky.c/h`** (probe.c is the sibling-module precedent; consumes the
  public ibl toolkit). `Scene` gains `SkyAtmosphere* sky` (pattern: `scene->probe`).
  Atmosphere params: Earth defaults in sky.h (Rg 6360/Rt 6460 km, Rayleigh
  (5.802,13.558,33.1)e-3/km H=8, Mie 3.996e-3 g=0.8 H=1.2, ozone tent 25±15 km).

## Milestones (branch `sky`, `git commit -S -v`)

**M0 — bridge: ibl.c re-bake hygiene + shared bake path.** Delete-before-gen for
`environment_cubemap`/`irradiance_map`/`brdf_lut`; extract public
`ibl_bake_from_cubemap(ibl, engine, env_size, prefilter_size, prefilter_mips)` (assumes
env cube populated+mipped; runs irradiance with parameterized mip, prefilter, BRDF-if-absent,
full state save/restore); `precompute_ibl` = equirect→2048→`ibl_bake_from_cubemap(2048,1024,9)`.
*Gates:* `-e` headless byte-identical to master (c64 + raiden); double-precompute leak check;
no GL errors.

**M1 — static LUTs + module skeleton.** sky.c/h; sky_transmittance_frag / sky_multiscatter_frag;
program registration (program.c + engine.c:946-970); scene.c/h `sky` field; app `--sky` /
`--sky-debug` parse + `-e` conflict error + LUT bake + timing logs.
*Gates:* no `--sky` byte-identical; LUT debug visuals (white zenith → orange → deep red at
grazing; MS smooth); determinism ×2.

**M2 — sky-view LUT, background pass, IBL population (the big one).** sky_view_frag,
sky_env_frag (cube faces, virtual ground, no disc), sky_background_frag (skybox_vert;
analytic limb-darkened disc × transmittance, radiance clamp <30000); `sky_bake()` =
sky-view → env 256² → mipgen → `ibl_bake_from_cubemap(256,256,7)` + max_reflection_lod 6;
`sky_render_background()`; cetra/src/render.c:642-653 sibling branch ahead of
`render_skybox`; app sibling branch of the `args.hdr_path` block (IBLResources without HDR,
sky_bake, light_dirs[0], render_skybox=true, ground projection off — key-light/catcher/
probe/fog code below runs unchanged).
*Gates:* byte-identity off; determinism ×2 on; visual checklist — horizon gradient (no
lat-long seam), ~0.53° crisp disc, sunset palette at 2–10°, below-horizon night (no NaN
speckle), IBL coherence (model tint matches sky; chrome ball reflects the gradient),
catcher shadow on virtual ground, glass/refraction sees the sky.

**M3 — sun ↔ key light + CLI sun.** `sky_sun_transmittance()` CPU eval; `--sun-elevation`/
`--sun-azimuth`; key-light color/intensity from transmittance + below-horizon fade.
*Gates:* byte off; elevation sweep strip {60,30,10,2,−4}° — shadow direction/tint track the
disc; `--fog` shafts inherit sun color automatically; `--no-key-light` sanity.

**M4 — dynamic sun GUI.** Sky group sliders; live cheap re-bake on change; prefilter +
probe env-only recapture + retint on release; `sky_update_sun()` split entry;
`--probe-scene` capture: skip recapture with a log note.
*Gates:* byte off; drag smoke (no hitch >1 frame at release, logged timings); 100-rebake
leak gate; headless equivalence (flag-set vs programmatic sun ⇒ identical PPM).

**M5 — review.** /thermo-nuclear + /simplify fanout (ALL run_in_background), apply, re-gate;
roadmap §4.7 shipped-shape (incl. AP deferral rationale + world-scale follow-up + no-disc
trade-off); memory notes. User merges on explicit request.

## Budgets & risks

- Budgets: sky shaders ≤2 samplers / ~50 uniform components each; pbr_frag/skybox_frag/
  postfx ZERO changes (sky IBL rides units 14-17 via bind_ibl_textures).
- Risks: 16F horizon precision (Bruneton mapping + km units); prefilter fireflies
  (structural: no disc in env cube); double-counted sun (sun-direct only in key light —
  same split as the HDRI path); lat-long horizon seam (Hillaire split mapping +
  clamp-to-edge); M0 refactor vs `-e` byte gate (it's the bridge's only job — land and
  verify first); prefilter hitch on release (measured in M4; fallback 128²/6 mips).
- Refs: Hillaire EGSR 2020; Bruneton 2008/2017 (transmittance UV); UE SkyAtmosphere
  (disc-outside-LUT convention, limb darkening).
