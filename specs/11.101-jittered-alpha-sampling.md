# Spec 11.101 — Jittered alpha sampling (the TAA-path flicker lift)

## Context

Spec 11.100's alpha distribution keeps distant cutouts alive as a binary dither on deep mip
levels — and on the LIVE TAA path that dither flickers, measured on the alphacov fixture at the
user's session framing: **31,264 pixels flipping by >8 codes between consecutive frames (mean
amplitude ~9) in the rows sampling the distributed mips, against 107 in the near field** (the
pre-existing content, stable). TAA's camera jitter re-samples a subpixel 0/255 lattice differently
every frame and the clamp cannot settle beyond-Nyquist content; before 11.100 those rows were
empty, and empty doesn't flicker. SSR is inert on the scene (220 px) — toggling it just resets the
temporal history. Every gate and golden runs the jitter-free path, so no instrument saw it; 11.100
records it as its known live-path ceiling.

The fix is Yuksel 2018 §6's own remedy with an argument the paper lacks: **offset the masked-alpha
UV by a per-pixel-per-frame hashed sub-texel amount at the distributed mips, only while TAA is
accumulating** — the dither decorrelates from the pixel lattice and TAA's accumulator integrates
the noise toward true fractional coverage: smooth AND temporally stable. Shadow pass and captures
stay unjittered (nothing there averages the noise).

## The design (settled; the load-bearing choices)

1. **"Where is the dither" is SCANNED from the final level stack, not plumbed from the derive.**
   `texture_scan_binary_alpha_from(stack, channels)`: first level ≥ 1 whose alpha is everywhere
   exactly 0 or 255 **with both present** (binary AND mixed — excludes degenerate solid levels), or
   −1. Runs once at publish in `texture_upload_image` on BOTH cook paths (hit adopts raw level
   bytes at texture.c:967 before upload; miss's stack is raw for `TEXTURE_BLOCK_NONE`), guarded by
   `texture_wants_coverage(channels, desc) && block == TEXTURE_BLOCK_NONE && channels == 4`.
   This detects the CONDITION (a binary lattice the shader will sample) rather than the mechanism,
   is identical on hit and miss, honest under the derive's OOM un-latch, needs **no meta section,
   no recipe bump, no cook change at all**. DXT5 (`--texture-compress-colour`, opt-in) defeats the
   scan → jitter stays off there, consistent with its documented coverage caveat (texture.c:429).
   False positive (a naturally binary-and-mixed level 1+ on a coverage chain) is benign — same
   smoothing — and recorded.
2. **Carrier**: out-param `int* out_distribute_level` on `texture_upload_image` (precedent:
   `out_internal_format`) → `texture_pool_publish` (sole caller) → new `int distribute_from_level
   // -1 = none` on `Texture` beside `mean_rgb/mean_valid`. Accessor
   `texture_distribute_from_level(const Texture*)` (NULL → −1) beside `texture_normal_gate` —
   the one-function-two-callers rule. **`create_texture` initializes it — and fixes the real
   pre-existing hole in passing: `mean_valid`/`mean_rgb` are malloc-garbage today**, so
   `texture_mean_color` can return uninitialized bytes as a valid mean.
3. **Uniforms**: per-material `distributeFromLod` (float) set UNCONDITIONALLY beside
   `albedoTexExists` (render.c:368; the reset-or-it-leaks rule). Engine-derived pair in
   `_submit_item`'s per-program block beside the capturing-gated precedents (render.c:486):
   `alphaJitter = engine->taa_jitter_this_frame && engine->alpha_jitter_enabled &&
   !engine->capturing`, plus `alphaJitterFrame = total_frames % 4096` (frozen at 0 when off — the
   pcss idiom). New Engine field `taa_jitter_this_frame` assigned from the SAME `taa_jitter_live`
   local that feeds the pcss stash (render.c:1403) — one predicate, two consumers.
   **Do NOT reuse `pcssStochastic`/`pcssFrameIndex`** — they upload below shadow.c's
   `if (!directional_on) return;` and are stale in no-directional scenes.
   `--no-alpha-jitter` on the render app (engine default true, not snapshotted — a diagnostic):
   the permanent falsification lever.
4. **The shader** (pbr_frag.glsl, the else arm at :1146; declarations beside `alphaMasked` :72-80):
   gate `alphaMasked > 0 && alphaJitter == 1 && distributeFromLod >= 0.0` (dynamically uniform, so
   the off arm stays THE EXACT CURRENT CODE — every TAA-off frame byte-identical by construction).
   Inside: analytic LOD from derivatives (`textureQueryLod` is GLSL 400; we are `#version 330`) —
   `tx = dFdx(uv)*textureSize`, `lod = 0.5*log2(max(dot(tx,tx), dot(ty,ty)))` (the GL 3.3
   reference lambda itself). Jitter when `lod > distributeFromLod - 1.0` — **one whole level of
   margin, because trilinear starts blending level N at lambda N−1**, so that is when distributed
   bytes first reach the pixel; firing early is benign (the offset self-scales by `exp2(lod)`, so
   on a still-smooth finer level it is sub-texel there too). Offset:
   `(vec2(ign(fc), ign(fc.yx)) - 0.5) * exp2(min(lod, top_level)) / textureSize` with
   `fc = gl_FragCoord.xy + alphaJitterFrame * 5.588238` — the exact pcssStochastic shape already
   in this file (ign is the screen-space hash; TAA is what averages it). The clamp stops extreme
   minification wrapping the offset under REPEAT.
   **The jittered fetch is `textureGrad(albedoTex, uv + off, dux, duy)` with the UNJITTERED
   derivatives** — an offset through implicit derivatives corrupts LOD selection by up to a level
   per quad and defeats the gate's own premise; `stochastic.glsl:157-159` is the in-tree precedent
   (jittered coordinates, honest grads).
   **Prepass consistency**: masked geometry draws the depth prepass through this same shader with
   the same jittered projection, same uniforms, same `gl_FragCoord` — the jitter is a pure
   function of state identical in both passes, so the coverage resolve (:1176, above the prepass
   return :1269) reaches the same discard in both and GL_LEQUAL deletes nothing.
   No `PBR_FEAT` bit: a runtime branch is ~free (11.93's rule), and "TAA on this frame" is not a
   material/scene fact the resolver can answer.
5. **Reachability facts** (stated in the spec): the layered arm never sets `texAlpha`; the
   stochastic arm drops alpha; the untextured-masked path (mask_fixture, vertex alpha) never
   reaches the fetch (`albedoTexExists == 0`). Shadow (`shadow_depth_frag`, own shader) and
   captures (`!capturing`) untouched.

## Risks, with mitigations

- **Analytic LOD vs GL's lambda**: the formula IS the GL 3.3 reference lambda; implementation
  latitude is sub-level and the whole-level gate margin covers it.
- **Anisotropy**: GL's aniso samples finer than the max-axis estimate — the gate errs EARLY
  (benign, self-scaled), never late. The 11.100 grazing-anisotropy deletion remains the
  technique's ceiling; the jitter does not change it, and the spec says so.
- **textureGrad ulp drift** in the near field of jittered frames (the whole material's fetch
  switches instruction on the on-arm — per-fragment selection is illegal under derivative rules):
  not byte-compared anywhere; the near-field flip-count control bounds it.
- **DXT5**: scan refused → jitter off → flicker remains there; recorded beside the existing
  coverage caveat, not fixed.

## In-flight corrections (phase 3's measurement, 2026-09-02)

**The temporal half of this spec's premise is REFUTED, and the seven-agent-style claim audit that
followed found the spec still telling the predicted story.** This section is the record; the plan
text above is left as written, per the house rule that a committed spec takes corrections.

**What measurement said.** The Context's "TAA's accumulator integrates the noise toward true
fractional coverage: smooth AND temporally stable", the movement table's "TAA converges", and
phase 3's success criterion ("collapses from ~31k toward the jitter-free ~104") did not happen.
At MSAA 1 the alpha test is a binary step -- every frame each pixel lands fully on or off -- and
an exponentially weighted history fed a varying binary input holds residual variance whatever the
input sequence. Mid-band strong flips at the user's framing: **31,264 baseline -> 38,456 with the
white-noise offset -> 37,533 with the R2-stratified offset**. The ~1/n stratification argument
assumed a box average; TAA is an EMA, which defeats equidistribution. The in-tree Wyman-McGuire
digest had already recorded this exact failure mode -- "Since TAA effectively averages via an
exponentially weighted moving average ... this introduces temporal flicker", and plain temporal
stratification "gives spatial stability but temporally flickers" -- the refutation was on the
shelf, uncited by this plan.

**What the fix DELIVERS, verified on same-frame crops.** The spatial Moire is eliminated: the
crawling comb-teeth interference bands and beat clumps that 11.100's lattice renders under the
jitter ring dissolve into an even halftone at the correct density, in every frame. The churn's
CHARACTER changes from coherent band-crawl to decorrelated fine grain at the same amplitude
(~9 codes mean). That is Yuksel's own scoping vindicated: he used the jitter for Moire (his
Fig. 8) and nothing more; the TAA-averaging extension was this spec's added argument, tested, and
refuted. The near-field control read exactly 107 in every variant -- the gate, the plumbing and
the instrument all behaved; the physics refused.

**As-built deviations from the design section.** The offset is NOT decision 4's
`ign(fc + frame * 5.588238)` white-noise shape (the pcssStochastic arrangement): that variant
measured 38,456 and was replaced by a static per-pixel ign anchor translated by the R2 sequence
`fract(anchor + frame * (0.7548777, 0.5698403))`, whose surviving justification is SPATIAL -- a
uniform translation preserves ign's screen-space structure every frame, where hashing the frame
into the coordinate makes each frame's field white. And the Context's claim that "11.100 records
it as its known live-path ceiling" was aspirational when written -- no document recorded the
TAA-path flicker before this branch; phase 5's edit is what creates that record.

**Phase 4 must be redesigned before it is built.** The alphacov-churn arm as specified asserts
the flip-count collapse that does not happen -- built as written it either fails forever on a
working feature or gets tuned into asserting nothing. The metric the fix actually moves is the
flip mask's SPATIAL STRUCTURE (band coherence), not its count: the redesign should measure that
-- e.g. the variance of column sums over the mid band, which the comb-teeth bands inflate and the
even grain collapses -- with `--no-alpha-jitter` as the falsifier, and record here what was
chosen and why the count metric was retired (it measures churn energy, which the fix transforms
rather than reduces; the same instrument-vs-claim trap as 11.58's identity arm and 11.100's
bright-pixel count, caught this time by asking what the feature had actually done).

**The title's framing** ("the TAA-path flicker lift") names the refuted deliverable and stays as
the historical name; read it as "the TAA-path Moire lift".

## The ladder, and the verdict (2026-09-02)

Every measurement before this section was taken on the grazing dot plane, and every conclusion
drawn from it -- including the "refused" recommendation the correction section above records --
did not transfer. The instrument that replaced it is `assets/alpha_ladder_fixture`: three rows of
camera-facing cards, each card one mip deeper than the last (the UV range doubles per card;
doubling distance and size together cancels, and the generator records having shipped that way
first), on a flat backdrop -- foliage-shaped blobs, hard random specks, and the alphacov lattice
itself. A GUI checkbox puts the lookup beside TAA and MSAA so the states flip live. Its six arms
are the `ladder` gate group, and every number below is at the gate's 800x600 framebuffer (a hand
render at `-W 800` lands at 1600x1200 on this host and shifts every card one mip finer -- the
generator records the shift, and it is why the first round of hand numbers disagreed with the
arms).

**Which content dithers at all.** Distribution fires at level 9 -- the 1x1 tail -- on both the
foliage and the speck rows, and at level 3 on the lattice. On irregular content the 11.88 rescale
finds a scale that hits the target at every visible level, so 11.100 never engages there and the
lookup never fires: those rows are byte-identical with and without it. The regular lattice is the
one content class that enters the visible dither regime. `ladder-fire` pins this from the texture
probe, render-free: -1 / -1 / 3.

**What the live path does to the dither, dots cards 4-6** (truth = TAA off = 24.0 / 16.6 / 18.9
luma over the backdrop; churn = adjacent-frame strong flips on the row, one process):

| path | coverage, cards 4-6 | ratio to truth | churn |
|---|---|---|---|
| one sample + TAA, no lookup | 3.5 / 4.6 / 1.7 | 0.16 | 2,917 |
| one sample + TAA, the lookup | 4.9 / 4.5 / 3.7 | 0.22 | 358 |
| **MSAA 4 + TAA (A2C), no lookup** | **13.9 / 18.8 / 20.1** | **0.89** | **8** |
| MSAA 4 + TAA, lookup let loose | 15.7 / 14.0 / 13.3 | 0.72 | 454 |

**The verdict.** The live-path fix for 11.100's dither is alpha-to-coverage, which the engine
already had: at four samples the coverage survives at truth level and holds still. At one sample
nothing recovers the coverage -- a binary test under a clamped history has no way to hold an 11%
haze -- and the lookup's real, measured contribution is an 8x churn reduction plus the Moire kill
on that path. Under A2C it is a net loss (coverage down a fifth, churn up 50x from a base of 8),
so it gates OFF on `alphaToCoverage`: the MSAA path IS the fix, the lookup is the palliative for
the path that has no samples. Both halves proven at 0 px -- the gate leaves the A2C frame
byte-identical, and the one-sample frame unchanged.

**Why the plane lied.** Anisotropic filtering over a continuous lod gradient averages a sparse
lattice into a smooth low-alpha field, and the sharpened test then deletes it (11.100's own
recorded grazing ceiling); the un-jittered plane read as bright coherent bands and the jittered
one as boiling grain, and the count metric could not rank them. On facing geometry the same
lookup cuts the churn 8x. The R2 rotation and ign-anchor variants recorded above were answers to
questions the plane had posed wrongly; the shipped shape is the static white anchor, gated.

**The user's real defect is upstream of this spec**: the render app's interactive TAA session
runs at MSAA 1, the one configuration where masked content cannot hold fractional coverage. That
is booked as roadmap G3 rather than changed here -- it is an AA-policy decision with a perf cost to
measure, not a lookup.
