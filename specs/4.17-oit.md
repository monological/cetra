# 4.17 — Weighted-Blended Order-Independent Transparency (OIT)

## Context

The renderer draws ALPHA_BLEND (translucent) meshes in an **unsorted** second pass
(`render_current_scene` pass 2, `render.c:687-698`, `alpha_pass=true`) with depth-write off and a global
`SRC_ALPHA/ONE_MINUS_SRC_ALPHA` blend, so overlapping transparent surfaces composite in scene-graph order
and **pop** as the camera moves. 4.17 adds McGuire & Bavoil weighted-blended OIT: accumulate transparent
fragments (weighted by depth) into two targets in ONE unsorted pass, then composite -- correct-looking
layering with no sorting and no popping. **Off by default** (`--oit` opt-in) so the OFF path is
byte-identical to master. Scoped to `ALPHA_BLEND && transmission==0`; the transmission/refraction late
pass (§4.9) and the ALPHA_MASK alpha-to-coverage cutout path (opaque pass) are left untouched.

## Recon (verified against source)

- **Transparent pass** = pass 2 of `render_current_scene`, unsorted, `glDepthMask(FALSE)`, global
  `SRC_ALPHA/ONE_MINUS_SRC_ALPHA` (`engine.c:322`), same `pbr_frag`, into the MSAA scene FBO attachment 0
  only. Per-mesh partition (`render.c:295-296`): `is_late = alpha_mode==ALPHA_BLEND || transmission>0`.
- **Transmission is orthogonal** (a `transmission>0` float, opacity 1; screen-space refraction reads the
  resolved `opaque_color_texture`). OIT scopes to `ALPHA_BLEND && transmission==0`; a both-BLEND-and-
  transmissive material routes to refraction (transmission wins) -- documented, and the fixture avoids it.
- **ALPHA_MASK** (A2C cutout) renders in pass 1 (opaque), already order-independent -- untouched.
- **MRT/depth:** the `_gbuffer_attachments` descriptor table (`engine.c:59-84`, 5 attachments) on
  `engine->framebuffer` + a shared MSAA `depth_renderbuffer`. Indexed blend is GL 4.0 core and already
  used (`glDisablei`, `engine.c:1683`); OIT adds the first `glBlendFunci`/`glEnablei` (index = draw-buffer
  SLOT, re-set per pass since a blanket `glEnable(GL_BLEND)` wipes indexed state).
- **Resolve/composite model:** `postfx_run` resolves the MSAA HDR -> `hdr_fbo` (`postfx.c:1461`); mirror
  `_sss_fold_into_hdr` / `postfx_run_fog` -- `resolve_color_attachment` the accum+revealage targets, then
  one fullscreen composite folded into `hdr_fbo` before TAA/SSR/fog/DoF/bloom/tonemap. New fullscreen
  program via `create_post_program`; a new `.glsl` needs a full `./build.sh` (CMake re-GLOB).
- `pbr_frag` outputs 0-4 are used (FragColor/Normal/Velocity/Albedo/Diffuse); locations **5,6 are free**.
  `create_color_fbo` already handles `GL_R8`/`GL_R16F`.

## Design

- **Separate lazily-created MSAA OIT FBO sharing the opaque depth** (mirrors `_ensure_opaque_color_target`):
  `oit_accum` (`RGBA16F`) + `oit_revealage` (`R16F`) MSAA textures at the scene sample count, attached at
  `GL_COLOR_ATTACHMENT5/6`, plus `glFramebufferRenderbuffer(GL_DEPTH_STENCIL_ATTACHMENT,
  engine->depth_renderbuffer)`. Keeps the opaque descriptor table's invariants untouched; OIT depth-TESTs
  against opaque geometry, depth-write off. Attachments at 5/6 line up with the shader output locations.
- **`pbr_frag` OIT mode (guarded, FragColor untouched):** `layout(location=5) out vec4 AccumOut;
  layout(location=6) out vec4 RevealageOut;` + `uniform int oitPass;`. After the existing lit `color` +
  `finalOpacity`: `if (oitPass>0) { float w = oitWeight(ViewPos.z, finalOpacity); AccumOut =
  vec4(color*finalOpacity, finalOpacity)*w; RevealageOut = vec4(finalOpacity); }`. The guard DCEs when
  `oitPass==0` -> opaque AND the current alpha-blend path stay byte-identical.
- **Accumulate pass:** when `oit_enabled`, route pass-2 `ALPHA_BLEND && transmission==0` meshes to
  `oit_fbo`: `glDrawBuffers({NONE×5, ATT5, ATT6})`, clear accum=`vec4(0)`/revealage=`vec4(1)`,
  `glBlendFunci(5, GL_ONE, GL_ONE)` (additive accum) + `glBlendFunci(6, GL_ZERO, GL_ONE_MINUS_SRC_COLOR)`
  (multiplicative revealage -> `∏(1-a)`), `glDepthMask(FALSE)`, `oitPass=1`. Transmissive meshes keep the
  refraction path in the scene FBO.
- **Resolve + composite (postfx):** after the opaque HDR resolve, `resolve_color_attachment`
  accum+revealage -> single-sample; `oit_resolve_frag` outputs `vec4(accum.rgb/max(accum.a,1e-5),
  revealage)`, folded into `hdr_fbo` with `glBlendFunc(GL_ONE_MINUS_SRC_ALPHA, GL_SRC_ALPHA)` ->
  `avgColor*(1-reveal) + hdr*reveal`. Runs before TAA/SSR/etc. so they see composited transparency.
- **Weight:** McGuire depth weight, tuned in M3, e.g. `w = clamp(0.03/(1e-5 + pow(z/200.0, 4.0)), 1e-2,
  3e3)`, `z = -ViewPos.z`.
- **Toggle:** `engine->oit_enabled` (default false), `--oit`/`--no-oit`, GUI checkbox. Flipping the
  default is a later "live with it" call (like AgX).

## Byte-identity strategy

- OFF gate = `--no-oit` (default): the current unsorted alpha-blend pass runs unchanged; the OIT FBO is
  never allocated, `oitPass=0` DCEs the new `pbr_frag` outputs. Target: c64/raiden AND the OIT fixture
  `cmp`-exact vs master.
- **Never touch `FragColor`'s expression or grouping** (the clearcoat/sheen/SSS reassociation gotcha) --
  add only the two guarded outputs + `oitWeight`. Verify empirically after M1; isolate any sub-ulp drift
  via `git checkout master -- cetra/shaders/pbr_frag.glsl` + rebuild, then restore grouping or document.

## Milestones (branch `oit` off `master`; each `--no-oit` byte-identical)

- **M0 — Spec (this file), committed first.**
- **M1 — Plumbing (inert).** OIT MSAA FBO (lazy, shared depth) + targets + free; `pbr_frag` guarded
  outputs + `oitPass` + `oitWeight`; `render.c` uploads `oitPass`; `--oit`/`--no-oit` + `engine->oit_enabled`
  (default off) + GUI. No routing. Gate: `--no-oit` `cmp`-exact vs master (c64/raiden); attribute any
  pbr_frag drift.
- **M2 — Fixture + accumulate pass.** `assets/gen_oit_fixture.py` (overlapping BLEND quads, staggered
  depth, varied color/alpha). Route pass-2 `ALPHA_BLEND` meshes to `oit_fbo` with the indexed blend +
  clears + `oitPass=1`. Gate: `--no-oit` `cmp`-exact (fixture too); `--oit` populates accum/revealage.
- **M3 — Resolve + composite + weight tune (the working effect).** `oit_resolve_frag.glsl` +
  `create_oit_resolve_program` + the postfx resolve/composite into `hdr_fbo`. Gate: `--no-oit` `cmp`-exact

  build; no NaN/black.
- **R — Review + ship (user-gated).** thermo + simplify + correctness (background); re-gate; roadmap +

## Risks

1. **Core-shader byte-identity (highest):** two new guarded `pbr_frag` outputs + a weight; leave
   `FragColor` grouping exact, guard on `oitPass`, verify + isolate + document.
2. **Indexed blend:** `glBlendFunci` index = draw-buffer SLOT (not attachment); set it in the OIT pass and
   don't rely on prior state.
3. **MSAA resolve:** resolve accum+revealage before compositing; revealage `R16F` (`R8` may band `∏(1-a)`).
4. **Weight scale:** depth-tuned; wrong scale collapses to all-front/all-back. Tune on the fixture.
5. **Shared-depth FBO completeness:** OIT color attachments must be MSAA at the same sample count as
   `depth_renderbuffer`.
6. **New `.glsl` → full `./build.sh`** for `oit_resolve_frag.glsl`.

## Shipped — outcome & review fixes

All milestones landed. The OFF gate held with **zero drift**: `--no-oit` on c64/raiden AND the OIT
fixture are `cmp`-exact vs master (the guarded `pbr_frag` outputs DCE-guard on `oitPass`, `postfx_run`
gets `oit_fbo = 0`, and the routing filter reduces to the classic late pass). `--oit` composites the
three overlapping translucent quads order-independently: the unsorted `--no-oit` path lets the
last-drawn (blue) dominate the overlap and flips as the camera orbits, while `--oit` is a stable
weighted blend from every angle. The fixture wants a low fixed exposure (`--exposure 0.08`) to read the
translucent colors -- lit flat quads blow out under a bright key light, the same lesson as the SSS/glass
fixtures.

Design confirmed by review: a **separate lazily-allocated MSAA OIT FBO sharing the scene depth** (not
attachments 5/6 on the MRT descriptor table -- the OIT targets need indexed per-target blend and a
non-zero revealage clear the table can't express); guarded `AccumOut`/`RevealageOut` in `pbr_frag`
mirror the SSS `DiffuseOut` precedent; the `postfx` `oit_fbo` param mirrors the existing `msaa_fbo`
convention.

R-phase review (correctness + reuse/efficiency + simplification/altitude fanout) found and fixed:
- **Correctness (high):** the late-pass routing filter keyed on `engine->oit_enabled`, so when OIT was
  enabled but the accumulate pass did **not** run (a genuinely non-PBR frame, or an OIT-FBO allocation
  failure) it dropped every ALPHA_BLEND mesh -- they vanished. Now keyed on `engine->oit_this_frame`
  (true only when the accumulate actually ran); the fallback draws the classic late pass. The `--no-oit`
  path was already correct, which is why the byte gate didn't catch it.
- **Simplification:** hoisted the trailing late-pass call out of the `if/else` (the `else` duplicated
  it; `_render_node` decides transmissive-only vs all-late internally via `oit_this_frame`).
- **Efficiency:** gate the accumulate on a new `scene->oit_mesh_count` (ALPHA_BLEND && !transmissive) so
  a transmissive-only scene with `--oit` doesn't run an empty accumulate + 2 resolves + composite.
- **Correctness (low):** clamp the premultiplied weighted accum color to the fp16 ceiling (no `Inf`
  blob on a bright near-camera translucent); `glDisablei(GL_BLEND, 5/6)` in `engine_end_oit_pass` for
  symmetry (latent trap if the MRT ever widens to 5/6); explicit `oit_ready = false` init.

## Deferred

- **Weight tuning:** the McGuire depth weight saturates for near-camera fragments (the fixture quads all
  hit the ceiling), so it's effectively uniform weighting there -- fine for similar-depth transparency,
  but a large depth spread would want tuning; expose a per-scene knob if a scene needs it.
- **OIT vs shadow-catcher/overlay ordering:** OIT composites in postfx after the whole scene FBO
  (including the shadow catcher + overlays) resolves, so a translucent surface behind the catcher plane
  lands in front of it -- the reverse of the classic in-FBO late-pass order. Doesn't manifest above the
  floor; a minor quality difference, not a crash.
- **Fixture exposure:** wants `--exposure 0.08`; a dimmer/unlit fixture variant could read at default.
- **Partial-alloc cleanup** in `postfx_ensure_oit_targets` is left consistent with the sibling
  `ensure_*` functions (no cleanup on catastrophic GL failure).
