# Tier 3 · 4.10 — Clearcoat, on a `sampler2DArray` material-mask foundation

## Context

Clearcoat (a thin, smooth dielectric GGX lobe over the base BRDF — car paint, lacquer, varnish,
carbon fiber) is the notable gap in the engine's advanced-material set and the first Tier-3
material.

Exploration surfaced that the engine is **at the GL 4.1 fragment-sampler ceiling and slightly over
it**: `pbr_frag` declares 17 samplers on units 0–16, but the M1 Max reports
`GL_MAX_TEXTURE_IMAGE_UNITS = 16` (valid 0–15). `brdfLUT` sits at **unit 16 — out of spec** — and
survives only because two declared-but-never-sampled slots (`sheenTex` 8, `reflectanceTex` 9,
reserved for future KHR sheen/specular) keep the *active* count within Apple's lenient tolerance.
The engine never queries the cap; material units are hardcoded literals (render.c:164–176). GL 4.1
has no bindless textures, so the modern escape hatch is off the table.

The chosen fix (user decision, after weighing packing vs. array) is to build the material texture
system **the scalable GL-4.1 way: a `sampler2DArray`**. All the single-channel/linear **scalar
masks** (roughness, metallic, ao, opacity, microsurface, anisotropy, subsurface — and future sheen/
specular/coat masks) collapse into **one array sampler**, indexed per material by layer. That
collapses ~7 declared mask samplers into **1**, frees ~6 units, retires the unit-16 overrun, and —
unlike channel-packing, which caps at 4 channels/texture — **scales to any new mask type by adding a
layer, never a new sampler**. It is the closest thing to bindless available here. Quality-critical,
size-varying maps (albedo, normal, emissive) stay on dedicated native-resolution units, untouched.

So 4.10 is two phases: **(A)** the mask-array foundation (frees units, fixes the overrun), then
**(B)** clearcoat, the first client of the freed headroom. Reserved sheen/reflectance slots are
left intact.

## Design decisions

- **One `GL_TEXTURE_2D_ARRAY` for all scalar masks.** RGBA8, LINEAR, full mip chain, allocated with
  the exact pattern `shadow.c:144–153` already uses (`glTexImage3D` + params). Layers = the scene's
  *unique* mask textures (deduped by `Texture*`/id). Each material stores a small **layer index per
  mask slot** (`int roughness_layer …`, default −1 = absent → scalar-uniform fallback, replacing the
  `*TexExists` gate). Shader reads `layer >= 0 ? texture(maskArray, vec3(uv, layer)).<chan> :
  scalarUniform` — channels unchanged (roughness `.g`, metallic `.b`, ao/others `.r`). Declared
  samplers drop **17 → 11**; frees units **2, 3, 4, 7, 10, 11, 12** (minus 1 for the array = **~6
  net**).
- **Canonical size = clamp(largest present mask dimension, 256, `MASK_ARRAY_CAP`=2048).** Array
  layers must share one size, so smaller masks are **upsampled** to canonical; nothing is
  downsampled below the largest (no detail loss unless a mask exceeds the 2048 cap). Resampling is
  done on the **GPU by blit** — `glBlitFramebuffer` from a read-FBO(mask texture) into a
  draw-FBO(`glFramebufferTextureLayer(array, 0, layer)`) with `GL_LINEAR`, then
  `glGenerateMipmap` — reusing the probe's blit precedent (probe.c:199–204); **no CPU resize
  dependency** (`stb_image_resize` is absent, deliberately not added).
- **Byte-identity is asset-dependent and honestly RMSE where masks resample.** The albedo/normal/
  emissive path is untouched ⇒ `cmp`-exact everywhere. A mask layer sampled at its **native size
  (no resample) is byte-identical** to the old direct read; only *upsampled* masks differ. So
  uniform-mask-size assets stay `cmp`-exact; mixed-mask-size assets (c64) move to **RMSE** (tight
  bound, verified visually indistinguishable). This is the accepted trade for the scalable system —
  the color/normal path never resamples.
- **Cross-material build, deferred for async.** The array spans all materials, so it builds once all
  masks are resolved. Sync (`create_scene_from_model_path`, import.c:1255): build at load end. Async
  (`_async`, import.c:1371 + `async_loader` drain): a `scene->mask_array_dirty` flag + build when
  `!async_loader_is_busy()` in the engine's per-frame loader-drain step — masks fall back to scalars
  while streaming, then snap in (matches existing texture pop-in). Owned by `Scene` (sibling of the
  texture pool / shadow array); freed in scene destroy.
- **Clearcoat = a second GGX lobe reusing the existing toolkit**, no new IBL textures. Analytic
  (after the light-loop accumulation, pbr_frag:857) and IBL (after the split-sum, pbr_frag:905),
  fixed F0 = 0.04 (IOR 1.5), coat roughness for its own NDF/LOD, base geometric normal in v1.
  Reuses `distributionGGX`(:254)/`geometrySmith`(:310)/`fresnelSchlick`(:209)/
  `fresnelSchlickRoughness`(:214) and `prefilteredMap`+`brdfLUT` at coat roughness. Base term
  attenuated by the coat Fresnel `(1 − ccWeight·Fc)` — the `kD`-scaling pattern at :821–827 and the
  thin-film F-replace precedent at :803–811. `clearcoatFactor`/`clearcoatRoughnessFactor` are
  **scalars** (uniforms), so the lobe touches the array not at all; the optional clearcoat **normal**
  map lands on a **freed dedicated unit** (native resolution, byte-exact — normals don't belong in a
  resampled scalar array).
- **Kill-switch / byte-identity discipline** mirrors energy-comp / AgX: global `clearcoatEnabled`
  uniform + `--no-clearcoat`; per-material `clearcoatFactor` defaults 0 ⇒ lobe skipped
  (`if (clearcoatEnabled>0 && clearcoat>0.0)`), output identical to pre-clearcoat.

## Milestones (branch `clearcoat`, `git commit -S -v`)

### Phase A — `sampler2DArray` mask foundation

**A1 — Query caps, name the units, assert (byte-identical; no pixels move).** Add
`get_gl_max_texture_image_units()` + `get_gl_max_array_texture_layers()` in util.c/.h (mirror
`get_gl_max_lights` :26–44); query+log+store in engine (engine.c:287-block, engine.h fields). Add
`TEXUNIT_*` constants in common.h (after the `GL_ATTR_*` block, incl. `TEXUNIT_MASKS`) + a
`_Static_assert` the top material unit stays below `SHADOW_MAP_TEXTURE_UNIT`. Swap the literal unit
args in render.c:164–176 for the constants (no numeric change).
*Gates:* c64 + raiden `cmp`-exact; no GL errors.

**A2 — Build the mask array; migrate the 7 mask samplers → 1 (the big milestone).** New
`Scene`-owned mask `GL_TEXTURE_2D_ARRAY` + a build routine (alloc per shadow.c:144–153; blit-resample
each unique mask into a layer; mipgen). Material gains `int <mask>_layer` fields (material.h,
default −1, material.c init/free); resolve masks → layer indices during the cross-material build
(dirty-flag + build-when-idle for async, per Design). render.c `_update_program_material_uniforms`:
bind the array once to `TEXUNIT_MASKS`, set the 7 `*Layer` int uniforms, and DELETE the 7 mask
sampler-int sets / binds / `*TexExists` sets (:164–176/:188–241/:245–255 for the mask entries).
pbr_frag: declare one `sampler2DArray maskArray` + 7 `int *Layer`; replace the 7 mask reads
(:597/605/613/630/638/645/651) with `layer>=0 ? texture(maskArray, vec3(uv, layer)).<chan> :
scalar`; delete the 7 mask `sampler2D` + `*Exists` ints. Regenerate shader_strings.h via build.
*Gates:* color/normal path `cmp`-exact; mask-bearing assets (c64, raiden) verified by **RMSE ≤ tight
bound** + visual A/B indistinguishable; assert layer count < `GL_MAX_ARRAY_TEXTURE_LAYERS`; async
stream-in (raiden) renders without flashes beyond the existing pop-in; leak/no-GL-error over reload.

**A3 — Relocate engine samplers into the freed low band (byte-identical).** Renumber
`SHADOW_MAP_TEXTURE_UNIT` (shadow.h:14) + the three IBL units (ibl.h:16–18) down into the freed
range so `brdfLUT` ≤ 15 — retires the out-of-spec unit-16 bind; binding code already uses the
constants (render.c:356-block, shadow.c:351-block, ibl.c:725–744). Tighten the A1 assert.
*Gates:* c64 + raiden `cmp`-exact vs. their A2 outputs (same textures, new unit numbers).

### Phase B — Clearcoat (first client of the freed headroom)

**B1 — Material data + import + plumbing (inert; byte-identical).** Add `float clearcoat;` +
`float clearcoat_roughness;` to Material (the transmission/ior scalar cluster, material.h:50), default
0 (material.c:31-block), direct-write (no setter, like filmThickness). Import: a clearcoat block in
`extract_material_properties` mirroring the transmission block (import.c:215–238) reading
`AI_MATKEY_CLEARCOAT_FACTOR` / `AI_MATKEY_CLEARCOAT_ROUGHNESS_FACTOR` (glTF-scoped; FBX ⇒ 0). Uniform
upload (render.c:138-block), `clearcoatEnabled` global (engine.h/engine.c/render.c:338),
`--no-clearcoat` app triple (struct/usage/parse/apply ~render.c:102/186/509/1085), GUI checkbox
(engine.c Post ~1401). Shader declares the uniforms, no lobe yet.
*Gates:* c64 + raiden `cmp`-exact (factor 0); `--no-clearcoat` parses.

**B2 — The clearcoat lobe (analytic + IBL).** In pbr_frag, guarded by
`if (clearcoatEnabled>0 && clearcoat>0.0)`: analytic coat after :857 —
`Fc = fresnelSchlick(max(dot(H,V),0), vec3(0.04))`, `Dc = distributionGGX(N,H,ccRough)`,
`Gc = geometrySmith(N,V,L,ccRough)`, `coat = clearcoat*Dc*Gc*Fc/(4*NdotV*NdotL+ε)`; scale the base
per-light term by `(1 − clearcoat*Fc)`, add `coat`. IBL after :905 —
`ccBrdf = texture(brdfLUT, vec2(NdotV, ccRough)).rg`,
`ccPre = textureLod(prefilteredMap, R, ccRough*maxReflectionLOD).rgb`,
`Fc_ibl = fresnelSchlickRoughness(NdotV, vec3(0.04), ccRough)`,
`coatIBL = clearcoat*ccPre*(0.04*ccBrdf.x + ccBrdf.y)`; scale base `ambient` by `(1 − clearcoat*Fc_ibl)`,
add `coatIBL*aoMap*iblIntensity`. No new sampler; base normal. Firefly-clamp the coat like :857.
*Gates:* c64 + raiden `cmp`-exact with clearcoat off / factor 0 / `--no-clearcoat`; determinism ×2;
visual A/B on raiden (metal) + a clearcoat sphere — dual-lobe highlight, sharp coat reflection,
grazing coat Fresnel, energy sanity (base dims under the coat, no over-bright).

**B3 — Clearcoat normal map (the payoff) + test asset.** Declare `clearcoatNormalTex` on a FREED
dedicated unit (native res, byte-exact); Material `clearcoat_normal_tex` + setter + free; import via
bespoke `aiGetMaterialTexture(…, aiTextureType_CLEARCOAT, 2, …)` (the index-0-only TextureMapping
table can't express it — mirror the MR-UNKNOWN special-case, import.c:422–435). Shader perturbs a
coat normal `Nc` in the base TBN for the coat lobe's N·H/N·V/N·L; base normal unchanged. Author a
car-paint / carbon-fiber sphere fixture (KHR_materials_clearcoat via a gen-script, gen_glass_fixture.py
pattern) + a `set_node_clearcoat` app helper (set_node_iridescent_visor precedent, render.c:962).
*Gates:* byte-identical off; visual — orange-peel / weave under the coat; determinism.

**B4 — Review + ship.** /thermo-nuclear + /simplify fanout (ALL run_in_background), apply, re-gate;
roadmap §4.10 shipped-shape (+ the mask-array foundation, the array-vs-packing rationale, reserved-
slots policy, canonical-size/RMSE trade, the brdfLUT-was-at-16 fix); memory notes (sampler-budget
map + the array pattern). User merges on explicit request.

## Budgets & risks

- **Sampler budget** (the point): after A2/A3 the program lives in units 0–~13, unit-16 overrun gone,
  ~6 free units; clearcoat scalar lobe adds ZERO samplers, clearcoat normal takes one freed unit.
  Uniform components `215 + 64*21 = 1559 / 4096` — the 7 `*Layer` ints + clearcoat scalars are
  negligible; new uniform names need no uniform.c edit (lazy cache).
- **Risks:** (1) A2 is the load-bearing refactor — land A1–A3 and verify (cmp for color/normal, RMSE
  for masks) before any clearcoat pixels move (the foundation is the bridge, like the sky's M0).
  (2) Canonical-size resampling is the only non-`cmp` surface — bounded RMSE, confined to the mask
  path, color/normal never touched; watch mask **memory** (layers × canonical² — cap 2048, adaptive
  down). (3) Async build timing — build only when the loader idles; guard against building mid-stream
  (dirty-flag re-check). (4) One global wrap/filter for all mask layers (masks are ~always
  repeat/linear — a documented minor limitation). (5) fp16/energy + sun double-count in the coat
  (coat additive, base attenuated by its Fresnel). (6) glTF clearcoat texture indices share
  `aiTextureType_CLEARCOAT` (0/1/2) — bespoke index reads.
- **Reserved, not reclaimed:** sheen(8)/reflectance(9) stay for KHR_materials_sheen/_specular (they
  become array layers when built). The packed-then-arrayed memory optimization and albedo/normal
  arraying are documented future steps, not built.
- Refs: Kelemen-Szirmay-Kalos coat; Burley "PBS at Disney" (2012); glTF KHR_materials_clearcoat;
  Filament clearcoat; `sampler2DArray` (the shadow-map precedent, shadow.c).

or a freed unit); 4.12 separable SSS follows. Packed-then-arrayed layers and arraying albedo/normal
are the next scalability steps if batched material rendering ever lands.
