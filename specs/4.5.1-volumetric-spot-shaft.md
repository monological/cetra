# 4.5.1 Volumetric flashlight shaft — shadowed spot-light in the fog march

## Context

The spores flashlight (`LIGHT_SPOT`) shades the surfaces its cone lands on, but the **cone of light
in the air** — the TLOU2-style glowing shaft — isn't visible. That needs volumetric in-scattering:
the beam lighting the airborne medium along the view ray. The engine's volumetric fog march already
does this for **directional** lights (sun/key); it needs a spot term. And to look *right*, the beam
must be **occluded by geometry** (the glass ball cuts a gap in the shaft, walls block it), which
needs a shadow map rendered from the flashlight's viewpoint — the engine has none for spots today.

**Two phases; the second is the correct result, the first is the scaffold under it:**
- **Phase 1 — the shaft (unshadowed):** add the spot in-scatter term to the fog march so the glowing
  cone renders end-to-end. Necessary foundation; ships + verifies on its own.
- **Phase 2 — do it right (shadowed):** render a perspective spot shadow map and sample it per march
  step so the beam is occluded by geometry. Same map also gives the flashlight real **surface**
  shadows. This is the target look.

Recon facts:
- Fog lives entirely in `postfx.c/.h` + `fog_frag.glsl`. The march is **world-space**
  (`P = camPos + rayDir*t`, `fog_frag.glsl:136`); composite is additive HDR (`out = inscatter +
  scene*transmittance`, `postfx.c:1262-1275`) and blooms — no compositor change.
- Scene→PostFX flatten is `shadow_publish_to_postfx` (`shadow.c:611-646`, called `engine.c:1692`);
  fog uniform upload is `postfx_run_fog` (`postfx.c:1213-1249`). postfx must never see `Scene`.
- Shadow depth render is `render_shadow_depth_pass` (`shadow.c:420-595`, invoked `engine.c:2033`);
  the geometry walk `_render_shadow_node` and the depth shaders `shadow_depth_vert/frag.glsl` are
  **light-agnostic** — a perspective spot matrix works through them unchanged.
- `pbr_frag`'s `calculateShadow` already does the perspective w-divide (`pbr_frag.glsl:583`), so
  surface spot shadows are feasible with plumbing, no new projection math.

## Phase 1 — Unshadowed volumetric spot shaft

### 1a. PostFX spot fields (`postfx.h`, by the `fog_light_*` block :193-199)
```c
bool  fog_spot_enabled;
vec3  fog_spot_pos, fog_spot_dir, fog_spot_color; // world pos, cone axis, color*intensity
vec3  fog_spot_atten;                              // constant, linear, quadratic
float fog_spot_cos_inner, fog_spot_cos_outer;      // cutOff, outerCutOff
```
Default off in the constructor (`postfx.c:283-292`).

### 1b. Publish the spot — extend `shadow_publish_to_postfx` (`shadow.c:611-646`)
In its existing `scene->lights` loop, also grab the **first `LIGHT_SPOT`** and fill `fog_spot_*` from
live world data — `global_position`, `direction`, `color*intensity`, `constant/linear/quadratic`,
`cutOff`/`outerCutOff` (`light.h:10-43`; use `global_position`/`direction`, recomputed at
`scene.c:835-851`). `fog_spot_enabled = true` when found, else `false`. Independent of the
directional `shadow_map_index` path.

### 1c. Upload — `postfx_run_fog` (`postfx.c:1213-1249`)
Upload `spotEnabled`, `spotPos`, `spotDir`, `spotColor`, `spotAtten`, `spotCosInner`, `spotCosOuter`.

### 1d. Shader in-scatter — `fog_frag.glsl`
Declare the uniforms (:15-36). **Hoist** `spotPhase = phaseHG(dot(spotDir,-rayDir), anisotropy) *
sunBoost` by the `lightK` setup (:121-129). **Per step**, after the directional loop (after :145,
before `L += ...` at :146), using world `P`:
```glsl
if (spotEnabled == 1) {
    vec3 toL = spotPos - P; float d = length(toL);
    float cosT = dot(-toL / max(d, 1e-4), spotDir);
    float cone = clamp((cosT - spotCosOuter) / max(spotCosInner - spotCosOuter, 1e-4), 0.0, 1.0);
    if (cone > 0.0) {
        float atten = 1.0 / max(spotAtten.x + spotAtten.y*d + spotAtten.z*d*d, 1e-4);
        S += spotColor * (cone * atten * spotPhase);   // shadow multiplied in Phase 2
    }
}
```
Linear cone matches `pbr_frag`'s `spotConeFactor`, so the shaft edge aligns with the floor-pool edge.
Build regenerates `shader_strings.h` from the `.glsl`.

### 1e. Enable + tune fog in spores (`spores.c`, exposure block ~:130)
`engine->postfx->fog_enabled = true;` (also turns on the aux/linear-depth pipeline), then room-scaled
params: low `fog_density` + low `fog_ambient` (~0.01) so the room stays moody and the **beam
dominates**, `fog_anisotropy` ~0.6 (forward scatter → beam glow), `fog_floor_y`/`fog_height_falloff`/
`fog_far` for the ~24u room, `fog_sun_boost` to dial shaft brightness. Values tuned from captures.

## Phase 2 — Perspective spot shadow map (the occluded beam = correct result)

### 2a. Spot shadow storage — `ShadowSystem` (`shadow.h:33-57`)
Add a **standalone** spot depth map (keeps the directional cascade array + its layer math and the
`MAX_FOG_LIGHTS` static-assert untouched): `GLuint spot_shadow_map, spot_fbo; mat4 spot_light_space;
bool spot_active;`. Allocate a `GL_TEXTURE_2D` `GL_DEPTH_COMPONENT24` (e.g. 1024²) + FBO with
`glDrawBuffer/ReadBuffer(GL_NONE)` — the `init_shadow_caster` template (`shadow.c:75-113`).

### 2b. Perspective light-space matrix — new `compute_spot_light_space_matrix` (by `shadow.c:233-314`)
```c
float fov = 2.0f * acosf(light->outerCutOff) * 1.1f;         // cone angle -> vertical fov + margin
light_space_up(light->direction, up);                        // reuse shadow.c:223
glm_lookat(light->global_position, spotPos + light->direction, up, view);
glm_perspective(fov, 1.0f, near, far, proj);                 // near ~0.1, far spans the room (~40)
glm_mat4_mul(proj, view, dest);                              // -> spot_light_space
```

### 2c. Render depth from the spot POV — in `render_shadow_depth_pass` (`shadow.c:420-595`)
After the directional cascade loop, if a shadow-casting `LIGHT_SPOT` exists: build `spot_light_space`
(2b), bind `spot_fbo`, `glViewport` to the map size, clear depth, set the `lightSpaceMatrix` uniform
on the reused `depth_program`, and call `_render_shadow_node(scene->root_node, ...)` (unchanged) —
`glCullFace(GL_FRONT)` like the directional path. Restore viewport after. Auto-covered by both call
sites (`engine.c:2033`, `probe.c:116`).

### 2d. Publish + upload the spot shadow
Extend `shadow_publish_to_postfx` to also copy `spot_light_space` + the `spot_shadow_map` handle +
`spot_active` into new PostFX fields (`fog_spot_light_space`, `fog_spot_shadow_map`,
`fog_spot_shadowed`). In `postfx_run_fog`, bind `fog_spot_shadow_map` to a **new** texture unit
(unit 2; 0 = linDepth, 1 = the directional array) and upload `spotLightSpaceMatrix` + a
`spotShadowed` flag.

### 2e. Sample the shadow in the march — `fog_frag.glsl`
Add `uniform sampler2D spotShadowMap; uniform mat4 spotLightSpaceMatrix; uniform int spotShadowed;`.
In the spot block (1d), before adding to `S`, compute per-step visibility (perspective → **w-divide**,
the pattern at `pbr_frag.glsl:582-591`; the ortho affine `fogVisibility` fast-path can't be reused):
```glsl
float vis = 1.0;
if (spotShadowed == 1) {
    vec4 ls = spotLightSpaceMatrix * vec4(P, 1.0);
    vec3 pc = ls.xyz / ls.w * 0.5 + 0.5;
    if (pc.z <= 1.0 && all(greaterThanEqual(pc.xy, vec2(0))) && all(lessThanEqual(pc.xy, vec2(1))))
        vis = (pc.z - shadowBias > texture(spotShadowMap, pc.xy).r) ? 0.0 : 1.0;
}
S += spotColor * (cone * atten * spotPhase * vis);
```
Now the glass ball / walls **cut** the beam. Cost: one mat4×vec4 + divide per step for the single
spot — acceptable.

### 2f. (Included) Surface spot shadows — `pbr_frag.glsl`
The flashlight should also shadow surfaces (ball's shadow on the floor). Bind the spot map + upload
`spotLightSpaceMatrix` via `bind_shadow_maps_to_program` (`shadow.c:344-378`); add a `type == 2`
branch in the light loop (`pbr_frag.glsl:1049`) that multiplies the spot's contribution by a single
perspective tap (a trimmed `calculateShadow`, reusing the existing w-divide at :583, PCF optional).

## Verification
1. `./build.sh` clean (shader header regenerates).
2. **Phase 1** — `./out/bin/spores --headless --frames 300 --screenshot p1.ppm`: a visible glowing
   cone through the dust + the floor pool; it blooms. Tune density / sun_boost / anisotropy / spot
   intensity for beam-vs-haze balance.
3. **Phase 2** — same capture (`p2.ppm`): the beam is now **cut** where the glass sphere and walls
   block it (a dark gap tracking the sphere as it drifts); surfaces show the flashlight's cast
   shadow. Compare p1 vs p2 to confirm the occlusion.
4. **No directional-fog regression** — `render ... --fog` unchanged when no spot exists
   (`fog_spot_enabled`/`spotShadowed` false → no-ops).
5. Confirm depth-correctness (beam stops at the nearest surface) and that the moody exposure holds.

## Risks / notes
- **Perf**: the perspective spot tap adds a mat4×vec4 + divide per march step (the directional path
  hoists an affine fma) — fine for one spot at 24 steps / half res.
- **Shadow acne / peter-panning**: reuse the directional `shadowBias` + `glCullFace(GL_FRONT)`;
  a small perspective-depth bias may need tuning (a `spotShadowBias`).
- **General haze vs beam**: keep `fog_density`/`fog_ambient` low so the beam dominates the low-key mood.
- **Half-res + temporal**: a tight cone may shimmer at half res; lean on the TAA history / widen slightly.
- **Single spot** (v1). N spots = a small spot array + a shadow-map atlas/array — out of scope.
- Fresh branch off master; commit Phase 1, then Phase 2, as separate checkpoints.
