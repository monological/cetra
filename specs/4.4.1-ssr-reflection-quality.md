# Tier 2 · 4.4.1 — SSR reflection quality (full-res + stochastic + denoise + temporal)

> **STATUS — the pipeline is complete.** M1 full-res (`d201ff2` + `86a388e`), M2 temporal
> (`064f251`), M3a stochastic march (`8394647`), **M3b spatial à-trous denoise (`2e5530a`)** all
> shipped on `ssr-reflection-quality`. The striping is fixed: stochastic march scatters the Hi-Z grid
> stripes into noise, the à-trous resolves it into a clean reflection in a **single frame with no
> TAA** (verified deterministic, no `--headless-jitter` needed — the à-trous is spatial). Remaining:
> the R (review + ship) phase and the user's interactive sign-off, then merge.

## Context

The glossy shadow-catcher floor casts a serrated, striped reflection. This has been a multi-attempt
fix; the log matters so we don't repeat dead ends:

1. **Mip blur of the half-res buffer** — symptom-hide at the wrong altitude (over-softened the
   near-mirror floor, leaked SSR state into the shared fog composite). **Reverted.**
2. **Full-res tracing (M1, shipped `d201ff2` + Hi-Z fix `86a388e`)** — a genuine keeper: fixed a real
   "no reflection at non-grazing angles" bug (the Hi-Z reduction shader was hardcoded 2:1 and corrupted
   the full-res level-0 pyramid) and made the reflection *sharp*. But full-res alone does **not**
   remove the striping — a single-frame march always coverage/grid-aliases, finer at full-res but not
   gone.
3. **Temporal accumulation (M2, shipped `064f251`)** — reproject + neighborhood-clamp + blend, reusing
   the shared accumulator. **Verified (via the new `--headless-jitter`, `b27acd9`) that it does NOT
   fix the striping**: the stripes are pixel-for-pixel identical with M2 on vs off, because they are
   **fixed-screen-position Hi-Z/march *grid* artifacts (structured, deterministic), not temporal
   noise.** Averaging jittered frames just averages the same pattern. Temporal denoises *noise*; this
   isn't noise. M2 stays (useful for future curved-surface SSR / stability) but is not the fix.

**The actual fix (M3): the SSR denoise pipeline every production engine runs — which we simply never
built.** Real engines never show raw SSR; they trace stochastically and run a real denoiser. The
engine already has this exact pattern for **SSGI** (`gather → temporal accumulate → à-trous denoise →
composite`). Mirror it for SSR:

- **Stochastic march** — jitter the reflection ray per-pixel + per-frame (blue-noise/IGN keyed on the
  frame index, spread scaled by floor roughness). This converts the *deterministic grid stripes* into
  *noise*, which a denoiser can actually resolve (structured artifacts can't be denoised; noise can).
- **Spatial à-trous denoise** — clone `ssgi_atrous_frag.glsl` (edge-aware, depth + normal weights, 3
  iterations, `stepSize` 1/2/4) over the reflection buffer. Resolves the spatial noise into a clean,
  edge-preserving reflection.
- **Temporal accumulation (M2, have it)** — resolves the temporal noise + stabilizes.

**Honest caveat (do not skip):** a denoiser is a spatial+temporal *filter*. On a roughness-**0.1
near-mirror** floor the result will be **clean but slightly soft** (roughness-appropriate), not a
razor-perfect mirror — that softness is *why* big engines use planar reflections for flat near-mirror
surfaces. The user has chosen the proper-SSR path over planar with this understood.

Prerequisite shipped on `master` (`77a4e11`): the camera diagnostic. Artifact pose:
`-W 3456 -H 2104 --fov 50.0 --cam-eye -0.759,0.192,1.885 --cam-target -0.756,-0.190,-0.001 --cam-up 0,1,0`
(also the level grazing pose `--cam-eye -0.934,0.500,2.324 --cam-target -0.297,0.500,-0.079`).

### Recon facts (verified this session)

- **The SVGF pipeline to mirror lives in SSGI**, orchestrated in `postfx.c`: `ssgi_accum_frag.glsl`
  (temporal) + `ssgi_atrous_frag.glsl` (edge-aware B3-spline à-trous, depth weight
  `exp(-|Δz|/zTol)`, normal weight `pow(max(dot(n,cN),0),32)`, `stepSize=1<<i` over 3 iters) +
  `ssgi_atrous` PingPong. The loop is the template for the SSR à-trous.
- SSR runs (now full-res) in the SSR block: march → (M2) `run_temporal_accum` → composite via
  `upsample_tent`. M3 inserts the à-trous **between temporal and composite** (SVGF order:
  march → temporal → à-trous → composite).
- The march (`ssr_frag.glsl`) already reads the TAA-jittered `draw_projection` and has per-pixel IGN
  jitter in the linear branch; the Hi-Z branch is deterministic (`ssr_frag.glsl:158` "needs no
  jitter") — that determinism is the grid-stripe source. The stochastic term must perturb the **ray
  direction / start** per-frame (frame_index available as `fx->frame_index`), keyed to roughness.
- `--headless-jitter` (`b27acd9`) applies the sub-pixel jitter in headless so the temporal + denoise
  pipeline can be verified in a screenshot (non-deterministic; use an accumulated `--frames N` run).
- Denoise buffers: an `ssr_atrous` PingPong at the SSR resolution (mirror `ssgi_atrous`,
  `create_pingpong` in `create_ssr_buffers`, free in the realloc + `free_postfx`), plus the aux
  (linZ) + normals the à-trous weights need (already bound for SSGI's).

## Design (M3 — completes the pipeline; M1 + M2 already shipped)

**M3a — Stochastic march.** In `ssr_frag.glsl`, perturb the reflection ray per pixel + per frame:
a small offset drawn from blue-noise/IGN advanced by `fx->frame_index`, magnitude `∝ floorRoughness`
(with a small floor so the deterministic grid still breaks up at roughness 0.1). Uniform
`ssrFrameIndex` (or reuse an existing one). This turns the grid stripes into per-frame-varying noise.

**M3b — Spatial à-trous denoise.** New `ssr_atrous_frag.glsl` cloned from `ssgi_atrous_frag.glsl`
(edge-aware depth+normal weights) but smoothing the **full premultiplied `(color*weight, weight)`
vec4** instead of `.rgb` — filtering premultiplied RGBA is the correct blur for a coverage-alpha
buffer, and smoothing the weight is what softens the hard hit/miss coverage edge (the serration).
New `ssr_atrous_program` + `ssr_atrous` PingPong (SSR-res). Orchestrate 3 iterations (`stepSize`
1/2/4) in the SSR block, **after** the temporal accum, **before** the composite; point the composite
at the denoised result.

**Two decisions made while building (differ from the plan):**
1. **Broaden the stochastic gate to `ssr_denoise` (not `&& taa_resolving`).** The à-trous is a
   per-frame *spatial* resolver, so the stochastic march can run without TAA. But **freeze the jitter
   seed** (`ssrFrameIndex = taa_resolving ? frame_index : 0`) when there's no temporal accumulator, so
   the denoised pattern is *stable per frame* instead of boiling. With TAA, the seed advances and the
   temporal accum averages it (best quality).
2. **No `--headless-jitter` needed to verify.** The à-trous denoises spatially and the frozen-seed
   march is deterministic, so a plain headless single-frame render (no TAA, no jitter flag) already
   shows the clean result — and two runs are `cmp`-identical.

**M3c — Kill-switch + gates.** `ssr_denoise` field (default on) / `--no-ssr-denoise` / GUI. Off =
the current march (M1/M2), so off is byte-identical to the pre-M3 state. On = stochastic+denoised.

## Budgets & risks

- **Cost:** +3 à-trous passes at SSR res (cheap, mirrors SSGI's) + the stochastic march (no extra cost).
- **Near-mirror softness** (the honest caveat above): denoising roughness-0.1 leaves it clean-but-soft.
  If a razor mirror is required, that's planar's domain — explicitly declined.
- **Stochastic at roughness 0.1**: a tiny cone barely randomizes; a small minimum jitter floor is
  needed to break the deterministic grid. Tune so the denoiser has noise to work with without
  over-spreading the near-mirror.
- **Reflection reprojection ghosting** (M2, unchanged): surface-motion reproject; clamp-bounded.

## After 4.4.1

Reflection-motion reprojection (kill temporal ghosting under motion); roughness-driven importance
sampling for genuinely glossy reflective *materials* (this pipeline is the substrate); a variance-guided
à-trous (SVGF proper) if the fixed-iteration denoise leaves residue.
