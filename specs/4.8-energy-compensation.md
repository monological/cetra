# Tier 3 · 4.8 — Multi-scatter GGX energy compensation

## Context

Cetra's GGX specular is single-scatter: light that bounces between microfacets more than once is
discarded, so energy leaks and rough metals render darker than physical (the classic symptom the
roadmap names — a rough metal should hold its brightness as roughness rises; ours dims toward
gray). §4.8 adds the lost energy back per Kulla-Conty 2017 / Fdez-Agüera 2019. Pure correctness,
S-sized, and it needs NO new LUT, NO new sampler, NO format change: the split-sum BRDF LUT the
engine already bakes (`ibl_brdf_frag.glsl`, 512² GL_RG16F, `render_brdf_lut` at ibl.c:493) gives
the single-scatter directional albedo `Ess(NdotV, roughness) = A + B`, and the compensation is a
multiplier derived from it — the same formulation Filament ships.

**Verified code facts (explored):**
- pbr_frag.glsl is at the driver's 16-sampler redline (17 declared) — must REUSE `brdfLUT`
  (unit 16, `IBL_BRDF_LUT_TEXTURE_UNIT`). One extra fetch, no new sampler.
- Analytic loop (pbr_frag.glsl:694-758): `specular = NDF*G*F / (4·NdotV·NdotL)`, summed with
  the firefly clamp `min(..., vec3(10))`. The LUT is NOT currently sampled here.
- IBL block (pbr_frag.glsl:768-808): already fetches `brdf = texture(brdfLUT, vec2(NdotV,
  roughnessMap)).rg` and combines `prefilteredColor * (F * brdf.x + brdf.y)`.
- F0 = `mix(vec3(iorF0), albedoMap, metallicMap)` (:643-646). Roughness var `roughnessMap`,
  already spec-AA-widened before either consumer (:587-600) — comp sees effective roughness.
- **LUT lifecycle constraint:** `scene->ibl` exists only when the app loads an HDR (`-e`);
  `bind_ibl_textures` (ibl.c:675, called per program-switch from render.c:351) binds the LUT
  and sets `iblEnabled=1` iff `precomputed`. With no env, unit 16 has NO texture bound —
  sampling it would be undefined. Therefore the comp is gated on `iblEnabled > 0`, which is
  *exactly* the LUT-is-bound predicate. No-env scenes keep today's shading (deliberate scope
  cut; upgrade path below).

## Design

One hoisted block in pbr_frag.glsl before the analytic light loop (NdotV, the LUT fetch, and
the multiplier are all pixel-constant — N, V, roughnessMap, F0 don't vary per light):

```glsl
// Multi-scatter energy compensation (Kulla-Conty / Fdez-Agüera): single-
// scatter GGX loses the energy of light that bounces between microfacets
// more than once, dimming rough metals. The split-sum LUT's A+B is the
// single-scatter directional albedo Ess; scaling specular by
// 1 + F0*(1/Ess - 1) restores the lost multi-bounce energy (Fresnel-
// weighted, so dielectrics barely move and metals recover fully).
// Gated on iblEnabled: that is the predicate for the LUT being bound.
float NdotV = max(dot(N, V), 0.0);
vec2 brdf = texture(brdfLUT, vec2(NdotV, roughnessMap)).rg;
vec3 energyComp = vec3(1.0);
if (energyCompEnabled > 0 && iblEnabled > 0) {
    float Ess = brdf.x + brdf.y;
    if (Ess > 1e-4) {
        energyComp = 1.0 + F0 * (1.0 / Ess - 1.0);
    }
}
```

- **Analytic path:** `vec3 specular = numerator / denominator * energyComp;` (:719). Inside
  the existing firefly clamp; order preserved. The multiplier is bounded [1, 1/Ess] and ~1 for
  smooth surfaces (Ess→1), so the clamp headroom is unchanged in practice.
- **IBL path:** the block's own `brdf` fetch at :805 is the SAME coordinates — delete it and
  reuse the hoisted `brdf` + multiply: `specular = prefilteredColor * (F * brdf.x + brdf.y) *
  energyComp;`. Net: fetch count unchanged when IBL is on.
- The hoisted NdotV also replaces the inline `max(dot(N,V),0.0)` at :718 and the IBL block's
  own NdotV at :769 (same value, computed once).
- Deliberate approximations (document in the shader comment only if reviewers ask): isotropic
  Ess applied to the anisotropic NDF branch; thin-film's replaced F still comp'd by F0; kD /
  diffuse untouched (Fdez-Agüera's diffuse redistribution is out of scope — the roadmap's
  target is rough-metal specular loss).

## Risks / scope cuts

1. **No-env scenes get no analytic comp** (LUT doesn't exist without `-e`). Accepted: the LUT
   bake is env-independent in principle, so the upgrade path is engine-owned LUT baked at init
   and bound unconditionally — a lifecycle refactor deliberately NOT smuggled into this shader
   fix. Falls out naturally if/when a later item needs engine-level IBL restructuring.
2. **Firefly-clamp interaction:** comp raises rough-metal specular ≤ ~2-3× at worst (F0=1,
   Ess≈0.4 at r=1); the clamp at 10 still only trims sub-pixel spikes. Watch the M0 A/B for
   sparkle regression on the armor (memory: validate specular on the mirror-metal asset).
3. **LUT convention:** ibl_brdf_frag.glsl integrates the Karis split-sum (A += (1-Fc)Gv,
   B += Fc·Gv) — Ess = A + B is exact for F0=1, which is the convention the multiplier form
   assumes. Verified, not assumed.
