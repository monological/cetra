# Tree App AAA Visual Upgrade

## Context

The `apps/tree/` procedural tree demo looks far below the engine's capability: leaves render as
opaque untextured-looking rectangles (the leaf albedo has a real alpha cutout but the material
never sets `alpha_mode`), there are no shadows, no sky/IBL (so specular and ambient have no
environment), branches are naked overlapping open cylinders (12 segments, no caps, no joint
treatment, one mesh + SceneNode per branch ≈ 121 draw calls), and nothing moves. Meanwhile the
engine already ships a Hillaire atmospheric sky, CSM+PCSS shadows, screen-space SSS, a directional
wind system with vertex-shader displacement, a Niagara-style particle system, and a full HDR post
chain — the app simply doesn't use any of it.

Goal: rebuild the tree app into the engine's showcase — an Unreal-quality hero tree — while
keeping it a live procedural playground (ImGui sliders stay).

Direction locked with the user:
- **Fully procedural textures, baked at runtime** (no binary assets) — improve the existing
  CPU-generated bark/leaf/ground textures rather than importing files.
- **Full wind**: trunk/branch sway + per-leaf flutter in the vertex shader.
- **Complete scene treatment**: full lighting stack (sky, IBL, shadows, GTAO/SSGI/TAA/bloom,
  filmic tonemap), grounded environment (textured island stays), falling-leaf particles,
  DoF + composed cinematic default camera.
- **Sliders stay live**, with new ones added (wind, leaf density, season tint, sun).

## Design

### 1. Tree geometry & generation (apps/tree)

New files `apps/tree/src/tree_gen.h/.c` (~700–900 lines; `add_cetra_app` globs `src/*.c`, no build
change). `tree.c` keeps scaffolding/textures/materials/GUI; its `generate_branch` (tree.c:955) and
`generate_leaf_cluster` (tree.c:830) are deleted. **Two-phase generation:**

**Phase 1 — skeleton** (`tree_skeleton_build`, pure math): recursive `grow_branch` produces a flat
pool of curved branch spines (`Branch` slices into a shared `BranchPoint` pool; each point has
pos/tangent/radius/arc/root_dist). Per step the direction accumulates: gravity droop (thin
branches droop more), phototropism (outer parts re-straighten upward — the classic droop-then-
upturn S), and per-branch seeded wander noise. Deterministic own PRNG (`TgRng`, xorshift-style) —
independent of libc `rand()` which texture gen perturbs. Tip splits use the **da Vinci rule**
(child radii: `child_r = tip_r * sqrt(w_i)`, Σw=1, so Σchild² ≈ parent²) with a "leader" child
continuing the parent line (~0.4× tilt) — this rule makes silhouettes read as real trees instead
of broccoli. **Lateral branches** spawn along the parent arc (t ∈ [0.35, 0.9]) at golden-angle
137.5° phyllotaxis spacing, shorter near the tip (conical crown). Hard budgets (`TG_MAX_BRANCHES`
8192, point-pool cap) bound the worst slider corner to ~100 ms.

**Phase 2 — meshing**: ALL branches sweep into ONE bark `Mesh`, all leaves into ONE leaf `Mesh`
(two tree draw calls total, single "tree" SceneNode) via a growable `MeshBuilder`
(pos/nrm/tan/btn/uv0/uv1/idx arrays, safe_realloc-doubling, `mb_transfer` moves ownership into
`Mesh` — arrays are malloc-family so `free_mesh` works).
- **Sweep**: adaptive ring segments by radius (`clamp(5 + ceil(1.5*r), 5, 20)`: trunk ~17, twigs
  5–6), seam vertex duplicated (`segs+1` per ring — fixes the UV-wrap smear bug the old cylinder
  generator has at geometry.c:422), **parallel-transport frames** along the spine (no
  twist/pinch on curves), radial normals tilted by taper slope, circumferential tangents (matches
  bark normal map space).
- **Joints** (chosen: embed + flare + cap; ring-welding rejected as complex for no payoff): child
  spine origin pulled back inside the parent by `0.6 * parent_radius`; **basal flare** (branch
  collar) 1.3×→1× over first 22% of arc (trunk root flare 1.85×→1× over 15%); terminal twigs
  converge to a pointed apex fan; internal tips get a small hidden cap.
- **Bark UVs**: u spans integer tile count around circumference, v follows arc length / TILE
  (~6 world units), `uv_v0` inherited across joints → continuous, roughly uniform texel density
  trunk→twig, no stretching.
- **Leaves**: on the outer 1–2 generations along the outer 60% of arc, count from `leaf_density`
  slider (replaces leaves_per_tip), even spacing + jitter + tip cluster. Orientation:
  outward+upward phototropic bias jittered in a ~35° cone. Card = 2×1 subdivided quad (6 verts,
  4 tris) with mid-rib fold ~12° and tip droop ~15° (kills the flat-sticker look). UV0.v runs
  stem→tip (v=0 at stem = flutter pivot).

**UV1 wind contract** (both meshes, `aTexCoords2` @ location 8):
- `UV1.y = flex ∈ [0,1]` = normalized `root_dist^1.2` (arc length from trunk base through the
  hierarchy) — continuous at joints by construction, so wind displacement cannot tear attachments.
- `UV1.x = wind_phase ∈ [0,1)` — per-branch constant, blended from the parent's phase over the
  first 25% of arc (continuous at joints). Trunk = 0. Leaves: per-card `fract(twig_phase +
  rand*0.3)`; leaf flutter amplitude driven by UV0.y instead (pivot at stem).
- Constraints: bark/leaf materials must NOT bind an AO mask texture (pbr_frag.glsl:823 repurposes
  TexCoords2 as AO UV when UV1 exists); `uWindMaskMinY/MaxY` per-mesh AABB now spans the whole
  tree so the shader treats it as a broad envelope only — UV1.y is the real weight.

**tree.c wiring**: `regenerate_tree` → free old node (existing pattern skips lights/island), build
skeleton, two meshes, one node, `upload_buffers_to_gpu_for_nodes`; memcmp-on-TreeParams
regeneration unchanged. New sliders: Droop 0–1, Curve Noise 0–1, Phototropism 0–1, Laterals 0–3,
Twig Scale 0.5–2, Leaf Density 0.5–8; "Rad Decay" relabeled "Taper" (0.45–0.85); Twist defaults
137.5. New defaults: depth 4, branches 3, trunk 80/8, length_decay 0.72, taper 0.62, angle 32,
variance 12, droop 0.35, curve_noise 0.4, phototropism 0.3, laterals 1.2, leaf_size 8, density 3.

Budget at defaults: ~430 branches, bark ~13k verts / ~22k tris, leaves ~14k verts / ~10k tris —
~35k tris total, regeneration well under 10 ms.

### 2. Lighting & scene setup (app wiring, tree.c)

Replace `create_three_point_lights(scene, 1.0f)` with the full outdoor stack (mirror
apps/render/src/render.c:1480-1531):
- **Hillaire sky + IBL baked from sky**: `create_sky_atmosphere()` + `create_ibl_resources()`;
  golden-hour default `sun_elevation_deg = 14`, `azimuth = 235` (long raking shadows toward
  camera, leaf backlight); `sky_update_sun_dir` → `sky_bake_static_luts` → `sky_bake`;
  `scene->sky/ibl`, `render_skybox = true`.
- **Single sun directional** with `set_light_cast_shadows(sun, true)` (verified: light.h:57;
  `create_light` defaults cast_shadows=false which is why the app has zero shadows today —
  `create_scene` already auto-creates an enabled shadow_system at scene.c:71). Couple via
  `sky->sun_light = sun; sun_base_intensity = 10; sky_apply_sun_to_light(sky)`.
  `set_light_size(sun, 6, 6)` for PCSS penumbra.
- **Shadows tuned to tree scale** (radius ~150): `ortho_size 300, near 0.1, far 1200,
  pcss_enabled true, pcss_softness 1.5, cascade_count 3`, starting bias 0.0015 (tune against
  leaf acne). `scene->shadow_catcher` stays false — the island is real geometry and receives
  shadows through the PBR path.
- Engine GUI Environment section (live sun sliders + re-bake) lights up automatically once
  scene->sky/ibl are set.

### 3. Materials (bark / leaf / ground)

Reorder main so `create_scene()` precedes texture gen; upload ALL procedural textures through
`load_texture_from_memory(scene->tex_pool, ...)` (texture.c:387) and delete the app's hand-rolled
uploader — this **fixes an sRGB bug** (app uploads albedo as linear GL_RGB8 while pbr_frag
assumes hardware sRGB decode) and gains transparent-RGB dilation on the leaf cutout (no bright
mip fringes). Bark texture → 1024², deepen crack/cavity darkening ~1.3× (no AO map allowed —
UV1 now carries wind data; pbr_frag.glsl:823 repurposes UV1 as AO UV when an AO texture binds).
- **Bark**: albedo(sRGB)/normal/roughness + new height map (reuse the heightmap already computed
  inside `generate_bark_normal`) with `parallax_scale = 0.03` (POM); `wind_response = 1,
  wind_mode = 1`.
- **Leaf**: `alpha_mode = ALPHA_MASK, alphaCutoff = 0.4, doubleSided = true,
  foliage_shadows = true (new field, §4), wind_response = 1, wind_mode = 2 (new field, §5)`;
  SSS translucency: `subsurface = 0.6`, chlorophyll `subsurface_color (0.5, 0.8, 0.15)`,
  profile via `postfx_add_sss_profile(fx, (0.45,0.75,0.2), 1.5)` (engine sss_enabled defaults on;
  pass runs only when a subsurface material exists).
- **Island**: pool upload, roughness 0.9; receives sun shadows automatically.

### 4. Engine extension: alpha-tested foliage shadows (cast + receive)

Today ALPHA_MASK materials are fully excluded from shadow maps (cast skip verified at
shadow.c:413; receive gate `alphaToCoverage == 0` verified at pbr_frag.glsl:1071) — correct for
hair cards, fatal for a tree (no canopy shadows / dappled light, the #1 tree-ness cue). Additive,
gated extension; hair cards unchanged:
- New `Material.foliage_shadows` (bool, default false). Effective only when
  `ALPHA_MASK && alphaCutoff > 0 && albedo_tex`.
- `shadow_depth_vert.glsl`: pass through `aTexCoords` (location 2 — already in the mesh VAO,
  mesh.c:211-228) + wind block (§5) so swaying foliage casts swaying shadows.
- `shadow_depth_frag.glsl` (currently empty): `if (alphaTested == 1 && texture(albedoTex,
  TexCoords).a < alphaCutoff) discard;`
- `shadow.c _render_shadow_node`: replace the unconditional skip — masked non-foliage still
  skips; foliage binds albedo on unit 0, sets alphaTested/alphaCutoff, disables culling for
  doubleSided while drawing.
- Receive: `pbr_frag.glsl:1071` gate becomes `(alphaToCoverage == 0 || uFoliageShadows == 1)`;
  new uniform uploaded next to alphaToCoverage in render.c `_update_program_material_uniforms`
  (:175). Spot gate (:1079) and GTAO zero-normal marker (:1306) unchanged — leaf occlusion now
  comes from real shadows, not screen-space AO.

**Related hardening (A2C at MSAA 1x)**: render.c:175 sets `alphaToCoverage = 1` for ALPHA_MASK
unconditionally, but `GL_SAMPLE_ALPHA_TO_COVERAGE` is a no-op on 1-sample buffers → masked
geometry renders as near-full quads at MSAA 1x (threshold drops to A2C_MIN_ALPHA=0.02, verified
pbr_frag.glsl:84-88). Fix: when `engine->msaa_samples <= 1`, upload `alphaToCoverage = 0`
(binary cutoff fallback) and skip enabling A2C. No-op at MSAA >1 for all apps. The tree app
itself keeps engine-default **MSAA 4x, TAA off** (A2C dithers nicely, headless deterministic).

### 5. Engine extension: hierarchical vegetation wind (pbr_vert.glsl)

The existing curtain wind (windOffset, pbr_vert.glsl:73-85, verified) stays byte-identical.
New `Material.wind_mode` int (0 = curtain/default, 1 = vegetation branch, 2 = vegetation leaf),
uploaded next to uWindResponse (render.c:198). windOffset gains the UV1 signature
`windOffset(vec3 p, vec2 uv1, float t)`:
- mode 0: existing body verbatim.
- mode 1 (branches): trunk low-freq whole-tree lean (height-weighted via existing
  uWindMaskMinY/MaxY envelope, ~0.35× speed) + mid-freq per-branch sway
  `sin(t*speed + 2π*UV1.x) * amp * UV1.y` + turbulence term.
- mode 2 (leaves): mode-1 ride + high-freq flutter (`~6× speed`, position-decorrelated).
- Call sites keep prev-frame `t - uDeltaTime` (motion vectors stay honest for TAA/motion blur).
- Mirror in `pbr_skinned_vert.glsl` (has aTexCoords2 already) for parity.
- **Shadow-pass wind**: shadow_depth_vert gets the same windOffset + uniforms;
  `wind_upload_to_program` + time once per pass in `render_shadow_depth_pass`, per-mesh
  response/mode/AABB in `_render_shadow_node`. Gated by `uWindStrength<=0 || uWindResponse<=0`
  → wind-free scenes byte-identical. (Window-scene curtains gain moving shadows — intentional.)

App wiring: `Wind* wind = create_wind("breeze")`; direction (1, 0, 0.35), strength 2.5,
speed 1.2, gust_frequency 0.35, gust_amount 0.55, turbulence 0.5; `set_scene_wind`.

### 6. Engine extension: particle sprites + tumble (falling leaves)

Verified: billboard renderer has per-particle rotation in instance data but nothing animates it
(pool->rotation only zeroed), and particle_frag draws a procedural disc with no sampler.
- New module `particle_module_update_rotation(min_rate, max_rate)` — stable per-particle spin
  rate from seed, sign alternating (CPU backend; TF backend documented as ignoring it).
- New `billboard_renderer_set_sprite(renderer, Texture*, hdr_gain)` — binds sprite on unit 8,
  `uSpriteEnabled` uniform; fragment samples sprite (tint × vColor, discard a < 0.02) instead of
  the disc; hdr_gain replaces the hardcoded 6.0 (defaults keep spores byte-identical).
- New `particle_module_spawn_rate_set(module, rate)` for the GUI toggle (existing leaves finish
  falling).

App: 256-cap emitter, spawn 2.5/s, canopy-box init, life 14–22 s, size ~leaf_size/2, autumn
tint, update chain = rotation + curl noise (0.02, 5.0, 0.1) + drift (wind.xz·1.5, −3.5, ·1.5) +
integrate(0.96) + plane collider at island top (leaves settle). Sprite = the procedural leaf
albedo texture, hdr_gain 1. Ticked from a new `tree_update` callback via
`scene_update_particle_systems` (app currently passes NULL update to engine_run).

### 7. PostFX / camera / film look

`tonemap_mode = POSTFX_TONEMAP_AGX` (saturated foliage + sun disc without hue skew), then
`postfx_apply_film_look(fx)` with grain dialed back to 0.05. Subtle height fog
(density 0.0005, falloff 75, far 800, floor −5) for depth layering. DoF on with autofocus
(focus_distance 400, range 220 — tree sharp, edges fall away). `ssao_radius ≥ 1.6`
(scene-scaled). **SSR off** (rough dirt island — pure cost). Auto-exposure + bloom defaults kept.
Camera: hero framing, slightly low + off-axis — eye (110, 70, 380), look-at (0, 85, 0),
fov 0.55 rad, near/far 2/3000; drag controller stays.

### 8. Headless + CLI flags

`main(int argc, char** argv)` + minimal parser (mirror render.c:1221-1229 setter order, before
init_engine): `-x/--headless`, `-f/--frames N`, `-S/--screenshot path`, `--screenshot-every N`,
`-W/-H`, `--sun-elevation`, `--sun-azimuth`, `--no-shadows`, `--no-leaves-fx`, `--seed N`,
`--help`. GUI/FPS hidden when headless.

### App ImGui panel additions

Wind (strength 0–8, speed 0–4, gust freq/amount, turbulence — live, no re-bake), Leaves
(falling-leaves checkbox via spawn_rate_set; Season 0–1 lerping leaf albedo factor white →
autumn amber, optionally subsurface_color too), Sun (elevation/azimuth shortcuts calling
`sky_update_sun` — cheap per-drag re-bake).

```bash
./build.sh
# Hero frame: sky, sun, cutout leaves, canopy shadow dappling the island, SSS leaf rim
./out/bin/tree -x -f 240 -S <scratchpad>/tree_hero.ppm
magick <scratchpad>/tree_hero.ppm <scratchpad>/tree_hero.png   # then view the PNG
# Wind motion strip: trunk leans, branches sway de-phased, leaves flutter, canopy shadow moves
./out/bin/tree -x -f 480 --screenshot-every 80 -S <scratchpad>/tree_wind.ppm
# Backlight: sun behind tree -> leaf transmission glow
./out/bin/tree -x -f 240 --sun-elevation 8 --sun-azimuth 15 -S <scratchpad>/tree_backlit.ppm
# A/B shadow isolation
./out/bin/tree -x -f 240 --no-shadows -S <scratchpad>/tree_noshadow.ppm
# Wireframe joint/UV inspection: interactive, T key
# Regressions: hair cards still shadow-excluded, curtains still sway (moving shadows now
# expected), spores particles unchanged:
./out/bin/render -m <model> -x -f 120 -S <scratchpad>/regress.ppm   # + abandoned_window scene
```

Tuning loop: leaf shadow acne → raise bias; fizzy distant leaf edges → alphaCutoff 0.35; wind
amplitude → GUI sliders, bake back into defaults.
