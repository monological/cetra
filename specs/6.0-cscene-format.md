# Cetra scene format (.cscn) + Blender scene exporter — milestone 1

## Context

The abandoned-window project proved the pipeline gap: glTF carries geometry/materials/punctual lights,
but everything else that makes the *look* — ambient/environment, area fill lights, sun softness, fog,
exposure/bloom/tonemap, SSS tags, camera framing — is silently dropped. The first plan patched this
with a per-model sidecar; the user pushed on the architecture and the corrected direction is the one
real engines use:

> **Cetra gets its own scene file format. The scene file owns the look and references models.**
> (Godot `.tscn` → `.glb`; Unreal `.umap` → meshes; Unity scene → FBX. glTF is an asset, not a level.)

Direction (user-approved):
1. Scene format `*.cscn` — models to load + environment + lights + post + camera + material overrides
2. Render app opens it (`render scene.cscn`); CLI flags become debug overrides on top
3. Blender exporter writes GLB + `.cscn` in one go
4. (Later, out of scope) GUI "Save scene" writes tweaks back — the authoring round-trip

Decisions carried over: JSON via vendored cJSON; loader lives in the engine.

## Verified codebase facts the design uses

- No config parsing exists anywhere (first parser in repo). `cwalk` vendored (`src/ext/cwalk.h`);
  `path_exists()` in `util.c`; dirname idiom at `import.c:51-60` (`effective_texture_dir`).
- `PostFX` is public fields (`postfx.h:62-287`); tonemap enum `PASSTHROUGH/ACES/NEUTRAL/AGX`
  (`postfx.h:23-29`). App applies CLI look args at `render.c:1255-1387`; **world-unit params (fog
  density/far/floor, ssao radius, ssr distances) are set by the scene-scaled block `render.c:1876-1903`
  and must be overridden there, not earlier.**
- SSS: `configure_sss_materials` (`render.c:1178`, called `:1480`) hardcodes a fixture table;
  mechanism = `postfx_add_sss_profile(fx, color, radius)` (`postfx.h:300`, max 8) + tag
  `m->subsurface/subsurface_profile/subsurface_color` (`material.h:64-68`); lookup by
  `find_node_by_name`.
- **No area-light shader path** — `LIGHT_AREA` shades as a point light (`pbr_frag.glsl:963-973`);
  `Light.size` only feeds directional PCSS penumbra. Blender area lights therefore convert to point
  lights in the scene file. Real LTC = future work.
- Probe requires precomputed IBL (`render.c:1973-2059`); `-e` HDR applies at `:1567`; `--sky` at
  `:1482`. Per-light `set_light_size()` exists; CLI `--light-size` is global (`render.c:1795-1801`).
- Scene (single model) loads synchronously at `render.c:1460-1461`; name-based tagging hook right
  after (`:1479-1480`). Camera explicit-pose path (pose + orbit seeding + auto-orbit off + FREE mode):
  `render.c:1928-1950`.

## Scene format v1 — `<name>.cscn`

```json
{
  "version": 1,
  "models": [ { "path": "abandoned_window.glb" } ],
  "environment": { "mode": "hdr", "hdr": "ahornsteig.hdr", "probe_scene": true },  // hdr | sky | none
  "lights": [
    { "name": "BounceFill", "type": "point", "position": [2.4, 1.8, 0.35],
      "color": [1.0, 0.93, 0.76], "intensity": 6.0 }
  ],
  "light_overrides": [
    { "name": "SunKey", "size_from_angle": 0.09 }        // radians; size = tan(a) * scene_radius
  ],
  "post": {
    "tonemap": "agx", "exposure": 0.35,
    "bloom": { "enabled": true, "strength": 0.5, "threshold": 1.0 },
    "fog":   { "enabled": true, "density": 0.012, "anisotropy": 0.25 }
  },
  "materials": {
    "IvyLeafReal": { "sss": { "color": [0.4, 0.9, 0.3], "radius": 0.06 } }
  },
  "camera": { "eye": [-0.02, 1.29, 2.36], "target": [2.12, 1.55, 0.28], "fov": 38.4 }
}
```
- All vectors in glTF Y-up world space. Relative paths resolve against the scene file's directory.
- v1 scope: `models[]` supports exactly one entry (validate; warn and use the first if more). The array
  exists so multi-model scenes are a data change later, not a format change.

## Work items

### 1. Vendor cJSON — `cetra/src/ext/cJSON.c/h`
Single-file MIT lib, same treatment as `cwalk`; register in `cetra/CMakeLists.txt` alongside
`ext/cwalk.c` / `ext/log.c`.

### 2. Engine module — `cetra/src/cscene.c` / `cscene.h` (new)
- `CetraSceneDesc` plain struct mirroring the schema (fixed caps: 4 models, 16 lights, 16 overrides,
  8 material overrides), `bool has_*` flags per field for precedence handling by apps.
- `CetraSceneDesc* cscene_load(const char* path)` — read + cJSON parse + fill + `log_info` summary;
  NULL + `log_warn` on malformed input. Resolves nothing; stores strings as-is plus the scene dir
  (via the `import.c:51` dirname idiom) for the app to resolve relative paths.
- `bool cscene_path_is_scene(const char* path)` — extension test for `.cscn` (case-insensitive,
  matching the `uv_flip_flag` strcasecmp idiom). File content is JSON; the extension marks it as
  cetra's scene format.
- `void cscene_free(CetraSceneDesc*)`. Parsing only; zero application logic.

### 3. Render app — `apps/render/src/render.c`
- **Input handling**: if the `-m`/positional path is a `.cscn` (via `cscene_path_is_scene`),
  load the desc, and use `models[0].path` (resolved against the scene dir) as the model to import.
  Convenience: when given a bare model path, probe for `<model>.cscn` next to it and load if
  present. Print one summary line of what the scene file supplied.
- **Apply with precedence CLI > scene file > defaults** (RenderArgs sentinels/`*_set` flags; add
  given-ness flags where missing — bloom, exposure, tonemap):
  - post/tonemap/exposure/bloom → finishing-look block (`:1353-1387`)
  - fog enable early; density/anisotropy → scene-scaled block (`:1876-1903`), replacing the
    `0.08f/scene_radius` default
  - environment: no `-e` given + `mode:hdr` → set `args.hdr_path` (resolved) before `:1567`;
    `mode:sky` → sky flag equivalent; `probe_scene` → probe args before `:1973`
  - `lights[]`: `create_light` → `set_light_*` → `add_light_to_scene` + node (mirror
    `create_three_point_lights`, `app.c:322`); these count as "model ships lights" for the
    auto-key-light skip
  - `light_overrides[]`: match by name in `scene->lights`; `size_from_angle` applied in the
    scene-scaled section: `set_light_size(l, tanf(a)*scene_radius, same)`
  - `materials{}.sss` → generalize `configure_sss_materials` (`:1178`): scene-file entries take
    priority; hardcoded fixture table remains the no-scene-file fallback
  - `camera` → if `--cam-eye` absent, run the explicit-pose path (`:1928-1950`) + fov

### 4. Blender exporter — `tools/cetra_export.py` (new)
Runs in Blender (Script editor or `blender -b file.blend -P tools/cetra_export.py -- --out assets/name.glb`).
Writes `name.glb` + `name.cscn` (+ copies the world HDR next to them).
- **GLB export** (settings proven this session: `export_yup`, `export_apply`, lights, cameras,
  `use_selection`); excludes: custom prop `cetra_exclude`, `display_type == 'WIRE'`, volume-material
  objects, collection `_cetra_exclude`.
- **Scene-file writer** (`json.dump`):
  - area lights → `lights[]` point entries (world pos Z-up→Y-up `(x, z, -y)`, color,
    `intensity = energy * AREA_TO_POINT_K` module constant)
  - sun lamps → `light_overrides[]` `size_from_angle` from `light.angle`
  - volume objects (Principled Volume node) → `post.fog` (`density * FOG_K`, anisotropy); excluded
    from the GLB
  - world Environment Texture → copy HDR + `environment.mode=hdr`; else `mode=sky`; `probe_scene`
    script toggle (default true)
  - `scene.view_settings.exposure`; view transform AgX→`agx`, Filmic→`aces`, Standard→`neutral`;
    compositor Glare(Bloom) → bloom strength/threshold
  - materials with Principled `Subsurface Weight > 0` → `materials{}.sss` (color from Subsurface
    Radius normalized, radius from weight×scale) + manual-additions dict at script top
  - active camera → `camera` (eye/target/vfov, Y-up)
  - prints a manifest: written, converted, excluded
### 5. Ship the window scene through it
Export via the script (live Blender MCP session) → `assets/abandoned_window.glb` +
`assets/abandoned_window.cscn` (+ HDR), replacing the hand-exported GLB.

## Verification

1. `./build.sh` clean.
2. **Loader pass**: hand-write `assets/light_import_fixture.cscn` (models[0]=fixture gltf,
   tonemap agx, bloom, one sss entry) → `render assets/light_import_fixture.cscn -x` →
   summary log lists applied items; `--tonemap neutral` on the CLI beats the file (precedence).
3. **No-scene-file regression**: `sss_fixture.gltf`, `specular_fixture.gltf`, `room.fbx` unchanged
   (no `.cscn` present → loader no-ops; SSS fixture fallback table still fires).
4. **End-to-end**: run `tools/cetra_export.py` on the window scene in the live Blender session, then
   `./out/bin/render assets/abandoned_window.cscn -x --frames 120 --screenshot ...` with zero
   look flags → ambient fill present, warm point fill restored, fog haze, AgX + bloom, SSS-lit leaves,
   camera auto-framed. Compare against this session's best hand-flagged render.
5. Interactive spot-check: opens framed, GUI radio on Free, no auto-orbit; convenience path
   (`-m assets/abandoned_window.glb` with the cscene beside it) behaves identically.
