# 4.12.1 — SSS follow-ups (cleanup + per-material profiles + TAA)

## Context

Separable screen-space subsurface scattering shipped in 4.12 (diffuse-separation via a gated 5th MRT
attachment `DiffuseOut`; composite `hdr + blur(D) - D` keeps specular sharp). The 4.12 spec closed with
five deferred items. This branch (`sss-v2` off `master`) clears **all five** as end-to-end milestones:

1. **Remove the dead subsurface-texture chain** — `subsurface_scattering_tex` / `subsurface_layer` and
   their mask-array slot are fully dormant (always NULL / -1, no importer, no reader). Pure subtraction.
2. **G-buffer descriptor table** — attachment N is handled across ~11 hardcoded sites; a descriptor
   table collapses them into loops and fixes two latent *missed-site* bugs (the `free_engine` leak the
   review already patched, plus a `create_engine` zero-init that omits the SSS attachment).
3. **Per-material SSS profile** — today the blur radius/color are one per-scene global (last skin
   material wins). Lift to a per-material profile so two skin/wax materials scatter differently.
4. **TAA accumulation** — the SSS delta composites after TAA, so it isn't temporally accumulated.
5. **Cross-material bleed** — the blur's depth bilateral only rejects depth steps, so an off-skin
   surface at near-equal depth adjacent to skin catches a little scatter.

## Recon (verified against source)

- **#3 + #5 are coupled — one mechanism.** Both need per-pixel material identity in the screen-space
  blur. `DiffuseOut.a` (attachment 4 alpha, `pbr_frag.glsl` `DiffuseOut = vec4(subsurface*sssDiffuse,
  1.0)`) is a constant `1.0`, and the blur already binds that texture as `srcTex`/`origTex` but samples
  only `.rgb`. So `.a` is a **free per-pixel carrier** — no new attachment. Once it holds a profile
  index, #3 (per-material radius/color lookup) and #5 (reject taps whose index differs) both fall out.
- **#4 is independent.** `postfx_run` resolves the SSS diffuse pre-TAA (`postfx.c:1440`), TAA resolves
  into `hdr_fbo` (`:1449-1471`), then the SSS composite additively folds `blur - D` into `hdr_fbo`
  **after** TAA (`:1625` → the `postfx_run_sss` `glBlendFunc(GL_ONE, GL_ONE)` fold). No material
  identity involved — pure ordering.
- **#1 removal is clean.** `*_layer` slots are data-driven: `mask_layer_for` (`mask_array.c`) returns
  -1 for a NULL/zero-id texture *without* incrementing `count`, and `subsurface_scattering_tex` is the
  last (always-NULL) entry in the build loop, so deleting it does **not** renumber the six live layers
  (roughness/metallic/ao/opacity/microsurface/anisotropy). Write-only `subsurface_layer` has no reader
  (no `subsurfaceLayer` uniform); the shader samples only six mask layers.
- **#2 site inventory (~11):** `engine.c` zero-init (`:87-90`, omits `sss_diffuse` — the second missed
  site), `free_engine` teardown (`:216-220`), `_destroy_msaa_attachments` (`:349-359`),
  `_create_msaa_attachments` + `GL_MAX_DRAW_BUFFERS` guard (`:384-408`), `engine_set_scene_draw_buffers`
  `[5]` arrays (`:1653-1664`), per-frame gating + `glClearBufferfv` (`:1832-1870`); `postfx.c` resolves
  (`:1406-1495`). The two scene-MRT shaders (`pbr_frag`, `catcher_frag`) stay hand-authored but must
  match the table.

## Design

- **M1 — dead-chain removal.** Delete `subsurface_scattering_tex` (decl/init/free/setter) and
  `subsurface_layer` (decl/init/assign); `MASKS_PER_MATERIAL` 7→6 + fix the layer-list comment. No
  shader change. Byte-identical (dead-code subtraction).
- **M2 — descriptor table.** A `struct GBufferAttachment { GLuint* tex; GLenum internal_format; GLenum
  attachment; bool* this_frame; GLfloat clear[4]; }` array indexed 0..4, iterated for
  create/destroy/draw-buffers/clear/resolve. Attachment 0 (HDR) keeps its `glClear` path; 1..4 loop.
  Byte-identical; net-reduces `engine.c`.
- **M3 — per-material profile.** A small `sssProfiles[N]` uniform block (per-channel radius/color) on
  the blur program, populated from each SSS material (replacing the per-scene `sss_radius`/`sss_color`
  globals and `configure_sss_materials`' last-material-wins write). `pbr_frag` writes the material's
  profile index into `DiffuseOut.a` (**`FragColor` untouched**, new write guarded). `sss_blur_frag`
  reads center `.a` → index → per-channel radius/color, replacing the frame-global `sssRadius`/
  `sssColor` sampling. Multi-material fixture with 2+ distinct SSS materials.
- **M4 — cross-material reject.** In the bilateral, add `tapIndex == centerIndex` to the tap weight
  (reject when the profile differs). ~5 lines atop M3's channel.
- **M5 — TAA accumulation (droppable).** Fold the SSS `blur - D` into `hdr` **before** the TAA resolve
  instead of after, so the scatter is temporally accumulated. Preserve fog/SSS/TAA relative order.

## Byte-identity strategy

- OFF gate `--no-sss` stays `cmp`-exact vs master across every milestone.
- M1/M2 are refactors: byte-identical **with SSS on** too (non-multi-material scene), since behaviour is
  unchanged.
- M3 edits `pbr_frag` (`DiffuseOut.a`): leave `FragColor`'s expression/grouping byte-for-byte unchanged,
  guard the new write; isolate + document any sub-ulp OFF-path drift via `git checkout master --
  cetra/shaders/pbr_frag.glsl` + rebuild (the shipped-SSS discipline).

## Risks

1. **M2 touches every g-buffer attachment** — an inconsistent entry breaks all assets; keep each
   milestone OFF byte-identical and resolve all 5 through the same loop. Highest blast radius, high
   value (fixes two latent missed-site bugs).
2. **`DiffuseOut.a` index through MSAA resolve** — edge pixels get an averaged index at 1-px material
   seams (conservative reject for M4; imperceptible radius blend for M3). Headless-MSAA only; live 1×
   MSAA has no resolve averaging.
3. **M5 reorder** — moving the composite ahead of TAA reshuffles fog/SSS/TAA order; verify no fog/DoF
   regression, drop the milestone if it destabilizes (payoff unverifiable headless).
4. **File size** — `postfx.c` (~1.7k) grows with M3/M5; `engine.c` should shrink under M2. Extract
   helpers before either sprawls.
