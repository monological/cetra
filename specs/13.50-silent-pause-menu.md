# Spec 13.50: silent's pause menu -- Resume, Settings, Quit to Title, Exit to Desktop

## Context

silent has no in-game menu. Escape only frees the mouse when nothing is open, or closes the bag or
the map. Spec 13.49 gave silent saves and a title. The user now wants an Escape menu that pauses the
game.

**What the user chose:**
- **The Escape menu holds Resume, Settings, Quit to Title and Exit to Desktop,** and it freezes
  everything, the rain included. New Game and Load stay on the title.
- **The title gains Settings and Exit to Desktop** under Load Game.
- **Settings holds:**
  - one Volume slider (silent plays everything on the effects bus and has no music);
  - Display: window mode and vsync;
  - Look: sensitivity and invert;
  - Field of view.
- **The title keeps its 13.49 behaviour:** the game is held while the weather keeps moving.

**What exploration found:**
- **Taking the bag or the map deletes its node.** A played world cannot be put back, so Quit to
  Title followed by New Game would keep the flashlight and the map, and so would a Load. Both takes
  must become reversible.
- **Some state survives a load,** none of it in a save:
  - the cat's brain internals: its RNG, cooldowns and stale latches such as `want_stretch` and
    `startled`;
  - the HUD's thought, hint and save mark;
  - `cursor_wanted`;
  - the basement drip's `next_drip`;
  - door and cat poses, which are drawn a step late while the game is held.
- **The engine's settings** (`cetra/src/game/settings.c/h`, `settings_apply`) already do volume,
  window mode, vsync, FOV, look scale and invert, and applying twice is safe. But:
  - its one `settings.json` is shared by every app;
  - it applies look to whichever rig is installed, which at the title is the title's rig.
- **silent un-pauses every frame while playing** (`hold_game(game, !playing)`), so the pause has
  to go into that rule.

## Design

### The pause menu (`apps/silent/src/pause_menu.c/.h`, new)

**The screens.** A modal screen built like the title:
- `hud_modal_screen` with a dim backdrop;
- items drawn as words on nothing, with a plate behind the focused one.

The item drawing moves out of `title.c` into `hud.c` (`hud_item`) so both screens use it.

**The items:**
- **Resume** closes the menu.
- **Settings** opens the settings screen, which is opaque over the menu.
- **Quit to Title** appears only on a run that has a title.
- **Exit to Desktop** calls `game_quit`. `on_shutdown` writes the quit save, since the run is still
  playing.

**The keys.** A new non-UI action, `pause_menu`: Escape and pad Start.
- **Opening:** it opens the menu while playing with nothing up. Being non-UI, it reads nothing
  while the bag or the map holds the input, so there Escape stays their back.
- **Closing:** Escape and B use the UI's own back, as the bag does. Start is `menu_accept`, so on
  Resume it closes the menu too.
- **The cursor:** `release_cursor` loses Escape. The menu frees the cursor, because input is held,
  and resuming takes it back.

**The pause.** `hold_game` becomes a three-way rule:
- not playing: the game is held, and `g_held_clock` is the render clock (13.49, unchanged);
- playing with the menu up: frozen. `game_pause`, the sim clock stays the render clock (so the rain
  freezes), and `look_dt` is 0;
- otherwise: played.

### Settings (`apps/silent/src/settings_menu.c/.h`, new)

**The file.** It is silent's own: `save_default_path(path, cap, "silent-settings")`, which gives
`<per-user dir>/silent-settings.json` and honours `CETRA_SETTINGS_DIR`. It goes through the engine's
`settings_load` and `settings_save`, so gametest's file is untouched.

**Startup.**
- The file is loaded in `main` before `create_game`. The window mode, monitor and vsync go into
  `EngineConfig` for windowed runs, so the window opens as chosen.
- `fov_degrees == 0` loads as 68, silent's current FOV, so the slider shows what the player sees.
- `apply()` runs `settings_apply(&s, audio, engine)` (volume, FOV, window, vsync), then writes
  `look_scale` and `invert_pitch` onto `g_player.rig` itself.
- It is applied once audio exists and before `--mute`, so the flag still wins. `--fov` wins over the
  file.

**The screen.** One screen, opened from the title or the pause menu; it is opaque, and back returns
to where it was opened from. Its rows are the engine's own elements, so input and focus are the
UI's, drawn in silent's look with `ui_set_draw`:
- Volume: a slider, 0 to 1;
- Display: a selector, windowed, fullscreen or borderless;
- VSync: a toggle;
- Look speed: a slider, 0.25 to 3;
- Invert look: a toggle;
- Field of view: a slider, 50 to 100;
- Back.

Each row is its label on the left and its value on the right. A slider's track is drawn where the
element's drag maps the pointer (`ui.c`'s `_slider_track`).

Every edit applies at once. The file is written when the screen closes, by any route; gametest's
`ui_settings_dirty` is the pattern to follow.

### The title (`title.c`)

- **Settings and Exit to Desktop** go under Load Game. Exit asks silent to quit through a `quit`
  choice, which silent reads like the others.
- **The rig is installed when the title is shown** (`title_show(t, engine)`), so a return to the
  title puts it back. A titled run still installs it at init, so the view loads round the title's
  eye.

### Quit to Title and the world put back

**The flow.** A new run state, `RUN_RETURNING`.
1. **Quit to Title:**
   - writes the save now, with `save_game_quit`, so closing the window mid-fade loses nothing;
   - stops autosaving, with `save_game_begin(NULL)`;
   - pops every screen down to the HUD.
2. **The fade.** `RUN_RETURNING` is not playing, so the game is held, the weather moves and the
   view fades to black.
3. **At black:** `reset_world()`, then the title's rig, then `title_show` and `RUN_TITLE`. The title
   reads the games again, so the one just saved is Continue.

**`reset_world()`,** in `silent.c`:
- **The cat's mind, made afresh.**
  - `entity_remove_component(cat->entity, COMPONENT_BRAIN)` frees the brain, and
    `cat_mind_create` is called with the run's seed, as at init.
  - The save's rows point into `g_mind` by address, so they stay valid.
  - This resets the RNG, the cooldowns and every latch in one place.
- **The world's start, loaded:** `save_game_load(SAVE_GAME_START)`. This is a snapshot written at
  the end of `on_init` (`save_game_write_start()`) for runs that have a title. It is outside
  silent-1 to silent-8, so the list never shows it.
- **The HUD cleared:** a new `hud_clear` empties the thought, the hint and the save mark.
- **The cursor let go:** `player_release_cursor`. A fresh run takes the cursor on a click.
- **The basement's drip:** a new `basement_reset_drip` puts back its first-drip timer and its seed.
- **The poses brought up to date:** `sync_entity_transforms(game->entity_manager)`, so the doors and
  the cat are drawn where they now are while the game is held.

**The takes become reversible.** This is also what makes a Load over a played world right.
- **The bag:**
  - `backpack_take` detaches the bag's node, with `node_remove_child`, and keeps it.
  - `backpack_restore(…, taken = false, …)` puts it back under the scene's root and clears `taken`,
    `held`, `cell` and `rows`.
  - `backpack_free` frees a detached node.
- **The map:**
  - `FridgeMap` gains `taken`.
  - `fridge_map_take` detaches its node, and a new `fridge_map_put_back` reattaches it.
  - The reach offer keys on `!taken` instead of on the node.
  - A new `fridge_map_free` is called in `on_shutdown`.
- **`apply()` puts the map back** when the bag does not hold it, and otherwise takes it as now.

New Game from the title still loads nothing: after a reset, or on a first launch, the world is
already its start.

### Headless flags

`--pause-screen menu|settings` opens the pause menu, or settings over it, once the game is played,
for a headless picture. It works like `--title-screen`.

  Exit.

  - the rain is the same in two frames while the menu is up, and moves again after Resume;
  - a settings edit lands in `silent-settings.json`, and the next run reads it back;
  - Quit to Title then New Game gives the world its start, read from the saves.

## Not in this spec

- Music.
- A UI volume.
- Reduce motion: silent has no camera shake.
- Key rebinding.
- A monitor picker.
- A confirm on quitting: every way out saves first.

## As built

### Phase 1: the pause menu and the freeze

**The menu,** `pause_menu.c/.h`.
- **The screen:** a modal screen dimmed to 0.45, with "Paused" over Resume and Exit to Desktop.
- **Resume** pops the screen, the same as the UI's back on Escape or B.
- **Exit** leaves a `PAUSE_EXIT` choice, which silent takes after the UI's pass and answers with
  `game_quit`. The quit save follows, since the run is still playing.

**The items are one look.** `hud.c` holds what the title had to itself:
- `hud_item`, `hud_item_shown`, `hud_column` and `hud_words`;
- the item colours, exported as `HUD_ITEM_FG`, `HUD_FOCUS_FG`, `HUD_DISABLED_FG` and
  `HUD_HEADING_FG`.

The title now uses them.

**The keys.**
- **`pause_menu`** is a game action on Escape and pad Start. It reads nothing while a screen holds
  the input, so Escape there is still that screen's back.
- **The menu goes up after the UI's pass.** Start is also `menu_accept`, and before the pass the
  press that opened the menu would have chosen Resume on the same frame.
- **`release_cursor` is gone,** along with its read in `player.c`. The menu frees the cursor by
  holding the input, and the cursor comes back when the menu goes.

**The hold has three states,** chosen at the end of the frame input, once the frame's screens are
known:
- **`HOLD_PLAYED`;**
- **`HOLD_FROZEN`:** the game is paused, and the sim clock stays the render clock, so the rain hangs
  in the air;
- **`HOLD_HELD`:** 13.49's held clock.

`look_dt` and `look_time` now key on `g_looking`, the held clock being installed, rather than on
the pause. While frozen they read the sim, which stands still.

**The fade eases by the frame's own length** (`frame_dt`, the UI's rule: a fixed step headless, the
wall clock windowed). It used to ease by the sim's frame clock, which is 0 while paused, so a menu
up during the fade-in left the world black behind it; `--pause-screen` showed exactly that.
`hold_game`'s held clock now takes its step from `frame_dt` too.

**`start_play()`** is the one way into `RUN_PLAYING`, from loading or from the black, and opens the
menu when `--pause-screen menu` asks for a picture of it.

**Checked headless,** outdoors at -40,0, with the menu up from the start:
- Two frames 20 apart, after the fade had finished, differ by 1.8% of their pixels. The amplified
  difference is black but for a few specks at the lamp heads.
- After Resume, two frames differ by 11.9%, the difference all rain streaks.
- Exit to Desktop (down, then A) quit at once, with only frame 50 written of 400, and wrote the save
  on the way out.
