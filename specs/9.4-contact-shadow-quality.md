# Contact shadows, done right — full-res, coherence-gated march

## Context

Screen-space contact shadows (spec 9.3) work — they ground objects — but on hard-edged
geometry viewed close-up they show a **dithered stipple tracing every silhouette / depth
discontinuity** (confirmed by rendering the raw term: a dotted grey rim hugging cube edges,
while the one legitimate hit — a cube shadowing the next — shows as a solid bar). This is the
worst-case for the technique (plain matte cubes filling the frame), but it's a real artifact.

Root cause (diagnosed, not guessed): near a silhouette a marched sample straddles a depth
cliff at essentially **one** step; whether that step's jittered `t` lands on the near or far
side flips with the IGN phase → a single-sample, jitter-dithered false hit. Half-res output +
bilinear upsample smears each spike into the visible stipple. Raising `bias` 6× did nothing
(it is not a small-diff self-occlusion), confirming the mechanism.

This is the "do it right" rebuild — the way robust SSCS (UE4/Frostbite-class) is actually
built within our constraints: **full resolution + a coherence-gated march + direct-light
weighting**, all pure fragment-shader gather work (no compute needed — the compute/RT ceiling
only blocks Virtual Shadow Maps / RT shadows, which stay out of scope). Target quality bar:
clean, correct contact shadows equivalent to a good UE4-era game. NOT UE5/VSM (that needs
compute we don't have).

## The core fix: coherence, not magnitude

Grounding (`plane behind cube`) lands `diff ≈ object height H` — large and O(scene),
immediately, with no upper bound consultable (that's why every thickness slab killed
grounding). A silhouette→background jump is *also* a large-`diff` hit. The two populations
**overlap in magnitude**, so no threshold (nor a normal fetch) separates them. What does:
**grounding/cube-shadows-cube are continuous occluders (a run of consecutive hit steps); the
silhouette straddle is a lone spike unconfirmed by its neighbor.** Require ≥2 consecutive hits.

## Verified facts (current master)

- **Resolutions** (`postfx.c:214-221`): full internal `fx->width/height`; half `fx->ssao_width/
  ssao_height`. The march already samples the **full-res NEAREST** aux depth (`aux_texture`,
  RGBA32F, `postfx.c:405-415`) as `linDepthTex` — only the OUTPUT is half-res today.
- **Current contact plumbing**: targets `postfx_ensure_contact_targets` (`postfx.c:681-694`) —
  `cs_fbo[2]/cs_texture[2]` R8 + `cs_history` R16F, all at `ssao_width/ssao_height`; run block
  `postfx.c:1648-1707` (march → `ssao_blur` reuse → `run_temporal_accum` when `taa_resolving`);
  composite folds into `aoFactor` at `tonemap_frag.glsl:258-259` (`csTex` unit 10).
- **Full-res precedents**: SSR picks res from a flag in `create_ssr_buffers` (`postfx.c:74-111`)
  and reallocs via `postfx_set_ssr_full_res` (`postfx.c:127-133`); `taa_history` is a full-res
  PingPong (`postfx.c:422`) driven by `run_temporal_accum(...fx->width, fx->height...)`
  (`postfx.c:1623`); SSS accumulates full-res too (`postfx.c:876`).
- **`run_temporal_accum(fx, prog, pp, w, h, tex)`** (`postfx.c:1176`) takes w/h — runs at any
  res; its PingPong must match.
- **Blur texelSize is STATIC AO-res** (`postfx.c:564-565`), shared by the GTAO AO blur and the

  (`postfx.c:1207-1208`), fog (`postfx.c:1320`).
- **Direct-light dir is NOT in tonemap** — the contact shader computes `ndl = dot(n,
  lightDirVS)` itself (`contact_shadow_frag.glsl:61`); the term already carries the N·L ramp.

## Design

### 1. Shader — `contact_shadow_frag.glsl` (the rebuild)
Keep verbatim: `viewPosFromLinZ` reconstruction, the N·L cull (`ndl < 0.05 → lit`), the
normal-offset ray start (`startV = P + n*max(0.02, 0.01*(-P.z))`), the near-plane `tMax` clamp,
the `MAX_UV_LEN` screen-reach clamp, the deterministic IGN jitter (frozen when `temporal==0`).

Replace the single-sample accept with a **2-consecutive-hit run gate**, `STEPS = 16`:
- Per step: `occluder = (sceneZ < SKY_Z) && (sceneZ - rayZ > bias)`, `bias = BIAS_FRAC*csDistance
  + 2*zGrain` (**no upper bound** — keep it absent).
- Track `run` (consecutive occluder count). On the FIRST hit of a run remember `hitT`/`hitUV`.
  `run >= CONFIRM (2)` → break, confirmed. **Sky or a miss resets `run = 0`** (a lone spike
  never confirms; the run must count *contiguous* surface, so sky BREAKS the run — replaces the
  old `continue`).
- Commit `occ = distFade(hitT) * screenEdgeFade(hitUV) * smoothstep(0.05, 0.25, ndl)` measured
  at the first sample of the run (true contact point). `visibility = 1 - occ`.

Why it works: silhouette spike = one ambiguous step, neighbor not an occluder → never reaches 2
→ discarded regardless of jitter. Grounding/cube-shadows-cube = the wall fills many consecutive
steps → confirmed; large `diff` irrelevant (no bound). `STEPS 8→16` is load-bearing: at full
res the same UV reach is 2× the texels, so a genuine wall reliably spans ≥2 samples while a
1-texel cliff spans ≤1 (with 8 coarse steps a real thin contact could fall in one step and be
wrongly rejected). Note `fwidth(linZ)` halves at full res (tighter), so the `zGrain` term
shrinks and `BIAS_FRAC=0.02` dominates — keep 0.02 (nudge to 0.015 only if the terminator case
needs it).

### 2. Full-res plumbing — `postfx.c`
Contact shadows are a *sharpness* feature, so run the pass at full internal res (no half-res
option — simpler than SSR's toggle):
- `postfx_ensure_contact_targets`: allocate `cs_fbo[2]/cs_texture[2]` (R8) and `cs_history`
  (R16F) at `fx->width/fx->height` instead of `ssao_width/height`.
- Run block: viewport `fx->width/height`; `run_temporal_accum(..., &fx->cs_history, fx->width,
  fx->height, ...)`.
- **Blur texelSize per-draw**: before the contact `ssao_blur` draw set `texelSize = {1/width,
  1/height}`; before the GTAO AO blur draw set `texelSize = {1/ssao_width, 1/ssao_height}` (make
  it per-draw in both — the `run_atrous`/fog precedent — since the two consumers now differ in
  res and the contact block runs first). No new struct fields; `cs_fbo/cs_texture/cs_history`
  already exist (`postfx.h:150-156`).

### 3. Composite / direct-light weighting — no change
The shader's `smoothstep(0.05, 0.25, ndl)` already makes the term vanish off the lit hemisphere
— the right "direct-light only" proxy for a post pass. **Honest limitation (documented, not
fixed):** tonemap folds `cs` into `aoFactor`, which multiplies the fully composited HDR, so the
contact gap darkens ambient/IBL too — benign (a real gap *is* ambient-darker, that's AO) and
subtle at `csStrength=0.6`. True direct-only would need a separated direct-light buffer the
forward renderer doesn't produce; not worth it. Composite stays as-is.

## Cost & honest residuals

- **Cost**: full-res + 16 steps is ~8× the per-pixel march work of the old half-res 8-step
  pass (4× pixels × 2× steps). Correct tradeoff for a sharpness feature, and it's default-off,
  but note it — this is the price of "done right" in screen space.
- **Thin occluders** (< ~2 texels of screen width — a wire, a thin rod) under-shadow: the run
  gate trades them away to kill the stipple. Acceptable for the target content; documented.
- **Ray nearly parallel to and just inside a foreground edge** can make a genuine 2-sample run
  → a *thin solid* rim (no longer stippled) — rare, thin, further attenuated by the edge-aware
  blur + `distFade`. Not fully eliminable in screen space (a marched sample can't know a near
  occluder is a silhouette vs a real blocker without off-screen data).
- **Direct/ambient inseparable** in a post multiply (§3). Inherent; benign.
- **Ceiling**: this reaches UE4-era-clean. UE5/VSM-class shadow *detail* needs compute/RT we
  don't have at GL 4.1 — out of scope, unchanged by this work.
