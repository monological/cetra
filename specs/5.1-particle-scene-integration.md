# Plan: Particle systems as scene citizens (node-attached, engine auto-ticks + renders)

## Context

The particle system (`specs/5.0-particle-system.md`, shipped M0–M4 + cleanup on the
`particles` branch) works, but its **integration is at the wrong altitude**. Today the app
owns a free-standing `ParticleSystem`, ticks it in `on_update`, and hand-draws it in
`on_render` with ~15 lines of order-sensitive GL (depth resolve + blend-state set/restore).
That is not how modern engines work: in Unreal/Unity/Godot a particle system is a
**scene entity with a transform** (a component/node), and the renderer ticks and draws it
**automatically** — the app just places it and forgets.

This change makes cetra's particle system a first-class scene citizen, mirroring how a
`SceneNode` already holds a `Light*`/`Camera*`:

```c
// setup: attach and forget
ParticleSystem* sys = create_particle_system("spores");
... configure emitter ...
SceneNode* n = create_node();
set_node_particle_system(n, sys);          // like set_node_light
add_child_node(scene->root_node, n);
add_particle_system_to_scene(scene, sys);  // like add_light_to_scene (scene owns it)
// on_update / on_render: nothing -- the engine ticks + draws it.
```

This is the "engine-side hook" the spec deferred to M5; it supersedes that item and the
`engine_render_particle_system` helper idea. Scope = **transform-at-spawn / world-space
sim** (emitters spawn in their node's world frame, then live in world space). Full
local-space simulation (a cloud rigidly following a fast-moving node) is a later per-emitter
mode, not in this change.

## Design

- **`SceneNode` borrows, `Scene` owns.** A node holds an optional `ParticleSystem*`
  (borrowed, like `Light*`); the `Scene` owns a `ParticleSystem**` list and frees each one
  exactly once in `free_scene`. `free_node` leaves the node's pointer alone (matches the
  existing `Light`/`Camera` ownership comment at `scene.c:561-563`).
- **The system back-refs its node** for the spawn transform. Each tick, the system copies
  `node->global_transform` into each emitter's `local_to_world`; `init_box_location` spawns a
  local point and transforms it by `local_to_world` into world space.
- **Engine auto-ticks** in `run_game`'s fixed-timestep loop and **auto-renders** in
  `render_current_scene`. The app's manual tick/draw and the GL bracket disappear.
- **Timing (accepted):** during the fixed-timestep tick, `node->global_transform` is the
  previous render frame's (only `original_transform` is fresh — `apply_transform_to_nodes`
  runs at render time). One-frame spawn-origin latency; irrelevant for the static demo node,
  standard for moving emitters.

## Changes (files, with the pattern to mirror)

**`cetra/src/scene.{h,c}` — the ownership + attachment (mirror `Light` exactly)**
- `scene.h`: forward-declare `struct ParticleSystem;`. Add `ParticleSystem* particle_system;`
  to `SceneNode` (by `Light* light;`, `scene.h:37`). Add `ParticleSystem** particle_systems;
  size_t particle_system_count;` to `Scene` (by `lights[]`, `scene.h:88`). Declare
  `set_node_particle_system(SceneNode*, ParticleSystem*)` and
  `add_particle_system_to_scene(Scene*, ParticleSystem*)`.
- `scene.c`: `#include "particle_system.h"`. Init `node->particle_system = NULL` in
  `create_node` (`scene.c:528`). `set_node_particle_system` one-liner that also sets
  `sys->node = node` (mirror `set_node_light`, `scene.c:609`). `add_particle_system_to_scene`
  = copy of `add_light_to_scene` grow-by-one (`scene.c:268-283`). In `free_scene`, add a loop
  freeing `scene->particle_systems[i]` via `free_particle_system` + `free(scene->particle_systems)`,
  next to the lights loop (`scene.c:102-110`). **Do not** touch it in `free_node`.

**`cetra/src/particle_system.{h,c}` — node back-ref + spawn-transform sync**
- `particle_system.h`: forward-declare `struct SceneNode;`. Add `struct SceneNode* node;`
  (borrowed; NULL = world origin) to `ParticleSystem`.
- `particle_system.c`: `#include "scene.h"`. In `particle_system_update`, before
  `backend->simulate`, if `s->node` copy `s->node->global_transform` into each
  `emitter->local_to_world`.

**`cetra/src/particle_emitter.{h,c}` — re-add `local_to_world` (now with real use)**
- Re-add `mat4 local_to_world;` to `ParticleEmitter` (removed in the /simplify pass as dead
  — it exists for exactly this). Init to identity in `create_particle_emitter`.

**`cetra/src/particle_module.c` — spawn in the emitter's world frame**
- `init_box_run`: generate the local point as today, then transform by `e->local_to_world`
  (`glm_mat4_mulv3(e->local_to_world, local, 1.0f, e->pool->position[i])`). Identity ⇒
  byte-identical to today.

**`cetra/src/render.c` — auto-render** (`#include "particle_system.h"`; `scene.h`/`engine.h`
already present)
- New block at **`render.c:739`** (after the transparent pass `}` at 738, before the
  shadow-catcher), gated on `scene->particle_system_count > 0`. It owns its own bracket
  (state there is depth-write ON, color-only FBO, blend enabled): `engine_resolve_scene_depth`
  once → `glDepthMask(GL_FALSE)` + premultiplied `glBlendFunc(GL_ONE, GL_ONE_MINUS_SRC_ALPHA)`
  → build `ParticleRenderContext{view=engine->view_matrix, proj=engine->draw_projection,
  scene, scene_depth_texture=depth}` → loop `particle_system_render` → restore
  `glDepthMask(GL_TRUE)` + baseline `glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)`. This
  is exactly the block moved out of `spores.c:185-202`.

**`cetra/src/game/game.c` — auto-tick** (`#include "../particle_system.h"`)
- New block at **`game.c:255`** (after the `on_update` callback, inside `while (accumulator >=
  fixed_timestep)`), guarded like the physics step: `if (game->scene) for i in
  particle_system_count: particle_system_update(scene->particle_systems[i], fixed_timestep,
  game->time);`.

**`apps/spores/src/spores.c` — become "attach and forget"**
- `on_init`: keep the system/emitter/renderer creation; then create a node (at origin,
  identity ⇒ look unchanged), `set_node_particle_system(node, sys)`, `add_child_node`,
  `add_particle_system_to_scene(scene, sys)`.
- **Remove**: the `on_render` particle block (185-202), the `on_update` tick (159-162) and its
  `game_set_update` registration, the `on_shutdown` `free_particle_system` (207-210, scene owns
  it now — else double-free), and the `g_sys` global.

## Reuse (don't reinvent)
- Attachment/ownership → `add_light_to_scene` (`scene.c:268`), `set_node_light` (`scene.c:609`),
  the `free_scene` lights loop (`scene.c:102`), the `free_node` borrowed-pointer comment
  (`scene.c:561`).
- Draw bracket → moved verbatim from `spores.c:185-202`; `engine_resolve_scene_depth`
  (`engine.h:266`) already re-binds the scene FBO. `ParticleRenderContext` is "GL + Scene only"
  by design (`particle_renderer.h:12`), and render.c is the intended host.
- Tick → the guarded-physics-step shape (`game.c:264`).

## Risks / notes
- **Header cycle** — avoided by mutual forward declarations (`struct ParticleSystem;` in
  scene.h, `struct SceneNode;` in particle_system.h); only the `.c` files include the full
  headers.
- **Double-free** — the app must stop freeing the system once the scene owns it.
- **Auto-tick is game-loop only** — apps using `run_engine_render_loop` (not `run_game`) will
  auto-*render* particles but not auto-*tick* them (no fixed-timestep). Fine for spores;
  noted for future.
- **`space`/`PARTICLE_SPACE_LOCAL`** stay deleted — this change is world-space sim with a
  spawn transform; the local-space mode is a separate future addition.
