# 11.24 — Output dither / debanding

Roadmap item **E1** (Tier 4, `docs/aaa-rendering-roadmap.md`).

## Context

There is no dithering anywhere at the engine's 8-bit write. `tonemap_frag.glsl` gamma-encodes
with `displayEncode` (`pow(1/2.2)`, line 142), optionally adds grain, and writes `FragColor`
straight into `target_fbo` — which `postfx.h:553` documents as `0 = default framebuffer`, an
8-bit backbuffer. Anything with a shallow gradient quantizes to contour bands: sky, froxel
fog, bloom falloff, the inside of a DoF bokeh. Screenshots read that same buffer back with
`glReadPixels(GL_RGB, GL_UNSIGNED_BYTE)` (`engine.c:1530`), so every golden in the repo
already stores the banded result.

The fix is a triangular-PDF dither of ±1 LSB added after the gamma encode and immediately
before quantization. It ships **on by default**, matching `--vignette`, which is the existing
precedent for a default-on finishing stage.

Intended outcome: smooth gradients stay smooth at 8 bits; `--no-dither` reaches the old frame
exactly.

## What exploration settled before any code

- **Reuse `ign()` from `cetra/shaders/include/noise.glsl`.** Interleaved-gradient noise
  (Jimenez 2014), already in the tree, and its own header comment says: *"New stochastic code
  includes this file rather than inlining another copy of the hash."* This is the B8 lesson —
  a whole feature built beside an existing one because nobody looked — applying directly.
- **The dither must be STATIC — no per-frame seed.** The one non-obvious finding, and it is
  load-bearing. `_taa_churn` (`scripts/gates.py:1434`) measures frame-to-frame differing pixel
  counts on final framebuffer captures, and several gates compare a measured churn against a
  floor arm (`churn <= floor * DIR_CHURN_FACTOR + DIR_CHURN_SLACK_PX`, `gates.py:1940`). An
  animated dither would add ~50% of the frame churning by 1 LSB to **both** arms, inflating
  floor and measurement together until the ratio test passes trivially. That is exactly the
  "arm that cannot fail" failure this repo has been bitten by twice (11.21's `off is off`,
  11.22's `hole`). A dither that is a pure function of `gl_FragCoord` contributes exactly zero
  churn and every existing gate keeps its meaning.
- Placement is after `displayEncode` **and** after grain. Grain is sensor noise in display
  space; dither must be the last thing before quantization.
- Debug views return early from `main()` (lines 277-303), so they stay un-dithered. Correct —
  they are data, not images.
- No `GL_FRAMEBUFFER_SRGB` anywhere, so the encode is the manual `pow(1/2.2)` and 1 LSB is
  literally `1.0/255.0` in the shader's own units.
- Grain inlines its own `fract(sin(dot(...)))` hash instead of using `ign`. Observation only,
  **not in scope** — touching it would move the look of a shipped default-off effect.

## Phase 0 — prove the defect before fixing it

A fixture is a claim and must be measured (11.21). Before any code, render a sky-gradient
fixture on the current build and measure the banding.

Metric: along a scanline crossing the gradient, the **longest run of an identical 8-bit
value**. Banding means long runs separated by 1-LSB steps — the contour lines.

**If the runs are already short, stop and report.** E1 is then not worth doing, and that is a
cheap thing to find out.

## Implementation

### `cetra/shaders/tonemap_frag.glsl`

`#include "noise.glsl"`; two uniforms beside the grain block (`ditherEnabled`,
`ditherStrength` in LSB, 1.0 = textbook TPDF); an ~8-line block at the end of `main()` after
grain:

```glsl
float d = ign(gl_FragCoord.xy) - ign(gl_FragCoord.xy + vec2(37.0, 17.0));
color += d * ditherStrength * (1.0 / 255.0);
```

**Checkpoint, not an assumption:** `ign` is a structured plane function, not a hash, so two
offset samples are not guaranteed independent — the difference may come out patterned rather
than triangular. The Phase-0 metric re-run is what decides this. If the pattern shows, the
subtrahend moves to a second decorrelated source and this spec records that it did.

### `cetra/src/postfx.h` / `postfx.c`

Two fields beside `grain_enabled` / `grain_strength` (`postfx.h:393`); defaults
`dither_enabled = true`, `dither_strength = 1.0f` (`postfx.c:627`); uniform upload beside the
grain uniforms (`postfx.c:3217`). **Not** added to `postfx_apply_film_look` — dither is a
correctness stage, not a look.

### `apps/render/src/render.c` and `cetra/src/gui.c`

`--dither <lsb>` / `--no-dither`, mirroring `--vignette` / `--no-vignette` exactly. One
`_begin_effect_group("Dither", ...)` in the existing Finishing header beside Grain.

## Verification

1. **Off-gate:** `--no-dither` vs a build of the base commit → **0 differing pixels** on the
   raiden recipe. Same-build noise floor measured first.
2. **Three gate arms, each able to fail** (11.22's structure):
   - **`band-run`** — the Phase-0 longest-run metric with dither on must collapse from the
     recorded before-value. The arm that decides the item.
   - **`band-linearity`** — strength 4.0 must widen the local value histogram measurably more
     than strength 1.0. Without it, a C-side short-circuit makes on and off take the same path
     and the gate passes against a dead feature (11.21 shipped exactly that arm).
   - **`band-inverse`** — assert the un-dithered render *does* band, so the gate fails if the
     fixture stops being a gradient (11.22: all six MSM arms passed silently when the feature
     bailed, because that frame *is* the off case).
3. **Churn unchanged.** An existing churn gate re-run before and after must report the same
   numbers — the empirical proof that "static, not animated" worked.
4. **Golden re-bake — all 19.** Every `assets/*_golden.png` stores the banded 8-bit result and
   moves by ≤1 LSB. Re-rendered and committed on this branch; leaving them stale would break
   the *next* feature's verification, not just this one. Each new PNG confirmed 0 px against a
   second run of the same build before being committed.

## As built

Shipped as planned, with one construction replaced before it reached the shader and three
recorded facts about the golden corpus that did not survive contact with it.

### The measurement that decided the item

`aerial_fixture` at 800x500 (1600x1000 on the retina backing store), longest run of one 8-bit
value down a column:

| dither | longest run | runs >= 8 px per column-channel |
|---|---|---|
| off | **192 px** | 54.0 |
| 0.5 LSB | 134 px | — |
| **1.0 LSB (default)** | **22 px** | **13.4** |
| 2.0 LSB | 4 px | — |

The 0.5 row is why the default is 1.0 and not less: half amplitude barely moves the number.
No run sat at a clipped 0 or 255 in either arm, so none of this is the letterbox.

### The plan's TPDF construction was wrong, and cheap arithmetic caught it

The plan proposed `ign(p) - ign(p + c)` and flagged it as a checkpoint rather than a fact.
It is wrong. `ign` is `fract(52.98 * fract(dot(p, k)))` — a sawtooth riding a linear ramp — so
a constant offset shifts only the sawtooth's phase. Two phase-shifted sawtooths at one
frequency give a **four-level staircase**, not a triangular distribution. Evaluated over a
400x250 grid before any shader was touched:

| construction | distinct values | sd | shape |
|---|---|---|---|
| single `ign`, centred | 10001 | 0.289 | flat (RPDF), correct |
| `ign(p) - ign(p + c)` | **4** | 0.344 | three spikes — unusable |
| `ign(p) - ign(p.yx * s + c)` | 18397 | 0.408 | clean triangle |

Changing the *scale* changes the frequency, which is what actually decorrelates the taps. Each
channel varies in both swap and scale; cross-channel correlation measures ±0.001.

`ign`'s lag-1 correlation is **-0.48 in x**, and that is inherent to `ign` itself (plain `ign`
measures the same), not introduced by the differencing: the outer sawtooth advances 3.56
periods per pixel in x, which is a near-Nyquist alternation. That is the high-frequency
character a dither wants, and it is why `noise.glsl` exists.

### Static, and the number that proves it

The plan's central claim was that an animated pattern would silently defeat the churn gates.
Measured on `contact_fixture`, frames 90 vs 120 under TAA: **79,593 px with dither against
79,176 px without — 0.5%.** An animated pattern would have put roughly half of 1,920,000
pixels 1 LSB apart, inflating both the measurement and its floor arm together.

### Cost, and the black-lift question that answered itself

Raiden, dither on vs the base-commit build: **5,691,710 px of 8,294,400 move (68.6%), PAE
exactly 1/255** — every changed pixel moved by one LSB and none by more, which is the signature
`CLAUDE.md` calls last-bit rounding.

TPDF at ±1 LSB lifts an exactly-zero channel to 1 in 12.5% of cases analytically, which was
the one real argument for the weaker RPDF form. On raiden, exactly-zero channels are **0.02%
of the frame**, and the lift touches **0.006% of all channels** — 1,604 of 24,883,200. The
objection is real and it is negligible, so the textbook form stands.

### Gate arms, each falsified against a deliberate break

- **`band-inverse`** — the undithered arm must still band (115 px at gate size, bound 60).
- **`band-run`** — dithered run must collapse (20 px, bound 45, against 115 undithered).
- **`band-linear`** — 2.0 LSB must beat the 1.0 default (4 px vs 20 px).

Breaking the shader so it ignores `ditherStrength`: `band-linear` FAILS (20 px at both
amplitudes), the other two pass. Breaking it so it ignores `ditherEnabled`: `band-inverse` and
`band-run` both FAIL (the "off" arm renders at 20 px), `band-linear` passes. Three arms, three
distinct breaks, no arm that cannot fail — which is what an "off is off" arm would have been
here, since the C side short-circuits and both arms would take one path (11.21).

### Goldens: twelve re-baked, six that cannot be

Each recipe was scraped from the spec that introduced it and then **proven before use** —
rendered with `--no-dither` and required to hit 0 px against the committed PNG. Twelve of
thirteen did, which validates the recipes and the off-path in one measurement.

`contact_debug` is deliberately untouched: it is a `--cs-debug` view, the debug branches return
from `main()` before the finishing block, and it measured **0 px** of movement. The early
return proving itself.

Three recorded facts turned out stale:

- **`cornell_box` is not unreproducible.** 11.17 recorded 86% of pixels differing, identically
  at HEAD, and 11.19 repeated it. It measures **3 px, PAE 1/255** here. Something between 11.17
  and now closed it; it is re-baked.
- **`contact_debug` and `froxel_fog` do have recipes**, in 9.4 and 9.5, and both reproduce at
  0 px. 11.21 lists both as having "no recipe recorded anywhere".

Six are **not** re-baked and are now 1 LSB stale on top of whatever they already were:

| golden | why not |
|---|---|
| `cloud_fixture`, `cloud_fixture_lowsun` | **the fixture is not in the tree.** Only the two PNGs are; no `cloud_fixture.*` exists anywhere |
| `flare_fixture` | recipe unrecorded; eight candidate flag sets all miss by >=24%, consistent with 11.21 regenerating the fixture after the golden was baked |
| `roughness_sweep`, `guard_thin_panel`, `backface_dark` | no recipe recorded anywhere — 11.17 filed this, still open |

Re-baking any of these would mean inventing a reference rather than restoring one, so none was
touched. **This is the strongest argument yet for the `scripts/goldens.py` that 11.21 filed**:
a third of the corpus is now unverifiable, and every branch that touches the final image pays
this same scraping cost and discovers the same gaps again.

### Not in scope

- **Grain still inlines its own `fract(sin(dot(...)))` hash** rather than using `ign`.
  Pre-existing, and changing it would move the look of a shipped effect for no gain here.
- **RPDF as an option.** One knob, `--dither <lsb>`, covers the amplitude question; a second
  form would need its own gate arm to earn its place.
