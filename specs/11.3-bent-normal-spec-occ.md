# 11.3 — A5: Bent-normal specular occlusion from GTAO

## Context

**What and why.** The roadmap's next unstarted item (Tier 2, row 9). Today,
screen-space AO multiplies the entire composited HDR buffer once, at tonemap —
by then IBL specular, probe specular, SSR and SSGI are all mixed in, so the
"specular occlusion" term is a per-pixel heuristic (`aoVisibility()` in
tonemap_frag.glsl:160-181): it *fades AO toward unoccluded* by
fresnel/metallic/smoothness. That stops smooth specular from shimmering (its
4.2.1 purpose) but it is directionless — a reflection pointing straight into a
wall gets the same treatment as one pointing at open sky. The engine's GTAO is
the 2023 visibility-bitmask variant, and the shader's own comment notes the
unset sector bits are exactly the directions that are open: the **bent normal**
(average unoccluded direction) and an **aperture cone** fall out of the
already-computed bitmask with zero new samples. A5 exports them and replaces
the fade heuristic with a physically-grounded cone-cone intersection (Jimenez
2016): the visibility cone (bent normal + aperture) against the GGX reflection
cone (reflection vector + roughness-derived width). Crevice reflections stop
leaking energy from directions the geometry blocks — one of the remaining
"game-engine tell" artifacts.

**Why it's cheap.** The bent normal is a straight addition inside GTAO's
existing per-slice loop (no new taps); the AO targets widen in place
(R8→RGBA8, history R16F→RGBA16F — the shared temporal accumulator is already
vec4); consumption is post-only (the tonemap stage has free texture units, and
pbr_frag — which is at the driver's sampler limit — is untouched).

**The blast radius, and how it's staged.** GTAO + spec-occ are on by default
and no golden recipe disables them: 11 of 13 goldens move when the default
flips (immune: contact_debug's --cs-debug view returns before the AO apply;
backface_dark is pure black). Per the 11.0/9.8 precedent, the implementation
ships behind a three-state `specOccMode` (off / legacy / bent) whose **legacy
mode is byte-exact with master** — the 0-diff gate — and the default flips to
bent **only after the user approves the look on screen**, with the golden
re-bake done golden-by-golden with predicted verdicts and per-commit
justification.

## Settled design

- **Production (gtao_frag.glsl).** After each slice's bitfield completes,
  accumulate `cos(θk)·V + sin(θk)·tangent` for every UNSET sector bit k
  (mid-sector angle from the existing `hemiStart`), sum across slices,
  normalize; fall back to N when fully occluded/degenerate. No new samples —
  64 sincos at half res. The occlusion expressions stay textually untouched so
  `.r` is byte-identical modulo the benign reschedule class. Early-outs: sky
  and hair write encoded +Z (never consumed — the tonemap guard returns first);
  the sub-resolution early-out writes N (an unoccluded surface's bent normal
  IS N). Output: `AoOut = vec4(ao, bentN*0.5+0.5)` — RGBA8, view space
  (~0.5° quantization, far below what a 2-slice estimator resolves).
- **Targets (postfx.c).** `ssao_fbo` ×2 R8→RGBA8 (:410), `ao_history`
  R16F→RGBA16F (:418 — exponential blend needs >8-bit convergence; the shared
  temporal accumulator is already fully vec4).
- **Blur (ssao_blur_frag.glsl) — no renormalize, shared CS program safe by
  construction.** Fetch each tap once; keep the scalar `.r` sum *textually
  intact* (the exact chain the full-res contact-shadow reuse depends on — its
  R16F target discards `.gba` anyway); add a separate weighted `.gba` sum. The
  encode is affine, so blurring encoded values commutes with blurring vectors;
  the single `normalize()` at the tonemap read recovers direction after both
  blur and temporal blend. There is no no-blur consumption path.
- **Consumer (tonemap_frag.glsl aoVisibility(), the cone-cone).** Visibility
  cone: axis `normalize(aoTex.gba*2-1)`, aperture `cosAv = sqrt(1-ao)`. GGX
  cone: axis `R = reflect(-V, N)` (V from the legacy invFocal reconstruction),
  aperture `cosAs = exp2(-3.321928·roughness²)` (mirror at 0, ~hemispheric at
  1). Intersection: Oat–Sander spherical-cap overlap with the smoothstep lens
  approximation, normalized by the spec cone's own cap. No separate
  high-roughness fade — the aperture already degenerates toward plain AO at
  r→1 (contingency recorded). Metallic/fresnel weighting stays; the legacy
  `(1-roughness)` factor is dropped from the weight (the cone aperture now
  models it): bent mode returns `mix(ao, so, mix(fresnel, 1, metallic))`.
  Cross-check constants against Filament's specularAO at implementation time.
- **Mode plumbing.** `postfx.h` bool → `int spec_occlusion_mode`
  (OFF/LEGACY/BENT enum), default LEGACY through implementation. Uniform
  `specOccMode`; mode-1 branch is *textually* the current body (the 0-diff
  gate). CLI: `--no-spec-occlusion` → OFF (back-compat exact),
  `--bent-spec-occ` → BENT, plus wire `--spec-occ-debug` (existing view 7 had
  no CLI path) and a new `POSTFX_DEBUG_BENT = 9` view + `--bent-debug` (the
  verification instrument: bent ≈ N on flat ground, tilts off N in corners).
  GUI: the spec-occ checkbox becomes a 3-entry combo (Tonemap-combo pattern).
- **Default flips to BENT only after the user approves the look on screen**
  (11.0 precedent) — every implementation phase stays gated at 0 px on all 13
  goldens, and goldens bake once.

## As built

**Outcome: delivered opt-in.** The machinery landed complete and verified —
production, blur/temporal carry, cone-cone consumer, modes, debug views — but
the default stays LEGACY and the Phase-5 flip never happened. The look review
(Phase 4) approved the initial term, then live sessions on smooth metal
(raiden, studio HDR, close camera) surfaced static mottling that survived
every term-level fix. The default-flip decision moved into spec 11.4.

**The finding that stopped the flip: frequency mismatch, not noise.** The
consumer's reflection vector `R = reflect(-V, N)` uses the normal-mapped
G-buffer normal — it varies at texture frequency (rivets, scratches). The
bent normal is a half-res, 2-slice, blurred, geometry-scale field. The
cone-cone term therefore tracks the normal map *incoherently* with the
specular already summed into the buffer it multiplies, and the interference
prints as low-frequency mottling exactly on smooth metal. Two fixes aimed at
noise measured zero change (splitting the temporal feedback window for
`.gba`: 138,533 vs 138,120 px; tripling the bent-blur stride: blotch metric
6.67 → 6.63) — proof the bent normal was never the high-frequency operand.
Shipped engines avoid the class by construction (Filament bakes bent normals
at texture frequency; Activision evaluates occlusion in the lighting pass
where it co-varies with the specular sample). 11.4 takes the structural
route: ambient specular on its own G-buffer target, occluded in post where
the AO chain lives, so the query and the specular swing together.

**Divergences from the settled design, all deliberate:**

- The legacy `(1 - roughness)` weight factor was **kept**, not dropped. The
  theory said the cone aperture subsumes it; measured, dropping it moved
  cornell_box by 1.27M px at peak 0.66 — grazing Fresnel climbs to ~1 and
  hands mostly-diffuse energy to the specular answer. The weight stays; only
  its destination changed (a directional visibility instead of a blanket 1).
- The plain Oat–Sander lens gained `VIS_EDGE_SOFTNESS = 0.25`, a floored
  smoothstep band. In the mirror limit the exact function is a step, and a
  step over an 8-bit bent normal prints contour lines; higher input precision
  only thins them.
- The visibility ratio is normalized against the same lobe under an open
  hemisphere (`visible / open`): a reflection cone always hangs partly below
  its own horizon, and without the reference the term darkened fully
  unoccluded ground (backface_dark moved 11,121 px; landscapes ~500k).
- The catcher marker gained a floor (`-max(falloff, 0.002)`) and the tonemap
  guard tests the marker's **sign** (was a stale `-0.5` threshold from when
  the marker was exactly -1): broad dark bands across the studio backdrop
  were the catcher's outer ring reaching the cone term through a guard hole.
- CLI shipped as `--spec-occ <off|legacy|bent>`, not `--bent-spec-occ`.

**Legacy byte-identity is empirical on the goldens, not by construction.**
The guard sign-test is shared by legacy mode: catcher fade-annulus pixels
(marker in (-0.5, 0)) previously took the legacy blend and now return plain
AO. No golden carries a catcher, so all 13 stay 0 px — but on raiden (the
one catcher scene in the battery) legacy differs from master by 3,667 px of
8.3M (peak 0.58), localized to the contact region where the AO blur bleeds
the character's occlusion onto the annulus. Deliberate: the tonemap now
reads the same marker contract SSR does, instead of lifting AO off an
invisible floor.

**Measured (bent vs legacy, final term):** sheen_fixture 3,634 px /
specular_fixture 6,548 / froxel_fog 47,034 / roughness_sweep 19,565 /
guard_thin_panel 24,457–36,132 / backface_dark, cornell_leak, contact_debug
0 / aerial + clouds ~1 LSB. TAA adjacent-frame churn (raiden 800², frames
140→141): off 123,818 / legacy 127,372 / bent 137,958 px. Perf recipe:
17.6–17.7 s branch-legacy vs 18.3–19.7 s measured on master — the always-on
bent production costs nothing measurable at this scene scale.

**Review round (five background audits, applied as one commit):** the
`--no-spec-occlusion` flag became a real alias at the parse site (was a
second field resolved by apply order); `spec_occlusion_mode` took its enum
type with a GUI-local int marshal; the cone term's texel is fetched once and
`dot(bentN, R)` computed once; the hand-rolled hermite became `smoothstep`;
the catcher/SSR constant pair (0.002 < 0.004) now names both sides of its
inequality; the shared accumulator's channel contract was un-staled.
Considered and rejected: uniform-gating bent production and mode-dependent
AO formats — 11.4 flips the default to a bent-consuming mode, so both would
be transient mode-coupling.

## Perf recipe

`time ./out/bin/render -m assets/contact_fixture.cscn -x -f 300
--no-auto-exposure -E 1.0 --taa --headless-jitter -W 1920 -H 1080 -S out.ppm`
— ×2 per configuration (master / branch-legacy / branch-bent, plus one no-TAA
run to cost the accum path).
