# Tier 3 · 4.9 — Screen-space refraction (KHR_materials_transmission)

## Context

Cetra has IOR and thin-film but no see-through transmission: "glass" today is Fresnel-boosted
alpha blending — the background bleeds through, nothing bends or blurs, frosted glass is
impossible. §4.9 adds real transmission per glTF `KHR_materials_transmission` (+ the volume
bend from `KHR_materials_volume`): after opaques + skybox draw, the scene color resolves into
a mipped texture; transmissive surfaces draw in the existing late pass sampling the opaque
color behind them, roughness selecting a blurred mip, thickness×`refract()` bending the
sample point. Design validated by two exploration passes + an architecture review agent.

**Verified facts:**
- The frame ALREADY splits at the right seam: opaque+masked pass (G-buffer MRT) → skybox →
  color-only draw buffers → ALPHA_BLEND pass (render.c:627-638, gated on
  `scene->transparent_mesh_count`, depth-write off, unsorted) → catcher. The count is
  SAME-FRAME (reset :604, incremented :288 in pass 1's skip branch, consumed :631) — no
  latency, no pre-pass.
- pbr_frag already has `uniform mat4 view` + `projection` (the jittered draw projection,
  render.c:316-317) → the volume offset is `clip = projection * view * vec4(WorldPos +
  refract(-V,N,1/ior)*thickness, 1); uv = clip.xy/clip.w*.5+.5`, and **thickness=0
  degenerates exactly to the fragment's own UV** — thin and volume are ONE code path, no
  screenSize uniform, no gl_FragCoord path.
- Sampler budget: 17 declared, only 14 live (heightTex 6 / sheenTex 8 / reflectanceTex 9
  never sampled). sceneColorTex takes unit 6 — **but render.c:205-208 still BINDS height
  maps to unit 6 per draw; that dead bind must be removed first** (byte-safe today, fatal
  once unit 6 is live).
- `material->ior` is NEVER imported (all assets shade at the 1.5 default). assimp 6.0.5 has
  TRANSMISSION_FACTOR / REFRACTI / VOLUME_THICKNESS_FACTOR. c64/raiden carry no
  ior/transmission data (verified — byte gates are structurally safe under the policy below).
- No repo asset carries transmission → a generated glTF fixture is required.
- No window-resize rebuild path exists; MSAA attachments are created once at init size. The
  resolve target is created LAZILY on first transmissive frame at `engine_render_size` dims
  (dims stored, recreate-on-mismatch as insurance), deleted in teardown beside the MSAA
  textures (engine.c:199-202).
- gametest's ALPHA_OPAQUE "glass" and the visor's un-finalized opacity are both unaffected
  by a `transmission > 0` selector.

## Design

**Material + import (material.h/.c, import.c):**
- `float transmission;` (0) + `float thickness;` (0, world units) on Material; uploaded in
  `_update_program_material_uniforms` as `transmission` / `transmissionThickness`
  (filmThickness naming precedent).
- Import policy **(b)**: read `AI_MATKEY_TRANSMISSION_FACTOR` always; read `AI_MATKEY_REFRACTI`
  and `AI_MATKEY_VOLUME_THICKNESS_FACTOR` only when transmission > 0. Rationale: structural
  byte-safety — only glTF produces transmission, so IOR import is glTF-scoped for free, and
  the OBJ/FBX hazard (`Ni 1.0` exporter defaults → iorF0 0 → dielectric specular silently
  dies) never fires. "Honor KHR_materials_ior everywhere" stays a future byte-gated change.

**Selection + pipeline (render.c, engine.c/h):**
- Late-pass predicate at render.c:285 becomes `alpha_mode == ALPHA_BLEND || transmission >
  0`; a `transmissive_mesh_count` joins `transparent_mesh_count` (increment :287-289, reset
  :604, gate :631).
- Between skybox and the late pass, when `transmissive_count > 0 && render_mode ==
  RENDER_MODE_PBR && engine->refraction_enabled`: resolve MSAA ATT0 (GL_NEAREST blit,
  mirroring `resolve_color_attachment`'s read-buffer restore, postfx.c:817-824) into the
  lazy engine-owned full-internal-res RGBA16F texture (GL_CLAMP_TO_EDGE,
  GL_LINEAR_MIPMAP_LINEAR — textureLod above level 0 needs it), `glGenerateMipmap` (box
  mips v1; a dual-filter chain + the deferred `create_mip_chain` extraction is the upgrade
  if box mips band), re-bind `engine->framebuffer` (glDrawBuffers is per-FBO state — the
  color-only list restores automatically; viewport untouched by blits). Comment in code:
  the copy is what makes sampling legal (same-FBO read+draw is a feedback loop).
- `sceneColorAvailable` uniform: 0 in pass 1, 1 in pass 2, set in `_render_node`'s
  program-switch block — pass 2 already forces a program re-switch (current_program reset,
  render.c:632-633); preserve that invariant.

**Shader (pbr_frag.glsl) — the validated factoring (KHR: `mix(diffuse_brdf, specular_btdf,
transmission)` under the specular layer; specular + emissive stay untouched):**
- `kD *= (1.0 - transmission)` at the three existing kD sites: light loop (:747-749 after
  the metallic scale), IBL ambient (:793-794), no-IBL fallback (:831). Exact-1.0 multiply
  when transmission==0 → byte-safe (the energy-comp gate precedent held its byte gate).
- Transmitted term, added when `transmission > 0 && sceneColorAvailable > 0`:
  `refractedPos = WorldPos + refract(-V, N, 1.0/ior) * transmissionThickness;` → project via
  view/projection → clamp UV → `texture/textureLod(sceneColorTex, uv, roughness * lodScale)`
  → `transmitted = sample.rgb * albedoMap * (1.0 - F) * transmission * (1.0 - metallicMap)`
  (F = fresnelSchlickRoughness, already computed :790). Sum joins the existing
  `min(..., 60000)` fp16 guard. Alpha stays 1.0 on this path (background already baked into
  the transmitted term; SRC_ALPHA blend with a=1 replaces dst — correct).
- Fallback when `sceneColorAvailable == 0` (flag off, debug modes): the branch is dead and
  glass renders via today's opacity path — intended, stated behavior.
- v1 documented limitations: transmission composes before the Fresnel-alpha exit (baseColor
  alpha < 1 + transmission composes wrongly — rare, documented); OPAQUE+transmission meshes
  migrate to the late pass and lose depth/velocity/normals writes (no TAA velocity, invisible
  to AO/SSR/DoF-CoC — the existing translucent limitation); refracted image excludes the
  shadow catcher and other transparents; unsorted overlap composes in traversal order.

**Fixture (new):** python generator (repo precedent: gen_shader_header.py) emitting a small
.gltf with embedded base64 buffer — colored-quad backdrop (distinct albedo regions, no
texture dependency), a clear panel (transmission 1, roughness 0), a frosted panel
(roughness ~0.4, thickness > 0 on one of them); `extensionsUsed` lists transmission/ior/
volume. Generator + emitted asset both checked in.

**Flag:** `--no-refraction` → `engine->refraction_enabled = false` (resolve skipped →
sceneColorAvailable 0 → opacity fallback). House --no-bloom pattern; lands FIRST as the
byte-gate bridge.

**M3 — resolve + thin composite:** lazy target, mid-frame resolve + mipgen, sceneColorTex

backdrop visible THROUGH the clear panel (not alpha-washed), frosted panel blurs it;
determinism ×2; no GL errors; `--taa` sanity orbit.

**M4 — volume bend + roadmap + review:** thickness offset live (*gate:* visible refraction
shift through the thick panel; all prior gates hold), roadmap §4.9 ✅ + table + sequence,
memory notes, then the standard background review fanout (/thermo-nuclear + /simplify, ALL
run_in_background); user merges.

## Risks

1. **Mid-frame resolve state** — highest risk; the read-buffer restore + FBO rebind
   discipline above is the complete list (validated: draw-buffer list is per-FBO state).
2. **Unit-6 discipline** — the height-bind removal MUST land before sceneColorTex (M0); a
   review check that no other code binds unit 6 in the late pass.
3. **glGenerateMipmap full-res RGBA16F cost** (~50-90 MB + per-frame mipgen) — paid only on
   transmissive frames (count gate + lazy alloc); half-res base is the fallback if frame
   time complains.
4. **Composite regressions** — the kD-site scaling is surgical; byte gates + the fixture
   A/B arbitrate.
