# Spec 11.100 — Alpha distribution (roadmap G2, row 54)

## Context

Row 54 is the roadmap's only open row. Specs 11.87/11.88 fixed the alpha test's threshold and its
mip coverage, and hit the family's ceiling: **past the level a chain goes uniform, coverage is 0 or
1 and no alpha scale reproduces a fraction, so distant cutouts vanish rather than thin**. Alpha
distribution (Yuksel 2018, digest at `docs/papers/yuksel-2018-alpha-distribution-for-alpha-testing.md`)
redistributes alpha to binary per texel, so a uniform level becomes a dither at the right coverage —
distant canopy stays present. It lands as a pure pre-process inside `texture_derive_levels`
(`cetra/src/texture.c:633`), needs no sampler, no uniform, no shader edit, and the cook (11.99)
absorbs the cost after the first run via a recipe bump.

**Exploration corrected row 54 on four counts** (recorded in the docs phase): the paper's A2C
extension is **§4, not §3**, and is NOT render-time-free — §4.1 needs a second nearest-filtered
sampler (refused by the ledger), §4.2 needs `gl_SampleMask` shader work, and Yuksel's measured A2C
result only matches hashed alpha testing's ("no apparent qualitative improvement in
alpha-to-coverage" is a comparison against hashed — the review caught this spec deploying it as an
absolute verdict, which the source does not say). **The win lives on the BINARY paths** —
shadows (always binary), probe/GI captures, `--msaa 1` — which Cetra has and gets for free. The
recipe is `texture-mips/2`, not `/1`. And the alpha pyramid requires random contention resolution — a
determinism hazard against the cook's bit-identical-artefact charter.

## The seven decisions

1. **Algorithm: Floyd–Steinberg error diffusion (§3.1), serpentine scan. Not the pyramid.**
   FS is ~55 lines, zero randomness (multiplies/adds/compares in fixed serial order — the cook's
   determinism for free); the pyramid needs a PRNG, NPOT 4/6/9-texel region grouping, a per-region
   sort, and its correctness guarantee holds only at cutoff ≥ 1/2 (ours are 0.4 and 0.5) — for a
   result Yuksel rates "arguably marginally better." Serpentine (reverse odd rows, mirrored kernel)
   is the one deviation from the paper's letter: raster FS grows directional worms exactly on
   low-density uniform fields, which is the only place this fires. The recipe-version mechanism
   makes a future pyramid experiment cheap (`/4`).
2. **Scope: surgical with monotone closure.** Distribute level L ≥ 1 iff `texture_wants_coverage`
   AND the target is fractional (`0.002 < target < 0.998`) AND (level L−1 distributed, OR this
   level's `texture_preserve_alpha_coverage` best-error exceeds `TEXTURE_DISTRIBUTE_MISS = 0.05`).
   Structured levels stay **byte-identical** to today (near/mid canopy unchanged, movement confined
   to deep mips); the miss test IS "11.88's ceiling reached," measured in the feature's own
   currency. Monotone closure keeps the trilinear ramp from alternating smooth/dithered/smooth.
   Paper-faithful all-levels scope is rejected: it forfeits A2C's smooth one-pixel edges at every
   distance to fix a defect that exists only past the ceiling. On distributed levels the 11.88
   rescale is **replaced, never composed** (the dither reads the pristine halved alpha).
3. **No shader change**, and it is defensible: at firing levels one texel ≈ one pixel, filtered
   dithered alpha swings 0→1 across ~1 px, `fwidth(a)` sits at O(0.5–1), and the Golus ramp
   degenerates to `clamp(a − cutoff + 0.5)` — the dither reads as smooth fractional coverage. The
   binary branch (shadows, `--msaa 1`, captures) gets dotted distant presence instead of absence.
4. **Tail: no special case.** The same diffusion runs at 2×2 and 1×1, where it reduces to majority
   rounding of the target. `texture_mean_color` reads RGB only (`texture.c:1099`) — safe.
5. **Cutoff/target: internal threshold 1/2 on a normalized field; target = 11.88's level-0
   bilinear-reconstruction coverage** (already measured once before the loop, `texture.c:687`), not
   the paper's ᾱN/(2α_τ). Output is binary {0,255}, which tests identically at any authored cutoff,
   so the paper's α_τ=1/2 design-center problem dissolves; one definition of coverage spans
   11.88+11.100; and glTF MASK semantics says the thing to preserve across distance is the level-0
   *test result*, not ground-truth transparency. Pre-scale the level's alpha so its mean equals the
   target (`s = target·255·N/Σa`), then diffuse — diffusion conserves the sum, so the ON count lands
   at `round(target·N)`.
6. **Location: two statics in `texture.c`, no new TextureDesc field, no lever.**
   `texture_preserve_alpha_coverage` gains a `float` return (best_error; one caller);
   new `texture_distribute_alpha(pristine, out, w, h, target)`; ~15-line edit in the derive loop.
   Recipe `texture-mips/2` → `/3` (`texture.c:797`) **and** the hardcoded literal at
   `scripts/gates.py:20631`, same commit. No config_snapshot rows, no new key folds — the dither is
   a pure function of already-folded inputs.
7. **Explicitly OUT** (recorded in the spec): hashed alpha testing (shader complexity in a 16/16
   `pbr_frag`; Yuksel measures it noisy; remains the unbuilt half of row 54), §4.1 sample-mask
   texture (sampler ledger), §4.2 hashed sample mask (shader work for a path Yuksel says doesn't
   improve), texcoord jitter for Moiré (a shader change; the paper used it only for its Fig 8), the
   alpha pyramid, all-levels scope.

## The algorithm, precisely

`texture_distribute_alpha` body (new static under `texture_preserve_alpha_coverage`, texture.c:570):
1. `sum = Σ alpha` in uint64; if 0, return true (transparent is honest).
2. `s = (double)target · 255 · w · h / sum` — normalize the mean to the target.
3. Scratch `float* err = calloc(2·(w+2), sizeof(float))` (two rows, +1 offset so x±1 always lands
   in-buffer; padding cells discarded — deterministic edge loss, the paper's own behavior). On OOM:
   `log_warn` once, return false — caller falls back to the rescale for that level and re-arms.
4. Serpentine rows: `v = min(a/255·s, 1) + cur[x]`; `q = (v >= 0.5)`; `e = v − q`; write
   `q ? 255 : 0`. Interior rows: FS kernel 7/16 ahead, 3/16 behind-below, 5/16 below, 1/16
   ahead-below (mirrored on odd rows). **Last row: full residual flows ahead along the row**
   (`cur[ahead] += e`) — keeps count conservation O(1) instead of dropping 9/16 off the bottom,
   which matters for N×1 levels and the tail. At 1×1 it degenerates to majority rounding.
5. RGB untouched (out is the pristine copy; only alpha bytes rewritten). No libm, no PRNG, no
   threads — bit-identical within a build, which is what the cook charter claims.

Loop edit (replacing `texture.c:719-723`): if `distributing`, dither; else run the rescale, and if
`fractional && miss > TEXTURE_DISTRIBUTE_MISS`, set `distributing = true` and dither THIS level
(overwriting the rescaled bytes). One `log_info` at first fire (w×h, level, target, miss) — a
render-free observable gates can grep. The chain feed is untouched: `src = dst` still hands the
pristine level to the next halving. The 0.05 constant is re-derived with the replay table before
freezing (leaf atlases miss ~0.0007, dots uniform levels ~0.1133; anywhere in [0.02, 0.10]
separates) and its comment carries the measured table.

**Known accepted bias, recorded not fixed**: GPU-perceived coverage of a texel-fraction-f dither is
not exactly f (bilinear tent factor 0.61 at cutoff 0.5 / 0.93 at 0.4 on the binary path; ≈ +0.1 at
0.4 under the A2C ramp). Within ~±0.1 absolute against a status-quo error of the entire target. No
measure-and-recalibrate loop — the two render paths would want opposite corrections.

## As built (2026-09-01)

The plan survived contact better than its two predecessors, and the two places it did not are both
instrument findings, recorded here per 11.88's rule that anything computed before the measure has
to be re-derived after it.

**`TEXTURE_DISTRIBUTE_MISS` froze at 0.03, not the planned 0.05.** The replay's corpus table put a
real level's miss at 0.0502 -- the dots' level 3, STRUCTURED but unreachable (its reachable
coverage stops 0.0502 short of the 0.113 target under the [1/4, 4] scale cap) -- so 0.05 sat
0.0002 from a live reading. The separation that matters: largest miss that must not fire 0.0021
(ivy's worst structured level; the dots' structured levels read 0.0016 and less), smallest that
must fire 0.0502. So the criterion is UNREACHABILITY, not uniformity, and level 3 fires --
which moved `alphacov-mip` from 0.911 to 0.904 (its dither replaces a cluster rescale that was
fake structure, grid-beat blobs) and re-priced the no-rescale falsifier from 0.591 to 0.622.
The plan's "near/mid bands 0 px" prediction died here, exactly as 11.88 warned predictions do.

**The deep arm's planned instrument could not see the feature, and the fixture grew a quad.** On
the grazing plane the bright-pixel count read the distributing build at 0.0027 against the
vanishing build's 0.0114 -- LOWER, because ~15-degree anisotropic filtering averages a sparse
binary dither into a smooth low-alpha field and the Golus-sharpened test then deletes it, while
the old rescale's smooth clusters survive aniso and light whole pixels. That is a real ceiling of
the technique under grazing anisotropy, one Yuksel's paper does not discuss, and it is recorded as
such rather than worked around: `alphacov-deep` reads a camera-facing quad (his own Fig. 6
geometry -- aniso ~1, mip pinned at 4.9 by distance, budgets 116/29 texels) by MEAN luma over a
sky reference, which conserves the mass a threshold deletes. Readings: **+20.97 distributing**
(perceived coverage 21/162 = 0.13 against the 0.113 target -- the bilinear tent math holds on
facing geometry), **+3.21 vanishing** (edge taps of rescaled level 3, not the predicted ~0),
**+180.25 saturated**. Bounds 8/60 sit 4.8 above the vanishing reading and 120 under the
saturating one.

Everything else held. First fire on the fixture: level 3, target 0.1127, miss 0.0502 -- the C and
the python replica agree to four decimals. The ON count lands within boundary discard of
round(target*N) at every size (+0 at 256x256, -13 at 64x64, -1 at 4x4, exact majority round at
1x1). Consumers: tree's atlas fires at level 11 (its 2x1 tail), forest's at level 10, ivy at its
1x1 only, tsl_ramp at its 1x1 only -- the leaf class is inert through every structured level, as

## Moire, tiling and the other recorded limits

Yuksel's SS6 limitations, as they land here: **threshold change invalidates the artefact** -- true
and absorbed by the cook key, which already folds `coverage_cutoff`; **tiling repeats the
pattern** -- inherent, and the in-tree atlases are atlased rather than tiled; **magnification
staircases** -- avoided by the pristine level 0, which is ledger row 7; **Moire against regular
sampling** -- his Fig. 8 is structurally the alphacov fixture, and the rendered frame shows no
visible banding at this framing (the serpentine dither is irregular); the arms are band means and
robust to it regardless. The paper's texcoord-jitter remedy is a shader change against this spec's
no-shader-change scope and stays out. The GRAZING-ANISOTROPY deletion is this implementation's own
addition to that list, measured at ~15 degrees on the plane: the technique's win is real on facing
and mildly-inclined content and fades as the view grazes, because the sharpened test eats
aniso-averaged dither. A future consumer who wants distant grass to benefit should know that
before pointing the technique at a ground plane.

## The review record (seven agents, 2026-09-01)

Three thermo-nuclear reviewers (the C half, the gates/fixture half, a cross-cutting claim audit)
and four simplify angles (reuse, simplification, efficiency, altitude) ran against the branch;
every fix below was applied in one pass after all seven reported, and re-verified: generator
asserts green, alphacov/mask/texcomp/cook/gate-docs green, 29/29 goldens 0 px, the full suite
after that.

**The catch of the review -- a 1xN conservation gap, the transpose of the fixed one.** The
last-row rule kept N x 1 tails conservative and said so, but a SINGLE-COLUMN level had no mirror:
every interior row's kernel sent 11/16 of its error into guard cells, and a 1x4 at normalized 0.4
placed 1 ON texel against a budget of 2 -- under-representation at distance, the exact failure
class the feature exists for, invisible because no corpus content dithers a tall tail (ivy's 1x3
sits under the miss threshold). Fixed with the two-line transpose (`width == 1` flows the residual
straight down), traced to exact conservation (1x4 -> 2/2, 1x8 -> 3/3, 1x16 -> 2/2, wide rows
unchanged), and the recipe bumped to `texture-mips/4` with the gates literal in the same change --
the key model demands it even though no existing artefact's bytes move.

**Claim corrections the audit demanded.** The Yuksel A2C sentence is COMPARATIVE ("as compared to
hashed alpha testing ... no apparent qualitative improvement in alpha-to-coverage") and three
documents deployed it as an absolute verdict; all three now carry the comparator, and the A2C
refusal rests on its real legs (the sampler ledger, the `gl_SampleMask` work). The papers README
said "structured levels stay byte-identical" -- the exact claim this spec's own as-built corrects
(reachability, not structure, is the criterion) -- and its "six deviations" counted two
conformances (level-0 pristineness is the paper's own fix; PRNG-freeness deviates from nothing in
section 3.1); it now lists four deviations and files the other two as what they are.
`ALPHACOV_FAR_MAX`'s comment still carried the retired thins-to-nothing rationale while the arm's
own evidence string had the budget-starvation one; both now agree. The deep ceiling's comment
quoted the a-priori +160 estimate where the ledger measured +180.25; it now carries the measured
number, notes why it exceeds the estimate (the mutation saturates the plane too and bloom rides
the frame), and the consistency claim got stronger for it: 20.97/180.25 = 0.116 against the 0.113
target. verification.md gave two `--no-sky` floors (4 px and 40 px) with no configs; both now
state theirs.

**The fossil.** `BAND_DEEP` -- the plane band the arm abandoned for the quad -- survived as a
constant, a reach-loop row, and two placement asserts binding the fixture on behalf of no reader,
and had already drifted against this spec's own plan text ((0.38, 0.52) planned, (0.40, 0.52)
landed) with nothing to notice. Deleted; the grazing-anisotropy record moved beside the QUAD_*
block it justifies, which is prose in four homes and constants in none.

**Structural fixes.** The `dithered` flag was derivable from `distributing` (traced
byte-identical, one variable and one nesting level gone). The quad's corner asserts now project
