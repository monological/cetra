# Spec 11.100 — Alpha distribution (roadmap G2, row 54)

## Context

Row 54 is the roadmap's only open row. Specs 11.87/11.88 fixed the alpha test's threshold and its
mip coverage, and hit the family's ceiling: **past the level a chain goes uniform, coverage is 0 or
1 and no alpha scale reproduces a fraction, so distant cutouts vanish rather than thin**. Alpha
distribution (Yuksel 2018, digest at `docs/papers/yuksel-2018-alpha-distribution-for-alpha-testing.md`)
redistributes alpha to binary per texel, so a uniform level becomes a dither at the right coverage —
distant canopy stays present. It lands as a pure pre-process inside `texture_derive_levels`
(`cetra/src/texture.c:633`), needs no sampler, no uniform, no shader edit, and the cook (11.99)
absorbs the cost after the first run via a recipe bump.

**Exploration corrected row 54 on four counts** (recorded in the docs phase): the paper's A2C
extension is **§4, not §3**, and is NOT render-time-free — §4.1 needs a second nearest-filtered
sampler (refused by the ledger), §4.2 needs `gl_SampleMask` shader work, and Yuksel's own verdict is
"no apparent qualitative improvement in alpha-to-coverage." **The win lives on the BINARY paths** —
shadows (always binary), probe/GI captures, `--msaa 1` — which Cetra has and gets for free. The
recipe is `texture-mips/2`, not `/1`. And the alpha pyramid requires random contention resolution — a
determinism hazard against the cook's bit-identical-artefact charter.

## The seven decisions

1. **Algorithm: Floyd–Steinberg error diffusion (§3.1), serpentine scan. Not the pyramid.**
   FS is ~55 lines, zero randomness (multiplies/adds/compares in fixed serial order — the cook's
   determinism for free); the pyramid needs a PRNG, NPOT 4/6/9-texel region grouping, a per-region
   sort, and its correctness guarantee holds only at cutoff ≥ 1/2 (ours are 0.4 and 0.5) — for a
   result Yuksel rates "arguably marginally better." Serpentine (reverse odd rows, mirrored kernel)
   is the one deviation from the paper's letter: raster FS grows directional worms exactly on
   low-density uniform fields, which is the only place this fires. The recipe-version mechanism
   makes a future pyramid experiment cheap (`/4`).
2. **Scope: surgical with monotone closure.** Distribute level L ≥ 1 iff `texture_wants_coverage`
   AND the target is fractional (`0.002 < target < 0.998`) AND (level L−1 distributed, OR this
   level's `texture_preserve_alpha_coverage` best-error exceeds `TEXTURE_DISTRIBUTE_MISS = 0.05`).
   Structured levels stay **byte-identical** to today (near/mid canopy unchanged, movement confined
   to deep mips); the miss test IS "11.88's ceiling reached," measured in the feature's own
   currency. Monotone closure keeps the trilinear ramp from alternating smooth/dithered/smooth.
   Paper-faithful all-levels scope is rejected: it forfeits A2C's smooth one-pixel edges at every
   distance to fix a defect that exists only past the ceiling. On distributed levels the 11.88
   rescale is **replaced, never composed** (the dither reads the pristine halved alpha).
3. **No shader change**, and it is defensible: at firing levels one texel ≈ one pixel, filtered
   dithered alpha swings 0→1 across ~1 px, `fwidth(a)` sits at O(0.5–1), and the Golus ramp
   degenerates to `clamp(a − cutoff + 0.5)` — the dither reads as smooth fractional coverage. The
   binary branch (shadows, `--msaa 1`, captures) gets dotted distant presence instead of absence.
4. **Tail: no special case.** The same diffusion runs at 2×2 and 1×1, where it reduces to majority
   rounding of the target. `texture_mean_color` reads RGB only (`texture.c:1099`) — safe.
5. **Cutoff/target: internal threshold 1/2 on a normalized field; target = 11.88's level-0
   bilinear-reconstruction coverage** (already measured once before the loop, `texture.c:687`), not
   the paper's ᾱN/(2α_τ). Output is binary {0,255}, which tests identically at any authored cutoff,
   so the paper's α_τ=1/2 design-center problem dissolves; one definition of coverage spans
   11.88+11.100; and glTF MASK semantics says the thing to preserve across distance is the level-0
   *test result*, not ground-truth transparency. Pre-scale the level's alpha so its mean equals the
   target (`s = target·255·N/Σa`), then diffuse — diffusion conserves the sum, so the ON count lands
   at `round(target·N)`.
6. **Location: two statics in `texture.c`, no new TextureDesc field, no lever.**
   `texture_preserve_alpha_coverage` gains a `float` return (best_error; one caller);
   new `texture_distribute_alpha(pristine, out, w, h, target)`; ~15-line edit in the derive loop.
   Recipe `texture-mips/2` → `/3` (`texture.c:797`) **and** the hardcoded literal at
   `scripts/gates.py:20631`, same commit. No config_snapshot rows, no new key folds — the dither is
   a pure function of already-folded inputs.
7. **Explicitly OUT** (recorded in the spec): hashed alpha testing (shader complexity in a 16/16
   `pbr_frag`; Yuksel measures it noisy; remains the unbuilt half of row 54), §4.1 sample-mask
   texture (sampler ledger), §4.2 hashed sample mask (shader work for a path Yuksel says doesn't
   improve), texcoord jitter for Moiré (a shader change; the paper used it only for its Fig 8), the
   alpha pyramid, all-levels scope.

## The algorithm, precisely

`texture_distribute_alpha` body (new static under `texture_preserve_alpha_coverage`, texture.c:570):
1. `sum = Σ alpha` in uint64; if 0, return true (transparent is honest).
2. `s = (double)target · 255 · w · h / sum` — normalize the mean to the target.
3. Scratch `float* err = calloc(2·(w+2), sizeof(float))` (two rows, +1 offset so x±1 always lands
   in-buffer; padding cells discarded — deterministic edge loss, the paper's own behavior). On OOM:
   `log_warn` once, return false — caller falls back to the rescale for that level and re-arms.
4. Serpentine rows: `v = min(a/255·s, 1) + cur[x]`; `q = (v >= 0.5)`; `e = v − q`; write
   `q ? 255 : 0`. Interior rows: FS kernel 7/16 ahead, 3/16 behind-below, 5/16 below, 1/16
   ahead-below (mirrored on odd rows). **Last row: full residual flows ahead along the row**
   (`cur[ahead] += e`) — keeps count conservation O(1) instead of dropping 9/16 off the bottom,
   which matters for N×1 levels and the tail. At 1×1 it degenerates to majority rounding.
5. RGB untouched (out is the pristine copy; only alpha bytes rewritten). No libm, no PRNG, no
   threads — bit-identical within a build, which is what the cook charter claims.

Loop edit (replacing `texture.c:719-723`): if `distributing`, dither; else run the rescale, and if
`fractional && miss > TEXTURE_DISTRIBUTE_MISS`, set `distributing = true` and dither THIS level
(overwriting the rescaled bytes). One `log_info` at first fire (w×h, level, target, miss) — a
render-free observable gates can grep. The chain feed is untouched: `src = dst` still hands the
pristine level to the next halving. The 0.05 constant is re-derived with the replay table before
freezing (leaf atlases miss ~0.0007, dots uniform levels ~0.1133; anywhere in [0.02, 0.10]
separates) and its comment carries the measured table.

**Known accepted bias, recorded not fixed**: GPU-perceived coverage of a texel-fraction-f dither is
not exactly f (bilinear tent factor 0.61 at cutoff 0.5 / 0.93 at 0.4 on the binary path; ≈ +0.1 at
0.4 under the A2C ramp). Within ~±0.1 absolute against a status-quo error of the entire target. No
measure-and-recalibrate loop — the two render paths would want opposite corrections.

## Verification

**Fixture numbers** (from `assets/alphacov_dots.png`, 512², coverage 0.1133, uniform from level 4):
distribution budgets per level are `round(0.1133·N)` — level 4 (32²) = 116, level 5 = 29, level 6
= 7, level 7 = 1.8, level 9 (1×1) = 0. So the "alive" floor cannot live on BAND_FAR (mips 7.0–9.9,
budgets ≤ 2); the new band goes at rows **0.38–0.52 = mips ~4.3–6.1**, past uniform, budget-rich.

Gate arms (`run_alphacov_gate`, gates.py:11241):
- **`alphacov-mip` KEPT** — threshold 0.70 unchanged; structured levels are byte-identical under
  surgical gating so the reading stays ~0.911; evidence strings re-measured, never carried.
- **`alphacov-far` KEPT bound (0.25), docstring RECLAIMED** — its meaning flips from "must be empty
  because correct declines out here" to "must stay sparse because the budget out here is ≤ 2
  texels." New named falsifier: invert/unclamp the visibility budget → band reads ~1.0.
- **`alphacov-deep` NEW (the arm G2 exists for)** — `BAND_DEEP (0.38, 0.52)` added to
  `assets/gen_alphacov_fixture.py` (bands are python constants; committed assets expected
  byte-identical — verify `git status` clean after regen). Two-sided: `DEEP_MIN <= deep <= DEEP_MAX`
  (provisional 0.03 / 0.30, finalized from measured readings with distance-to-falsifier stated in
  the docstring). **Committed red on master first** (the 0ef634cf `mask-samples` precedent): master
  reads 0.0000 there. New generator asserts: BAND_DEEP's nearest row ≥ uniform level; farthest row's
  budget ≥ 4 texels.
- **`mask` group unchanged** — `mask_fixture` has no textures; distribution cannot reach vertex
  alpha. If any arm moves, the `texture_wants_coverage` guard leaked.
- **Cook arms**: `cook-texture`'s literal → `/3` (symmetric tripwire either direction);
  `cook-determinism`'s two-cold-cooks byte-compare covers the new code for free; `cook-key`
  unchanged (texture-mips deliberately exempt from both site sets).

**Goldens**: `translucent_shadow` predicted 0 px — the ramp's shadow samples LOD ~0 (64 texels/unit
against the cascade's density), and a halved linear ramp is a ramp so only the 1×1 fires; measure,
