# 5.3 Particle colliders (sphere repel + room containment) + moving glass-sphere spores demo

## Context

cetra's particles are pure force-field advection today (curl-noise + drift + integrate); they
ignore all geometry — no collision, no object coupling (confirmed: zero collision code in the
particle system). Goal: add a **composable collider module family** so particles react to shapes,
then demo it. Two instances of one primitive:
- **keep-OUT** — a moving sphere that repels/pushes particles (the demo's glass sphere).
- **keep-IN** — the room walls/floor that contain the dust.

Must work on **both** sim backends (CPU and the transform-feedback GPU backend) to preserve the
engine's deliberate CPU/GPU parity. Demo: add a glass sphere that moves through the spore room on a
deterministic path, visibly parting/pushing the dust, with the dust contained by the room.

The engine tree is nested: sources under `cetra/src/`, shaders under `cetra/shaders/`, demo under
`apps/spores/src/`.

## Design

### Part A — Unified collider module (`cetra/src/particle_module.{h,c}`)
ONE `PARTICLE_PHASE_UPDATE` module, `collider`, where the shape and the keep-in/keep-out mode are
**data**, following the `update_drift`/`update_integrate` pattern (private params struct;
`module_new(..., PARTICLE_PHASE_UPDATE, collider_run, params)`; kernel iterates `[begin,end)`
reading/writing `e->pool->position[i]` / `e->pool->velocity[i]`). Added to the emitter's update list
**after** `update_integrate` so it corrects the just-moved position.

```c
typedef enum { COLLIDER_SPHERE, COLLIDER_BOX, COLLIDER_PLANE, COLLIDER_CAPSULE, COLLIDER_CYLINDER } ColliderShape;
typedef enum { COLLIDER_KEEP_OUT, COLLIDER_KEEP_IN } ColliderMode;
```
- **mode**: `KEEP_OUT` repels particles out of the shape (obstacles); `KEEP_IN` clamps them inside
  it (containment). Orthogonal — every shape supports both (plane keeps particles on its `+normal`
  side; flip the normal for the other side).
- **restitution**: bounce of the into-surface velocity (0 = slide, 1 = elastic).
- **wake** (`KEEP_OUT` obstacles): fraction of the shape's OWN velocity imparted to touched
  particles, so a MOVING collider shoves dust along its travel. Derived from `(a - prev_a)/dt`.

Private `ColliderParams { int shape, mode; vec3 a, b, prev_a; float radius, restitution, wake; }`
where `a`/`b` are shape-dependent anchors: sphere `a`=center; box `a`/`b`=min/max; plane
`a`=point, `b`=normal; capsule/cylinder `a`/`b`=segment endpoints (+`radius`). The kernel dispatches
on `shape` to a per-shape resolve helper (`collider_resolve_sphere/box/plane/capsule/cylinder`) — a
new shape = one enum case + one helper + the matching shader branch.

Ergonomic constructors:
```c
particle_module_collider_sphere  (vec3 center, float radius, ColliderMode, float restitution, float wake);
particle_module_collider_box     (vec3 min, vec3 max, ColliderMode, float restitution);
particle_module_collider_plane   (vec3 point, vec3 normal, float restitution);           // half-space, +normal side
particle_module_collider_capsule (vec3 p0, vec3 p1, float radius, ColliderMode, float restitution, float wake);
particle_module_collider_cylinder(vec3 p0, vec3 p1, float radius, ColliderMode, float restitution, float wake);
```
Setter (move any collider each step; tracks `prev_a` for the wake):
`particle_module_collider_set(ParticleModule* m, vec3 a, vec3 b, float radius)`.

One introspection reader (matched on the **run-fn pointer**, like the existing `read_*`) fills a
public `ColliderState { int shape, mode; vec3 a, b, vel; float radius, restitution, wake; }` — `vel`
is the shape velocity `(a - prev_a)/dt`:
`bool particle_module_read_collider(const ParticleModule* m, ColliderState* out, float dt)`.

No `particle_sim.c` (CPU backend) change — `cpu_simulate` runs every update module via its generic
`e->update` loop.

### Part B — TF/GPU backend (`cetra/src/particle_sim_tf.c` + `cetra/shaders/particle_sim_vert.glsl`)
Colliders are **stateless per particle** (all data from uniforms) → no `ParticleGpuState`/varying
change. The backend supports up to `MAX_COLLIDERS` (e.g. 8) of any shape/mode.
- **Shader** (`particle_sim_vert.glsl`): a uniform collider array, 4 `vec4` per collider:
  `c0 = (shape, mode, radius, restitution)`, `c1 = (a.xyz, wake)`, `c2 = (b.xyz, 0)`,
  `c3 = (vel.xyz, 0)`, plus `int colliderCount`. After the integrate step (`pos += vel*dt;
  vel *= drag`), loop `for (i<colliderCount)` and apply the per-shape response, mirroring the CPU
  helpers (module-order parity is manual in GLSL; GLSL helpers `closestPointOnSegment`, etc.).
- **Uniform seam** `tf_simulate` (sim_tf.c:191-203): iterate `e->update[]`, `read_collider` each,
  pack into the arrays, and upload **every frame** in the per-frame section next to `dt`/`time`
  (colliders are few + may move, so no `setup_done` caching — this sidesteps the moving-collider
  parity trap by design). `vel` per collider comes from the reader.
- No `program.c` change (uniforms resolve by name at set-time). Editing the `.glsl` regenerates
  `shader_strings.h` via `build.sh`.

### Part C — Procedural UV sphere (`cetra/src/geometry.{h,c}`)
No sphere generator exists (documented engine gap). Add, mirroring `generate_box_to_mesh`
(geometry.c:572) and the asset's `assets/gen_glass_sphere.py` UV-sphere math:
```c
typedef struct { vec3 position; float radius; int segments_lon, segments_lat; } Sphere;
void generate_sphere_to_mesh(Mesh* mesh, const Sphere* s);
```
Fill positions / normals (= normalized position) / UVs / tangents / bitangents / indices. **CCW
winding from outside, single-sided** — avoid the equatorial reflection-seam bug the glass-asset
commit documents (inward winding on a double-sided mesh trips `pbr_frag`'s `gl_FrontFacing` flip).

### Part D — Spores demo (`apps/spores/src/spores.c`)
- `add_glass_sphere(root, radius)` helper (like `add_box`): `generate_sphere_to_mesh` + glass
  material inline — `transmission=1.0, roughness=0.04, metallic=0, ior=1.5, thickness=1.0,
  opacity=1.0, doubleSided=false`, `pbr` shader. Retain the node in a static `g_sphere_node`.
  (Refraction is engine-default-on, so glass "just works"; spores never disables it.)
- In `on_init`: build a **sphere collider** (`COLLIDER_KEEP_OUT`, with wake) for the glass sphere
  and a **box collider** (`COLLIDER_KEEP_IN`) for the room; **retain the sphere pointer** in a static
  `g_sphere_collider`; add both to the emitter update list after `integrate`. The room box uses the
  interior AABB (e.g. min `{-11.5, 0, -11.5}`, max `{11.5, 14, 11.5}`): an invisible front plane
  contains the dust while the room keeps its **open-front** look (only 3 walls + floor are rendered).
- Register `game_set_update(game, on_update)`. `on_update` runs in the fixed loop **before** the
  particle tick (game.c:204 → :209), so each sub-step:
  - compute the sphere world position `p` from `game->time` (deterministic, phase-locked to the
    particle clock) on a lissajous path — e.g. `x = Ax*sinf(fx*t)`, `z = Az*cosf(fz*t)`,
    `y = base + Ay*sinf(fy*t)` — kept inside the room AABB minus the sphere radius;
  - `particle_module_collider_set(g_sphere_collider, p, p, radius)` — feeds this sub-step;
  - write `p` into `g_sphere_node->original_transform[3][0..2]` (the shapes.c translation-column
    pattern) so `on_render`'s existing `apply_transform_to_nodes` propagates it for rendering.
- `on_render` unchanged (already applies transforms + `render_current_scene`).

## Files
- `cetra/src/particle_module.{h,c}` — unified `collider` module (5 shapes × keep-in/out), the five
  ergonomic constructors, the setter, and one `read_collider` reader.
- `cetra/src/particle_sim_tf.c` — per-frame collider-array upload + `TfEmitterState`.
- `cetra/shaders/particle_sim_vert.glsl` — collider uniform array + per-shape response after integrate.
- `cetra/src/geometry.{h,c}` — `Sphere` struct + `generate_sphere_to_mesh`.
- `apps/spores/src/spores.c` — glass-sphere node, collider modules, `on_update` wiring, containment.

## Reuse (don't reinvent)
- `update_drift_run` / `update_integrate_run` (particle_module.c) as the kernel template; the
  existing `read_curl`/`read_drift`/`read_integrate` as the reader template.
- `generate_box_to_mesh` (geometry.c:572) as the generator template; `assets/gen_glass_sphere.py`
  for the UV-sphere vertex/index math.
- `tf_simulate` uniform seam (sim_tf.c:191-203); `uniform_set_vec3/float` (uniform.h).
- shapes.c translation-column write; `game->time` (deterministic sim clock); `game_set_update`
  (fires before `scene_update_particle_systems`); `particle_system.c:63-64` copies
  `node->global_transform` into the emitter frame automatically.

## Verification
1. `./build.sh` clean (shader header regenerates from the edited `.glsl`).
2. **TF (default)** — `./out/bin/spores --headless --frames 600 --screenshot tf.ppm`: glass sphere
   visible; a clear dust-free cavity/wake around it; dust contained (no motes past walls/floor/front).
3. **CPU parity** — `./out/bin/spores --cpu --headless --frames 600 --screenshot cpu.ppm`: same
   collision behavior (per-particle positions differ due to the pre-existing CPU/GPU noise
   divergence, but the cavity around the sphere + containment must match qualitatively).
4. **Motion strip** — `--screenshot-every N` to a strip: confirm the sphere moving and the dust
   reacting frame-to-frame (the moving-sphere-uploads-per-frame check on TF).
5. Interactive run to eyeball the push + the dust refracting through the glass.

## Risks / notes
- **Per-frame sphere upload on TF** is the specific parity trap — a frozen GPU sphere means the
  `setup_done` cache wasn't bypassed for it.
- **GLSL module-order parity** is manual — collider response must sit after the integrate step.
- **Glass is transmissive** → the demo now exercises the refraction resolve + transparent/particle
  pass ordering in one scene; verify the glass refracts the dust cleanly and particles composite.
- **Containment AABB** must sit just inside the visible walls (too tight = motes stick; too loose =
  clip walls).
- **Cylinder** is the most involved shape (finite: curved side + two end caps) in both the CPU
  helper and GLSL; capsule (segment + radius) and plane (half-space) are simpler.
- `MAX_COLLIDERS` bounds the TF array; excess colliders on an emitter are dropped (log it).
- Optional future extension (out of scope): floor-settle + light gravity for "kicked-up dust."
- Do this on a fresh branch off master.
