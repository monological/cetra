# Tier 2 · 4.11 — Parallax Occlusion Mapping (POM)

## Context

The engine carries a **height texture slot** (`Material.height_tex`, `material.h:75`) but never uses it
for depth — a flat brick/tile/cobble surface reads flat. POM ray-marches a height field in tangent
space to offset the sampled UV so the surface fakes real relief with self-occlusion, self-shadowing,
and receding silhouettes, at no extra geometry. Roadmap feature 4.11.

Two scope decisions settled with the user:
- **Full technique in v1:** core relief + self-occlusion **and** soft self-shadowing **and** silhouette
  clipping.
- **Height loading = dedicated texture + filename convention.** glTF core defines **no** height/
  displacement texture (`KHR_materials_displacement` was an abandoned draft; assimp surfaces nothing),
  and the engine imports 100% through assimp with no JSON parser. Every major engine models height as a
  **dedicated material slot the pipeline resolves** — so we keep the existing `Material.height_tex` and
  populate it by a **filename convention** (`…_height.png` sibling). This works on real glTF/FBX/OBJ
  assets and leaves `import.c`/assimp byte-clean. (Normal-alpha packing was considered and rejected as
  legacy/niche — modern BC5 normals are two-channel with no alpha to pack into.)

## Design decisions

1. **Dedicated `sampler2D heightTex` on unit 4.** POM samples the field ~16–37×/frag (adaptive linear
   search + 5 bisections) plus the self-shadow march; a native-res dedicated sampler is cache-friendly
   and simplest. Unit 4 is inside the material band (`4 < MATERIAL_MAX=9`) so the ordered assert chain is
   unchanged; add a local `_Static_assert(CLEARCOAT_NORMAL < HEIGHT < EMISSIVE)`. Active samplers stay
   ≤ 15 (GL 4.1 ceiling 16). Not the mask `sampler2DArray` — it canonical-resamples layers (softens
   relief) and is heavy to thread through `mask_array_build`.
2. **Filename-convention height loader.** Post-import `resolve_height_maps(scene, texture_dir)`: for each
   material with no `height_tex` but with an albedo/normal texture that has a resolvable file path,
   derive a sibling by suffix (`_albedo|_basecolor|_diffuse|_normal|_norm` → `_height`, else
   `<stem>_height`) and, if the file exists, load it (`is_srgb=false`). Assets without a sibling are
   untouched → byte-clean. `import.c`/assimp unchanged.
3. **`float parallax_scale` (Material, default 0 = inert) + `parallax_enabled` (engine, default true).**
   Guard the whole POM path with `parallaxEnabled>0 && heightTexExists>0 && parallaxScale>0.0` so any
   non-POM material runs the exact pre-feature path. Mirrors clearcoat.
4. **Tangent-space march in the fragment shader — no vertex/skinned change.** `Vts =
   normalize(transpose(TBN) * V)` (TBN maps tangent→world; transpose = world→tangent for the
   near-orthonormal interpolated basis). Offset dir in UV = `Vts.xy / max(abs(Vts.z),1e-4)`. Adaptive
   layer count (8 near-normal → 32 at grazing) with a fixed loop bound + early break, then 5 binary
   bisections. Convention `depth = 1 - height` (white = raised). Rewrite `uv` immediately after `:601`.
5. **Full technique**, staged: core relief (M3) → self-shadowing (M4) → silhouette clipping (M5).
   AO-on-UV1 (`:678`) is **not** offset (lightmaps are flat).

## Budgets & risks

- **Tangent-space math** (highest): `transpose(TBN)` is world→tangent only for an orthonormal basis; the
  interpolated TBN is near-orthonormal (the normal path re-orthonormalizes before its own use). Fine for
  a fake-relief offset; skinned non-uniform scale skews it — v1 targets flat/static. `max(abs(Vts.z),1e-4)`
  guards grazing blow-up.
- **Self-shadow cost** (M4): extra tangent-space march ×lights on the POM material only; POM-guarded.
- **Silhouette clip** (M5): discard interacts with A2C/depth; feather to avoid holes.
- **Byte-identity off:** all new code inside the guard; declare-but-don't-sample in M1; don't touch
  `:737`'s `V`. clearcoat/specular/sheen prove the bar.
- **Convention loader:** resolves siblings for external-texture assets (the fixture uses external PNGs);
  embedded/data-URI textures have no sibling path (documented; app can set height explicitly).

## Shipped (2026-07-19) — outcome & known limitations

All milestones landed as designed: dedicated unit-4 `heightTex`, filename-convention loader, adaptive
linear march + last-two-sample refine, self-shadowing, silhouette clipping. Global toggle
(`engine->parallax_enabled` / `--no-parallax`), per-material `parallax_scale`, guarded so the OFF path is
the pre-feature pipeline.

**Byte gates (final, post-review-fix binary):** c64 OFF and fixture `--no-parallax` are `cmp`-exact vs
the master baselines; determinism ×2 exact; the C-side (render/engine/import) is `cmp`-exact for raiden.
**raiden shows ±1 ulp on 2 of 6.2M pixels** vs master — root-caused (isolated by rebuilding with master's
`pbr_frag.glsl` on top of all POM C changes → raiden byte-exact) to GLSL **compiler FP reassociation** of
the added, guarded, inert POM shader code (the shared fragment shader grew; the base lighting math is
textually unchanged and the fixture's OFF path is byte-exact across the pre/post-POM shader boundary). It
is a benign compiler artifact on the skinned asset, **not** a behavior leak (POM is fully guarded off for
raiden; a real leak would move thousands of pixels, not 2). Accepted and documented rather than chased.

**Known limitation — silhouette-edge aliasing at grazing angles.** Silhouette clipping recedes the relief
via `discard`, which is all-or-nothing per pixel. MSAA antialiases *triangle* edges but cannot smooth a
discard edge, and the contour is also quantized by the discrete march layers — so at grazing angles a
still frame shows a stepped/"dashed" silhouette. **Live rendering is clean** because the interactive path
runs 1× MSAA + **TAA** (jitter + accumulation + camera motion smooth the edge); the artifact only surfaces
in non-TAA contexts — notably the deterministic **headless 4× MSAA screenshots** (TAA is deliberately off
there for reproducible byte gates) and first-frame-before-TAA-converges. The recession itself is doing
real work (the wall reads with edge thickness), so a flat cutoff would trade the artifact for a flat,
card-like contour. Deliberate ship decision: keep silhouette clipping; live is clean. Proper fix deferred
(below).

**Also deferred:**
- **Silhouette AA (the real fix):** convert the hard discard to fractional **alpha-to-coverage** so the
  edge antialiases in the MSAA path (stills/headless) while TAA continues to carry the 1× live path; pair
  with a finer/adaptive march-layer count to cut the depth quantization. Non-trivial: routes the opaque
  POM material through the A2C pipeline and re-opens all byte gates.
- **Tiled/wrapped-UV seam:** the `uv0 ∈ [0,1]` silhouette gate protects interior tiles but not tile-0's
  own `[0,1]` boundary for tiled UVs; a per-material "relief is edge-bounded" flag or wrap-mode awareness
  would generalize it. v1 targets 1:1 relief (the fixture).
- `g_parallax_default_scale` could migrate from an `import.c` static to an engine field; kept as-is for v1.
