# Tier 2 · 4.5 — Volumetric fog / god rays (screen-space raymarch)

## Context

The engine has no participating media: air is perfectly clear, so nothing reads volumetrically —
no light shafts through the key lights, no atmospheric depth, no ground haze. §4.5 adds it. Per
the user's decision the implementation is a **screen-space raymarch**, not the roadmap's froxel
grid: this viewer has one shadow-casting key-light rig and essentially no transparents, so the
grid's advantages (many lights amortized, fog on transparents, authored volumes) never activate,
while its costs (the codebase's first 3D textures + ~64 slice passes per frame on Apple's
GL-on-Metal, banding without TAA — which headless disables) are exactly the driver-edge risks
that hurt us in 4.4. Froxels remain the upgrade path if gametest grows local lights; everything
below except the march itself (composite, publish plumbing, GUI, policy) carries over.

**The design:** a half-res pass marches each pixel's view ray from the camera to its depth
(`fogFar` for sky), accumulating single-scattered light where the shadow map says the air is lit
(Henyey-Greenstein phase, per-caster) plus an ambient term, through an exponential height-fog
density, producing `(inscatter.rgb, transmittance.a)`. Composite into the HDR scene before
DoF/bloom as `scene·T + inscatter` — one blend mode — so shafts bloom like direct light.

**Key exploration facts:**
- Insertion seam verified at `postfx.c:1030→1032` (after the SSGI composite, before DoF picks
  `scene_tex`) — fog then flows into DoF, auto-exposure metering, bloom, tonemap.
- The blend `glBlendFunc(GL_ONE, GL_SRC_ALPHA)` on a `(inscatter, T)` source gives exactly
  `scene·T + inscatter`; mirror the SSR composite idiom incl. blend-state restore (postfx.c:1004-1008).
- **postfx has zero light/shadow data today** — the main new plumbing is a publish function
  mirroring `reflection_probe_publish_to_postfx` (probe.c:255-271, called engine.c:1440).
- Ray reconstruction uses the aux buffer's linear view-Z (GTAO's `viewPosFromLinZ`,
  gtao_frag.glsl:48-52) + `invView`, NOT depth+invProjection: the catcher writes aux=0 always
  (deliberate sky sentinel) while its *depth* varies with SSR state and shadow discards — the
  linZ path treats the whole background uniformly and needs no depth-resolve gate. The jittered
  `draw_projection` already passed to postfx keeps TAA-jitter consistency by construction.
- Simple shadow sampling precedent: catcher_frag.glsl `occlusion_from` (:38-55) — project by
  `lightSpaceMatrix[slot]`, bounds-check → lit, single compare vs
  `texture(shadowMaps, vec3(uv, slot)).r`. Fog needs one tap per step per caster (no PCF/PCSS —
  dither + tent + 24 steps average it).
- Array uniforms in the fog block use the catcher's snprintf-indexed loop (render.c:673-684) —
  postfx has no array-uniform precedent.

## Fog math (spec)

- **Density:** `sigma(h) = fogDensity · exp(-max(h - fogFloorY, 0) / fogHeightFalloff)`.
  `fogFloorY = 0` (the app recenters models so the ground is y=0; `bb_min.y` under `--no-recenter`).
- **Per-step integration (energy-conserving closed form — NOT naive Riemann, which explodes when
  scene-scaled sigma meets scene-scaled dt):**
  ```
  stepTrans = exp(-sigma·dt);  L += T·(1−stepTrans)·S;  T *= stepTrans
  ```
- **Source:** `S = ambientColor + sunBoost · Σ_j lightColor[j] · phase_j · visibility_j(P)` with
  `lightColor = color·intensity` (the PBR pass's units).
- **Phase:** normalized Henyey-Greenstein (with 1/4π), `cosθ_j = dot(lightDir[j], −rayDir)`
  (lightDir = travel direction). Directional lights ⇒ phase is pixel-constant → hoisted out of
  the loop (why HG beats Schlick here). Default `g = 0.45`.
- **All 3 casters** looped (not key-only): the studio rig makes up to 3 intensity-weighted
  casters; cross-shadowing needs each light's own map. 24 steps × ≤3 taps ≈ cheaper than the
  catcher's 75-tap full-res PCF.
- **Early-out** at `T < 0.003`; write clamp `min(L, vec3(500))` (fp16 safety; do NOT clamp low —
  shafts must stay HDR to bloom).
- **March extent:** `tEnd = sky ? fogFar : |viewPos|`, clamped by `fogFar` and by the floor
  plane for downward rays (`(floorY − camPos.y)/rayDir.y`) — makes dome-floor "sky" rays
  terminate where a real floor would; sky rays give shafts against the dome walls.
- **Dither:** IGN of gl_FragCoord (ssr_frag precedent) — frame-static headless; under
  `taa_resolving` add golden-ratio × frameIndex rotation (GTAO's `temporal` idiom).

## Data model

**postfx.h:** `POSTFX_DEBUG_FOG = 6`; `#define POSTFX_FOG_MAX_LIGHTS 3` (== MAX_SHADOW_LIGHTS,
postfx stays Scene-agnostic); PostFX fields:
- Params: `bool fog_enabled(false)`, `float fog_density(0.02)`, `fog_height_falloff(4)`,
  `fog_floor_y(0)`, `fog_far(60)`, `fog_anisotropy(0.45)`, `fog_sun_boost(1)`,
  `vec3 fog_ambient(0.05)`, `int fog_steps(24)` — meter-scale defaults, apps scene-scale.
- Targets (lazy, DoF pattern): `bool fog_ready; GLuint fog_fbo, fog_texture` (half-res RGBA16F
  at ssao_width/height); `PingPong fog_history` (M3).
- Programs: `fog_program`, `fog_composite_program`, `fog_accum_program` (M3).
- Published block: `int fog_light_count; mat4 fog_light_space[3]; vec3 fog_light_color[3];
  vec3 fog_light_dir[3]; GLuint fog_shadow_map_array; float fog_shadow_bias`.

**Publish plumbing:** `shadow_publish_to_postfx(const Scene*, PostFX*)` in **shadow.c** (owns
the source data; already includes scene/light/engine headers; add postfx.h — no cycle).
Guard → count 0 + array 0 when shadows off/absent (fog degrades to ambient haze). Else fill
slots by `light->shadow_map_index` like the catcher weight loop (render.c:663-672). Declare in
shadow.h with `struct PostFX;` forward. Call in `engine_present_frame` right after the probe
publish (engine.c:1440), unconditional.

**Predicate:** extend `postfx_wants_aux_gbuffer` (postfx.c:637-644) with `|| fx->fog_enabled`
(+ doc comment postfx.h). No new G-buffer attachment needed.

## Shaders (new, auto-embedded by gen_shader_header.py)

- `cetra/shaders/fog_frag.glsl` — the march. Uniforms: `auxTex(0)`, `shadowMaps(1,
  sampler2DArray)`, `invView`, `projection` (only [0][0]/[1][1] used), `lightSpaceMatrix[3]`,
  `lightColor[3]`, `lightDir[3]`, `numLights`, `ambientColor`, `density/heightFalloff/floorY/
  fogFar/anisotropy/sunBoost/shadowBias`, `steps`, `temporal`, `frameIndex`. Structure per the
  math spec; `fogVisibility(slot, P)` = catcher-style projection + bounds→lit + single compare.
- `cetra/shaders/fog_composite_frag.glsl` — 3×3 tent upsample (copy ssr_composite_frag.glsl,
  rgba). Depth-aware upsample deliberately omitted v1 (low-frequency signal); upgrade path =
  aux-linZ-weighted taps.
- `cetra/shaders/fog_accum_frag.glsl` (M3) — ssgi_accum clone with the same uniform layout (so
  `run_temporal_accum` works unchanged) but **rgba-preserving** (transmittance in .a must clamp
  through the same neighborhood AABB); plain RGBA clamp, FEEDBACK 0.9 (no YCoCg — low-frequency).

**Program factories:** `create_fog_program/…_composite/…_accum` via the static
`create_post_program(name, frag_src)` (program.c:695); declare in program.h; register + sampler
ints in create_postfx (fog: auxTex 0, shadowMaps 1; composite: fogTex 0; accum: 0/1/2 + texelSize);
tonemap gets `fogTex = 8` (units 0–7 taken); free with the others.

## postfx_run fog block (insert between :1030 and :1032)

```c
bool fog_active = fx->fog_enabled && aux_written && postfx_ensure_fog_targets(fx);
if (fog_active) {
    // march into fog_fbo at ssao res (own glm_mat4_inv(view, inv_view) local);
    // array uniforms via snprintf loop; bind aux(0) + shadow array(1)
    GLuint fog_result = fx->fog_texture;
    if (taa_resolving) fog_result = run_temporal_accum(..., &fx->fog_history, ...); // M3
    else fx->fog_history.valid = false;
    // composite: hdr_fbo, full-res viewport, tent shader, texelSize=1/ssao;
    glEnable(GL_BLEND); glBlendFunc(GL_ONE, GL_SRC_ALPHA);   // scene·T + inscatter
    draw; glDisable(GL_BLEND); glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);
} else { fx->fog_history.valid = false; }
```

`debugView == 6` block in tonemap_frag.glsl, suppression guard `(POSTFX_DEBUG_FOG && !fog_active)`.

## Risks (defaults chosen)

1. **Shadow-volume coverage:** casters' ortho box (±2r, far 8r) < `fog_far` 5r laterally —
   distant sky-segments exit the volume and return lit; shafts live within ~2r and fade to
   plain haze beyond. Benign; CSM (§4.6) is the real fix.
2. **Half-res silhouette seams** at high density: accepted v1; upgrade = linZ-weighted tent.
3. **Translucents** don't receive fog (no aux) — same limitation as GTAO/SSR; ignore.
4. **fp16:** physical inscatter ≈ ≤5; `min(L, 500)` guards hostile slider combos.
